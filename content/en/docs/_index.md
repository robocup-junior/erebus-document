## Erebus Rescue Simulator
Erebus is a robot simulation competition environment. You develop a controller for a robot that autonomously explores a maze, finds and identifies wall tokens (letter victims and cognitive targets), avoids obstacles and traps, and builds a map of the environment.

It is built on [Webots](https://cyberbotics.com/), a robotic simulation platform designed for professional use and widely used in industry, education and research. Cyberbotics has maintained Webots continuously since 1998. See the [Webots User Guide](https://cyberbotics.com/doc/guide/index?version=R2023b) for details of the simulator itself.

This documentation covers **Erebus v26**, which implements the **RoboCupJunior Rescue Simulation 2026** rules.
