## Compétition internationale RoboCupJunior 2027 {#robocupjunior-2027-international-competition}

La RoboCup 2027 aura lieu à Nuremberg, en Allemagne, du 17 au 21 juin 2027. Le simulateur Erebus sera utilisé par les équipes participant à la compétition RoboCupJunior Rescue Simulation.

Cette documentation décrit Erebus v27 et les règles 2027, utilisés pour cette compétition. Consultez la [page de l’événement](https://rescue.rcj.cloud/events/2027/RoboCup2027/simulation/index.html) et le [forum](https://junior.forum.robocup.org/) pour les dernières nouvelles et les éventuels changements de règles.
