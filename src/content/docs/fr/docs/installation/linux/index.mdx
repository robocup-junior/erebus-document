<Steps>

1. Ouvrez le terminal, puis installez pip et les bibliothèques nécessaires :

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   Sur Ubuntu 24.04, pip refuse d’installer des bibliothèques dans le Python du système, avec une erreur `externally-managed-environment`. Ajoutez `--break-system-packages` à la deuxième commande, ou installez les bibliothèques dans un [environnement virtuel](https://docs.python.org/3/library/venv.html) et indiquez son Python dans les préférences de Webots.

2. Téléchargez et installez **Webots R2025a** :

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. Téléchargez <DownloadErebus /> et décompressez-le.

</Steps>

## Lancer l’environnement \{#run-the-environment\}

Ouvrez le monde depuis le terminal, en remplaçant le chemin par celui de votre dossier Erebus :

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots ouvre la fenêtre de contrôle d’Erebus dans votre navigateur web. La première fois, Erebus installe quelques bibliothèques Python et prépare le modèle du robot, ce qui peut prendre un moment. Il est prêt quand la fenêtre affiche **Ready** et le chronomètre de jeu à 08:00 :

![La fenêtre de contrôle d’Erebus, prête à démarrer](../../../../docs/installation/linux/../control-window-ready.png)

La première fois, la console de Webots peut aussi afficher `ERROR: Skipped PROTO 'custom_robot'`. Vous pouvez l’ignorer : Erebus prépare le modèle du robot et recharge le monde de lui-même.

Ensuite, lisez le [Résumé des règles](/docs/rules/) pour comprendre le jeu. En cas de problème, consultez [Dépannage](/docs/troubleshooting/).
