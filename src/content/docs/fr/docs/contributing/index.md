## Contribuer à la plateforme Erebus  {#contributions-to-the-erebus-platform}

Si vous souhaitez contribuer à la plateforme Erebus, il existe actuellement plusieurs façons de le faire.
- Ouvrir des [issues dans le dépôt](https://github.com/robocup-junior/erebus/issues) : signalez-nous les bugs que vous trouvez dans la plateforme, ou une fonctionnalité qui devrait selon vous être ajoutée.
- Pull requests : si vous parvenez à corriger le bug vous-même, vous pouvez proposer une pull request pour que cette modification soit éventuellement intégrée.
- Parlez-nous sur le [serveur Discord](https://discord.com/invite/6FJxZxk) : vous pouvez échanger avec nous (développeurs, comité RCJ Rescue) sur le serveur Discord. N’hésitez pas à partager vos idées !

### S’impliquer davantage {#deeper-involvement}
Nous ne recherchons pas activement de nouveaux développeurs pour la plateforme de simulation en ce moment. Cependant, nous sommes toujours à la recherche de nouveaux talents pour faire vivre cette plateforme pour les générations futures. Si vous pensez vraiment avoir les compétences nécessaires et souhaitez rejoindre l’équipe de développement de la plateforme, contactez l’équipe de développement ou le comité RoboCupJunior Rescue sur le serveur Discord.

## Contribuer à la documentation {#contributions-to-the-documentation}

- Ouvrir des issues en cliquant sur [Documentation issue](https://github.com/robocup-junior/erebus-document/issues) et en créant une issue dans le dépôt du projet.
- Parlez-nous sur le [serveur Discord](https://discord.com/invite/6FJxZxk) : vous pouvez échanger avec nous (développeurs, comité RCJ Rescue) sur le serveur Discord. N’hésitez pas à partager vos idées !
- Devenez un rédacteur actif de la documentation ! Si vous souhaitez participer activement à sa rédaction, contactez l’équipe de développement de la plateforme sur le serveur Discord.

La documentation est un site [Astro](https://astro.build/) qui utilise le thème [Starlight](https://starlight.astro.build/). Les pages sont des fichiers Markdown dans `src/content/docs`, et chaque page comporte un lien **Modifier cette page** en bas. Consultez le [README](https://github.com/robocup-junior/erebus-document#readme) du dépôt de la documentation pour la lancer en local.
