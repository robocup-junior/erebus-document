## Contribuer à la plateforme Erebus {#contributions-to-the-erebus-platform}

Il existe plusieurs façons de contribuer à la plateforme Erebus :
- Ouvrez une [issue dans le dépôt](https://github.com/robocup-junior/erebus/issues) : signalez-nous un bug que vous avez trouvé dans la plateforme, ou une fonctionnalité qui, selon vous, devrait y figurer.
- Proposez une pull request : si vous corrigez un bug vous-même, vous pouvez soumettre la modification dans une pull request, pour qu’elle soit relue et intégrée.
- Parlez-nous sur le [serveur Discord](https://discord.com/invite/6FJxZxk) : vous pouvez y joindre les développeurs et le comité RCJ Rescue. N’hésitez pas à partager vos idées !

### S’impliquer davantage {#deeper-involvement}
Nous ne recherchons pas activement de nouveaux développeurs pour la plateforme de simulation en ce moment. Cependant, nous sommes toujours à la recherche de nouveaux talents pour faire vivre la plateforme pour les générations futures. Si vous avez les compétences nécessaires et souhaitez rejoindre l’équipe de développement, contactez l’équipe de développement de la plateforme ou le comité RoboCupJunior Rescue sur le serveur Discord.

## Contribuer à la documentation {#contributions-to-the-documentation}

- Ouvrez une issue dans le [dépôt de la documentation](https://github.com/robocup-junior/erebus-document/issues).
- Parlez-nous sur le [serveur Discord](https://discord.com/invite/6FJxZxk) : vous pouvez y joindre les développeurs et le comité RCJ Rescue. N’hésitez pas à partager vos idées !
- Devenez rédacteur de la documentation ! Si vous souhaitez aider à la rédiger, contactez l’équipe de développement de la plateforme sur le serveur Discord.

La documentation est un site [Astro](https://astro.build/) qui utilise le thème [Starlight](https://starlight.astro.build/). Les pages sont des fichiers Markdown dans `src/content/docs`, et chaque page comporte un lien **Modifier cette page** en bas. Consultez le [README](https://github.com/robocup-junior/erebus-document#readme) du dépôt de la documentation pour la lancer en local.
