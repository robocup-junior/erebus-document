---
title: Programmer votre robot
description: Le chemin de votre premier programme jusqu’à un robot qui joue la partie complète.
---

Un programme, ou **contrôleur**, tourne en boucle : lire les capteurs, décider, régler les moteurs, et laisser la simulation avancer d’un pas. Tout ce que fait votre robot vient de cette boucle.

Tous les exemples présentés ici fonctionnent avec le [robot de départ](/docs/robot/). Chargez-le avant de les exécuter, et ils fonctionnent tels quels. Chaque exemple existe en version Python et C/C++ : choisissez votre langage dans les onglets, et tout le site suit votre choix.

## Le chemin \{#the-path\}

| Étape | Vous apprenez à… |
|---|---|
| 1. [Votre premier programme](/docs/programming/first-program/) | Écrire, charger et exécuter un programme |
| 2. [Déplacement](/docs/programming/movement/) | Avancer et tourner |
| 3. [Capteurs](/docs/programming/sensors/) | Trouver les murs, les trous, les marqueurs et votre position |
| 4. [Parcourir le labyrinthe](/docs/programming/navigate-the-maze/) | Tout assembler dans un programme complet |
| 5. [Communication](/docs/programming/communication/) | Signaler les marqueurs et marquer des points |
| 6. [Marqueurs muraux](/docs/programming/wall-tokens/) | Distinguer les victimes, les cibles et les leurres |
| 7. [Explorer et cartographier](/docs/programming/exploring/) | Explorer méthodiquement et mémoriser le labyrinthe |
| 8. [Règles de cartographie](/docs/rules/mapping/) et [Soumettre la carte](/docs/programming/map-bonus/) | Obtenir le bonus de cartographie |

Chaque étape s’appuie sur les précédentes. Si ce n’est pas encore fait, lisez d’abord le [Résumé des règles](/docs/rules/) : il explique ce que votre robot doit faire, et ce qui rapporte des points.

Si vous programmez en C ou en C++, lisez d’abord [Contrôleurs C++](/docs/programming/cpp/) pour compiler et exécuter vos programmes.
