Les capteurs renseignent votre robot sur le monde. Tous les capteurs s’utilisent de la même façon :

1. Obtenez-le grâce à son nom avec `robot.getDevice()`.
2. Activez-le avec `enable(timeStep)`. Avant cela, il ne donne aucune valeur.
3. Lisez-le dans la boucle principale. Les valeurs sont mises à jour après chaque `robot.step()`.

Comme les vrais capteurs, ils ont du bruit : une même mesure peut varier un peu d’un pas à l’autre. Les organisateurs ne modifient pas le bruit pour la compétition : rendez donc votre programme robuste face à lui, par exemple en comparant plusieurs mesures.
