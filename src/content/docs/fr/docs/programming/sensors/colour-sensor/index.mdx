Le capteur de couleur regarde le sol : il renseigne donc le robot sur les trous, les marécages, cases de contact et les passages. C’est une caméra d’un seul pixel, orientée vers le bas. Sur le robot de départ, il s’appelle `color` et se trouve à l’avant du robot, pour voir un trou avant que les roues ne l’atteignent.

## Couleurs du sol \{#floor-colours\}

Ces valeurs ont été mesurées avec le robot de départ sur `world2.wbt` et `mapping_example_1_cyan_tiles.wbt` :

| Sol | Rouge | Vert | Bleu |
|---|---:|---:|---:|
| Normal | 242 | 242 | 242 |
| Point de contrôle | 254 | 254 | 254 |
| Marécage | 225 | 193 | 115 |
| Case de contact (cyan) | 0 | 242 | 242 |
| Trou (bord noir) | 34 | 34 | 34 |
| Passage entre les zones 1 et 2 (bleu) | 72 | 72 | 254 |
| Passage entre les zones 2 et 3 (violet) | 161 | 72 | 238 |
| Passage entre les zones 1 et 4 (vert) | 38 | 253 | 38 |
| Passage entre les zones 3 et 4 (rouge) | 254 | 72 | 72 |

:::caution
Les valeurs peuvent changer selon le monde et les réglages graphiques. Utilisez des plages plutôt que des valeurs exactes, et vérifiez-les avec `calibrateColourSensor.py` dans le dossier `player_controllers` d’Erebus.
:::

Les trous ont un bord noir : le sol devient donc sombre juste avant un trou. Les points de contrôle ne sont qu’un peu plus clairs que le sol normal : étalonnez sur l’un d’eux dans votre monde avant de vous y fier.
