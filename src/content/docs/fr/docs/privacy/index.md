Cette documentation est un site web statique. Il n’y a pas de comptes, et aucune information personnelle ne vous est demandée.

## Mesure d’audience {#analytics}
Ce site utilise [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) pour savoir quelles pages sont consultées, afin de les améliorer. Il compte les visites sans cookies et sans identifier les visiteurs individuellement.

## Ce qui est enregistré dans votre navigateur {#what-is-stored-in-your-browser}
Le site enregistre quelques réglages dans votre navigateur, qui ne sont envoyés nulle part :

- Votre thème
- L’onglet de langage sélectionné dans les exemples de code

Ce site n’utilise pas de cookies.
