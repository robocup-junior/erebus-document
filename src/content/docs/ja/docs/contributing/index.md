## Erebus プラットフォームへの貢献 {#contributions-to-the-erebus-platform}

Erebus プラットフォームには、次のような方法で貢献できます。
- [リポジトリに Issue を作成する](https://github.com/robocup-junior/erebus/issues): プラットフォームのバグを見つけたときや、あったらよいと思う機能があるときに知らせてください。
- プルリクエストを送る: 自分でバグを修正したら、その変更をプルリクエストで送ってください。レビューを経てマージされます。
- [Discord サーバー](https://discord.com/invite/6FJxZxk)で話しかける: 開発者や RCJ Rescue 委員会と連絡を取れます。ぜひアイデアを聞かせてください！

### さらに深く関わる {#deeper-involvement}
現在、シミュレーションプラットフォームの新しい開発者を積極的には募集していません。ただし、次の世代のためにプラットフォームを維持していけるよう、新しい人材はいつでも探しています。スキルがあり、開発チームに加わりたい方は、Discord サーバーでプラットフォーム開発チームか RoboCupJunior Rescue 委員会に連絡してください。

## ドキュメントへの貢献 {#contributions-to-the-documentation}

- [ドキュメントのリポジトリ](https://github.com/robocup-junior/erebus-document/issues)に Issue を作成する。
- [Discord サーバー](https://discord.com/invite/6FJxZxk)で話しかける: 開発者や RCJ Rescue 委員会と連絡を取れます。ぜひアイデアを聞かせてください！
- ドキュメントの編集者になる！ドキュメントの執筆を手伝いたい方は、Discord サーバーでプラットフォーム開発チームに連絡してください。

このドキュメントは、[Starlight](https://starlight.astro.build/) テーマを使った [Astro](https://astro.build/) サイトです。ページは `src/content/docs` にある Markdown ファイルで、すべてのページの下部に **ページを編集** リンクがあります。ローカルで動かす方法は、ドキュメントリポジトリの [README](https://github.com/robocup-junior/erebus-document#readme) を参照してください。
