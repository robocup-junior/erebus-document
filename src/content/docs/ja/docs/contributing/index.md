## Erebus プラットフォームへの貢献  {#contributions-to-the-erebus-platform}

Erebus プラットフォームに貢献したい場合、現在はいくつかの方法があります。
- [リポジトリの Issues](https://github.com/robocup-junior/erebus/issues) に投稿する: プラットフォームのバグや、追加すべきだと思う機能を見つけたら教えてください。
- プルリクエスト: 自分でバグを修正できたら、その変更のプルリクエストを作成してください。採用される可能性があります。
- [Discord サーバー](https://discord.com/invite/6FJxZxk)で話しかける: Discord サーバーを通じて、私たち（開発者、RCJ Rescue 委員会）と連絡を取れます。ぜひアイデアを聞かせてください！

### さらに深く関わる {#deeper-involvement}
現在、シミュレーションプラットフォームの新しい開発者を積極的には募集していません。ただし、次の世代のためにこのプラットフォームを維持していけるよう、新しい人材はいつでも探しています。自分にスキルがあり、このプラットフォームの開発チームに加わりたいと強く思う方は、Discord サーバーを通じてプラットフォーム開発チームか RoboCupJunior Rescue 委員会に連絡してください。

## ドキュメントへの貢献 {#contributions-to-the-documentation}

- [Documentation issue](https://github.com/robocup-junior/erebus-document/issues) をクリックして、プロジェクトのリポジトリに Issue を作成する。
- [Discord サーバー](https://discord.com/invite/6FJxZxk)で話しかける: Discord サーバーを通じて、私たち（開発者、RCJ Rescue 委員会）と連絡を取れます。ぜひアイデアを聞かせてください！
- ドキュメントの編集者として活躍する！ドキュメントの執筆に積極的に関わりたい方は、Discord サーバーでプラットフォーム開発チームに連絡してください。

このドキュメントは、[Starlight](https://starlight.astro.build/) テーマを使った [Astro](https://astro.build/) サイトです。ページは `src/content/docs` にある Markdown ファイルで、すべてのページの下部に **Edit page**（ページを編集）リンクがあります。ローカルで動かす方法は、ドキュメントリポジトリの [README](https://github.com/robocup-junior/erebus-document#readme) を参照してください。
