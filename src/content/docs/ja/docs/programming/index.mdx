プログラム（**コントローラー**）はループで動きます。センサーを読み取り、判断し、モーターを設定して、シミュレーションを 1 ステップ進めます。ロボットのすべての動きは、このループから生まれます。

ここにある例はすべて[スターターロボット](/docs/robot/)で動きます。実行する前にスターターロボットを読み込めば、そのまま動きます。各例には Python 版と C/C++ 版があります。タブで言語を選ぶと、サイト全体がその選択に従います。

## 学習の道のり \{#the-path\}

| ステップ | 学ぶこと |
|---|---|
| 1. [最初のプログラム](/docs/programming/first-program/) | プログラムを書き、読み込み、実行する |
| 2. [移動](/docs/programming/movement/) | 走行と旋回 |
| 3. [センサー](/docs/programming/sensors/) | 壁、穴、トークン、自分の位置を見つける |
| 4. [迷路を進む](/docs/programming/navigate-the-maze/) | すべてを組み合わせて完全なプログラムにする |
| 5. [通信](/docs/programming/communication/) | トークンを報告して得点する |
| 6. [壁のトークン](/docs/programming/wall-tokens/) | 被災者、ターゲット、偽物を見分ける |
| 7. [探索と地図作成](/docs/programming/exploring/) | 計画的に探索し、迷路を記憶する |
| 8. [地図作成のルール](/docs/rules/mapping/)と[地図の提出](/docs/programming/map-bonus/) | 地図ボーナスを獲得する |

各ステップは、それまでのステップの上に成り立っています。まだ読んでいなければ、先に[ルールの概要](/docs/rules/)を読んでください。ロボットが何をしなければならないか、何が得点になるかを説明しています。

C や C++ で書く場合は、プログラムをコンパイルして実行するために、先に [C++ コントローラー](/docs/programming/cpp/)を読んでください。
