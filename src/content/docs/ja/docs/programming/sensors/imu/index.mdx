## ジャイロスコープ \{#gyroscope\}

ジャイロスコープは、各軸まわりのロボットの回転速度を **ラジアン毎秒** で返します。スターターロボットでは `gyro` という名前です。

`getValues()` は `[x, y, z]` を返します。**Y 軸が垂直方向** なので、`getValues()[1]` がロボットの旋回速度です。左に曲がるときに正の値になります。

:::caution
これはスターターロボットのジャイロの場合です。軸はジャイロの回転に従うので、自作のロボットでジャイロを回転させて取り付けた場合は、ロボットが旋回したときにどの値が変わるかを確認してください。
:::

## 例: 90 度回転する \{#example-turning-90-degrees\}

回転速度にタイムステップを掛けた値を足し合わせると、回転した角度が求まります。速度に左右されないので、旋回を時間で測るよりも確実です。

<CodeTabs file="turn" />

スターターロボットでのテストでは、この方法で計算した角度は実際の回転と 0.01 ラジアン以内で一致しました。小さな誤差もゲーム中に積み重なるので、たとえば壁に合わせるなどして、できるときに向きを補正しましょう。

## 加速度センサー \{#accelerometer\}

加速度センサーは、各軸方向の加速度を m/s² で返します。スターターロボットでは `accelerometer` という名前です。静止しているとき、`getValues()[1]` は重力にあたる約 9.8 になります。

## 慣性計測ユニット \{#inertial-unit\}

慣性計測ユニット（inertial unit）はスターターロボットには付いていません。[Robot Customizer](/docs/robot/customizer/) で追加でき、デフォルトの名前は `inertial_unit` です。回転速度を足し合わせなくても、`getRollPitchYaw()` で向きを直接得られます。[Webots のリファレンス](https://cyberbotics.com/doc/reference/inertialunit?version=R2023b)を参照してください。
