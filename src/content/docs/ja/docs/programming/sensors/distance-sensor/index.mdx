距離センサーは、正面にある最初の物体までの距離を **メートル** 単位で、最大 0.8 m まで測ります。スターターロボットには `leftDist`、`frontDist`、`rightDist` の 3 つがあり、それぞれ左、前、右を向いています。

## 壁を見つける \{#finding-walls\}

タイルの幅は 12 cm なので、ロボットがタイルの中央にいるとき、横の壁までは約 5 cm です。このプログラムは 3 つのセンサーを確認し、壁が見えているセンサーを表示します。

<CodeTabs file="walls" />

センサーは、ロボットの中心からではなく、ロボット上で取り付けられた位置から距離を測ります。壁の近くで値を表示して、自分でしきい値を決めましょう。
