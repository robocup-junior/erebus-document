センサーは、ロボットに周りの世界のことを教えてくれます。どのセンサーも同じ方法で使います。

1. `robot.getDevice()` で名前を指定して取得します。
2. `enable(timeStep)` で有効にします。有効にするまでは値を返しません。
3. メインループの中で読み取ります。値は `robot.step()` のたびに更新されます。

本物のセンサーと同じようにノイズがあり、同じ読み取り値でもステップごとに少し変わることがあります。競技でも運営者はノイズを変更しないので、たとえば複数の読み取り値を比べるなどして、ノイズに強いプログラムにしましょう。
