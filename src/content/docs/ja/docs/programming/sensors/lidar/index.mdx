LiDAR は、たくさんの距離センサーを一度に使うように、ロボットの周囲全体の距離を **メートル** 単位で測ります。スターターロボットでは `lidar` という名前で、ロボットの上部にあります。

ロボットの周囲 512 点を、上下に積み重なった 4 つのレイヤーで、最大 1 m 先まで測ります。何にも当たらなかった点は `inf` になります。

## 距離を読み取る \{#reading-distances\}

`getLayerRangeImage(0)` は、1 つのレイヤーの 512 個の距離を返します。最初の値はロボットの正面で、そこから **時計回り** に並びます。4 分の 1 の位置が右、半分の位置が後ろ、4 分の 3 の位置が左です。

<CodeTabs file="read" />

## 点群 \{#point-cloud\}

LiDAR は、各点を LiDAR からの相対位置として返すこともできます。これは、ロボットが見ているものの地図を描くのに便利です。計算に余分な時間がかかるので、使うときだけ有効にしましょう。

<CodeTabs file="pointcloud" />

:::caution[LiDAR の配置]
自作のロボットでは、LiDAR が水平になるように、[スターターロボット](/docs/robot/build/)と同じ回転で上部に配置してください。本体の内部に置いたり傾けたりすると、ロボット自身を測ってしまいます。
:::
