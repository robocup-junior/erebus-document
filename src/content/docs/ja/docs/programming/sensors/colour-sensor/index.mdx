カラーセンサーは床を見て、穴、沼地、通路があることをロボットに知らせます。下を向いた 1 ピクセルだけのカメラです。スターターロボットでは `color` という名前で、車輪が穴に落ちる前に穴が見えるよう、ロボットの前方に付いています。

<CodeTabs file="read" />

## 床の色 \{#floor-colours\}

次の値は、`world2.wbt` でスターターロボットを使って測ったものです。

| 床 | 赤 | 緑 | 青 |
|---|---:|---:|---:|
| 通常の床 | 252 | 252 | 252 |
| 沼地 | 245 | 222 | 142 |
| エリア 1 と 2 の間の通路（青） | 91 | 91 | 255 |
| エリア 2 と 3 の間の通路（紫） | 193 | 91 | 251 |
| エリア 1 と 4 の間の通路（緑） | 48 | 255 | 48 |
| エリア 3 と 4 の間の通路（赤） | 255 | 91 | 91 |

:::caution
値はワールドによって変わります。`world1.wbt` では、通常の床は約 240 になります。正確な値ではなく範囲を使い、Erebus の `player_controllers` フォルダーにある `calibrateColourSensor.py` で確認しましょう。
:::

穴のふちは黒いので、穴の直前で床が暗くなります。このセンサーにはチェックポイントが通常の床とほとんど同じに見えるので、自分のワールドのチェックポイントでキャリブレーションしてください。
