カラーセンサーは床を見て、穴、沼地、コンタクトタイル、通路があることをロボットに知らせます。下を向いた 1 ピクセルだけのカメラです。スターターロボットでは `color` という名前で、車輪が穴に落ちる前に穴が見えるよう、ロボットの前方に付いています。

<CodeTabs file="read" />

## 床の色 \{#floor-colours\}

次の値は、`world2.wbt` と `mapping_example_1_cyan_tiles.wbt` でスターターロボットを使って測ったものです。

| 床 | 赤 | 緑 | 青 |
|---|---:|---:|---:|
| 通常の床 | 242 | 242 | 242 |
| チェックポイント | 254 | 254 | 254 |
| 沼地 | 225 | 193 | 115 |
| コンタクトタイル（シアン） | 0 | 242 | 242 |
| 穴（黒い縁） | 34 | 34 | 34 |
| エリア 1 と 2 の間の通路（青） | 72 | 72 | 254 |
| エリア 2 と 3 の間の通路（紫） | 161 | 72 | 238 |
| エリア 1 と 4 の間の通路（緑） | 38 | 253 | 38 |
| エリア 3 と 4 の間の通路（赤） | 254 | 72 | 72 |

:::caution
値はワールドやグラフィックの設定によって変わることがあります。正確な値ではなく範囲を使い、Erebus の `player_controllers` フォルダーにある `calibrateColourSensor.py` で確認してください。
:::

穴には黒い縁があるので、穴の直前で床が暗くなります。チェックポイントは普通の床より少し明るいだけなので、頼る前に自分のワールドのチェックポイントで調整してください。
