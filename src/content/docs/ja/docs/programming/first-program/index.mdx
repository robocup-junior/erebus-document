最初のプログラムは、ロボットを前進させ、壁の手前で止めます。短いプログラムですが、どのプログラムにも必要なものがすべて入っています。

<CodeTabs file="hello" />

## しくみ \{#how-it-works\}

1. **ロボットを作成します。** `Robot()` で、プログラムをシミュレーター内のロボットにつなぎます。
2. **タイムステップを取得します。** シミュレーションは数ミリ秒ずつのステップで進みます。`getBasicTimeStep()` はワールドのステップを返します。
3. **デバイスを取得します。** 各モーターとセンサーは名前で見つけます。これは、[ロボットを組み立てた](/docs/robot/build/)ときに付けた名前です。
4. **センサーを有効にします。** センサーは有効にするまで値を返しません。タイムステップは、どのくらいの頻度で更新するかをセンサーに伝えます。
5. **ループします。** `robot.step(timeStep)` はシミュレーションを 1 ステップ進め、シミュレーションが終わると -1 を返します。ロボットのすべての動作は、このループの中で行われます。

## 実行する \{#run-it\}

1. プログラムを `hello.py` として保存します。
2. `game/worlds/mapping_example_1.wbt` を開き、右側の LOAD ボタンで[スターターロボット](/docs/robot/)を読み込みます。
3. 左側の LOAD ボタンで `hello.py` を読み込み、スタートを押します。

ロボットが前進し、止まるまでの間、正面の壁までの距離が Webots のコンソールに表示されます。代わりにエラーが表示された場合は、[トラブルシューティング](/docs/troubleshooting/#your-program)を確認してください。

:::tip
ロボットが何をしているかを理解するには `print` を使いましょう。問題を見つけるための、いちばん簡単で役に立つ方法です。
:::

## 試してみよう \{#try-it\}
- 速度を `3.0` から `6.0` に変えてみましょう。壁の近くで何が起こりますか？
- 5 cm ではなく 10 cm で止まるようにしてみましょう。
- `robot.getTime()` で時間も表示してみましょう。

次は、[移動](/docs/programming/movement/)で走行と旋回を学びましょう。
