プログラムは、すべてのロボットに付いている 2 つのデバイスを通じてゲームとやり取りします。

- **エミッター（emitter）** は、ゲームにメッセージを送ります。有効にする必要はありません。
- **レシーバー（receiver）** は、ゲームからメッセージを受け取ります。センサーと同じように有効にします。

以下の各セクションは、[スターターロボット](/docs/robot/)用の完全なプログラムです。すべてのメッセージは[メッセージリファレンス](/docs/reference/messages/)に載っています。

## 壁のトークンで得点する \{#scoring-wall-tokens\}

スマイリーの被災者（Letter victim）やコグニティブターゲット（Cognitive target）で得点するには、ロボットは次のことをする必要があります。

1. トークンの近くで **1 秒より長く停止する**。直前の 1 秒間にロボットが動いていると、Erebus は報告を無視します。
2. トークンの **位置と種類を送る**。X と Z は **センチメートル** 単位で、種類は 1 文字で表します。

| 壁のトークン | 種類 |
|---|---|
| スマイリーの被災者、悲しい顔（負傷） | `H` |
| スマイリーの被災者、普通の顔（安定） | `S` |
| スマイリーの被災者、笑顔（無傷） | `U` |
| コグニティブターゲット、合計 0（Flammable Gas、可燃性ガス） | `F` |
| コグニティブターゲット、合計 1（Poison、毒物） | `P` |
| コグニティブターゲット、合計 2（Corrosive、腐食性物質） | `C` |
| コグニティブターゲット、合計 3（Organic Peroxide、有機過酸化物） | `O` |

被災者は顔で表示されますが、種類は文字です。GPS はメートル単位なので、100 を掛けてください。

<CodeTabs file="report" />

ロボットはトークンと同じ側の壁にいなければならず、ロボットの中心と送る位置の両方が、トークンからタイル半分（6 cm）以内でなければなりません。

このプログラムを `world1.wbt` のスタート地点で実行してください。そこにはトークンがないので、コントロールウィンドウの試合のイベントに `Misidentification of Victim -5` と表示されます。偽物の報告を含め、誤った報告は 5 点の減点になり、各トークンは 1 回しか得点できません。

![誤った報告をした後の試合のイベント](../../../../docs/programming/communication/history.png)

## 競技進行停止 \{#lack-of-progress\}

ロボットが動けなくなったとき、競技進行停止（Lack of Progress, LoP）によってロボットは最後のチェックポイントに戻され、5 点を失います。20 秒間動かないと自動的に発生しますが、プログラムから `L` を送って宣言することもできます。そのたびにゲームはロボットに `L` を送るので、プログラムは自分の位置が変わったことがわかります。

<CodeTabs file="lop" />

レシーバーはさまざまなメッセージを受け取るので、例のように、読み取る前に各メッセージの長さを確認してください。

## ゲームの情報 \{#game-information\}

`G` を送ると、スコア、残り時間、バッテリー残量がわかります。ゲームは 20 バイトのメッセージで返信します。内容は、文字 `G`、スコア、残りのゲーム時間と残りの実時間（秒）、そしてバッテリー残量（パーセント）です。

<CodeTabs file="gameinfo" />

どちらかの時間がなくなるか、バッテリーが空になると、ゲームは終わります。これらを使って、スタートに戻るタイミングや、[バッテリーを交換する](/docs/programming/battery/)タイミングを判断しましょう。

## ゲームを終了する \{#ending-the-game\}

`E` を送るとゲームが終了します。ロボットがスタートタイルにいて、壁のトークンを 1 つ以上識別していれば、10% の脱出ボーナス（Exit bonus）が得られます。

<CodeTabs file="exit" />

:::caution
`E` を送った時点でロボットがどこにいてもゲームは終了し、ロボットは続行できません。先にスタートタイルに戻り、[地図を提出](/docs/programming/map-bonus/)したことを確認してください。
:::
