ロボットには 2 つの車輪があり、それぞれに専用のモーターが付いています。[スターターロボット](/docs/robot/)では `left wheel motor` と `right wheel motor` です。各車輪の速度を設定してロボットを動かします。

| 左の車輪 | 右の車輪 | ロボットの動き |
|---|---|---|
| 前進 | 前進 | 前進する |
| 後退 | 後退 | 後退する |
| 後退 | 前進 | その場で左に回転する |
| 前進 | 後退 | その場で右に回転する |
| 速い | 遅い | 右にカーブする |

速度の単位は **ラジアン毎秒** で、最大 6.28（1 秒に車輪 1 回転）です。負の速度にすると車輪は逆回転します。

## 走行する \{#driving\}

1. 名前を指定して各モーターを取得します。
2. 位置を無限大に設定して、制限なく回るようにします。
3. 速度を設定します。

モーターは最後に設定した速度を保つので、プログラムがほかの処理をしている間もロボットは動き続けます。このプログラムは、前進、後退、左回転をそれぞれ 1 秒ずつ行います。

:::note
Webots の角度はラジアンです。変換式: ラジアン = 度 × π / 180
:::

## 車輪がどれだけ回ったかを測る \{#measuring-how-far-a-wheel-turned\}

各モーターには位置センサー（エンコーダーとも呼びます）があり、車輪が回った量をラジアンで数えます。決まった距離を走らせるのに便利です。逆回転すると値は減っていきます。

<CodeTabs file="encoders" />

時間で動きを測るのは簡単ですが、結果は速度によって変わります。エンコーダーは動きそのものを測るので、より確実です。正確に旋回したいなら、[ジャイロ](/docs/programming/sensors/imu/)がさらに適しています。
