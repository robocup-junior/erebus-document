地図ボーナス（Map bonus）はスコアを最大 2.2 倍にするので、とても価値があります。次の手順で獲得できます。

1. [地図作成のルール](/docs/rules/mapping/)で説明しているように、地図を配列に入れます
1. 配列のサイズを送り、続けて、配列をカンマ区切りで平坦化し UTF-8 でエンコードしたものを送ります
1. 地図評価リクエスト `M` を送ります
1. ゲームを終了します。ゲーム終了時に、Erebus がスコアにボーナスを適用します

## 知っておくこと \{#things-to-know\}

- 地図はゲーム中いつでも提出できますが、**評価されるのは 1 回だけ** です。2 回目以降の `M` メッセージは無視されるので、地図がこれ以上完成しないところまで来たら送りましょう。
- 時間が残っていることを確認してください。`M` を送る前にゲームが終わると、評価する地図がありません。
- ボーナスを得るために `E` を送る必要はありません。時間切れになった場合もボーナスは適用されます。ただし、脱出ボーナス（Exit bonus）を得るには `E` を送る必要があり、脱出ボーナスは地図ボーナスが適用される前に加算されます。
- 地図にはスタートタイル（`5`）が含まれている必要があります。スタートタイルは、地図を正解に合わせるために使われます。スタートタイルがないと、地図を評価できません。
- 結果は、コントロールウィンドウの履歴に `Map Correctness` として表示されます。Webots のコンソールに `Map scoring error` と表示された場合は、形式を確認してください。

次の例は `world1.wbt` の正解を送ります。通信のコードを確認するのに便利です。ゲームの最初から実行すると、すぐにゲームが終了します。倍率を掛ける対象がないので、スコアは 0 のままです。
