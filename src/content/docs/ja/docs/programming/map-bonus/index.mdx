地図ボーナス（Mapping bonus）はスコアを最大 2.2 倍にするので、とても価値があります。獲得する手順は次のとおりです。

1. [地図作成のルール](/docs/rules/mapping/)で説明しているように、地図を配列に入れます。
1. 配列のサイズを送り、続けて、配列を平坦化してカンマ区切りの UTF-8 テキストにしたものを送ります。
1. `M` を送って、地図の評価を要求します。
1. ゲームを終了します。ゲーム終了時に、Erebus がスコアにボーナスを適用します。

## 知っておくこと \{#things-to-know\}

- 地図はゲーム中いつでも提出できますが、**評価されるのは 1 回だけ** です。2 回目以降の `M` メッセージは無視されるので、地図をできるだけ完成させてから送りましょう。
- 時間が残っていることを確認してください。`M` を送る前にゲームが終わると、評価する地図がありません。
- ボーナスを得るために `E` を送る必要はありません。時間切れになった場合もボーナスは適用されます。ただし、脱出ボーナス（Exit bonus）を得るには `E` を送る必要があり、脱出ボーナスは地図ボーナスが適用される前に加算されます。
- 地図にはスタートタイル（`5`）が含まれている必要があります。スタートタイルは、地図を正解に合わせるために使われます。スタートタイルがないと、地図を評価できません。
- 結果は、コントロールウィンドウの試合のイベントに `Map Correctness` として表示されます。Webots のコンソールに `Map scoring error` と表示された場合は、形式を確認してください。

次の例は `world1.wbt` の正解を送ります。通信のコードを確認するのに便利です。ゲーム開始直後に実行するとすぐにゲームが終了し、倍率を掛ける対象がないので、スコアは 0 のままです。

## 地図を確認する \{#reviewing-your-map\}
コントロールウィンドウの **Save map** を押すと、地図がどのように採点されたかを確認できます。Erebus は結果を `match-results` にある試合の `map` フォルダーに保存し、ブラウザーで開きます。**Advanced setup** の **Automatic map result** を使うと、地図が評価されたらすぐに開きます。

![例の地図の確認: すべてのセルが正しい](../../../../docs/programming/map-bonus/map-review.png)

間違ったセルは赤く表示されます。セルをクリックすると、ロボットが送った値と正しい答えがわかります。**Save matrix** はロボットが送った地図を保存し、**Save PNG** は画像を保存します。

Erebus リリースの `player_controllers` フォルダーにある例 `MapScorerExample.py` も、同じように動作します。
