## ロボットがすべきこと \{#what-the-robot-has-to-do\}
得点の大部分は壁のトークン（Wall tokens）から得られ、誤った報告は 1 回ごとに 5 点の減点になります。そのため、見つけたトークンごとに、次のどれにあたるかを判断する必要があります。

| トークンの種類 | すべきこと |
|---|---|
| 文字の被災者（Letter victim）（Φ、Ψ、Ω） | `H`、`S`、`U` のいずれかを報告する |
| 偽の被災者（Fake victim）（同じ記号で立体的なもの） | 報告せず、地図にも含めない |
| 合計が 0 〜 3 のコグニティブターゲット（Cognitive target） | `F`、`P`、`C`、`O` のいずれかを報告する |
| 合計がそれ以外のコグニティブターゲット | 偽物です。報告せず、地図にも含めない |

正確な定義は[ルール](/docs/rules/#wall-tokens)を、報告の送り方は[通信](/docs/programming/communication/#scoring-wall-tokens)を参照してください。

## カメラに写るもの \{#what-the-camera-sees\}
スターターロボットのカメラは 64 × 40 ピクセルです。この解像度では、ロボットが近づくまでトークンは数ピクセルにしか写らないので、遠くから候補を探し、近づいてから読み取るのがよいでしょう。報告するにはロボットがトークンからタイル半分以内にいる必要があること、そしてカスタムのカメラはコストをかければ解像度を上げられることを覚えておきましょう。

![64 × 40 のカメラで見たコグニティブターゲット](../../../../docs/programming/wall-tokens/camera_target.png)


文字の被災者は白い正方形の上の黒い記号で、どの角度にも回転していることがあるので、向きに依存しない方法にする必要があります。

![シミュレーター内の壁にある文字の被災者](../../../../docs/programming/wall-tokens/letter_victim.png)


## コグニティブターゲットを読み取る \{#reading-a-cognitive-target\}
コグニティブターゲットは 5 つの同心円の部分でできているので、形を認識する必要はありません。中心と外側の半径がわかれば、各部分の中央の色をサンプリングできます。各部分の半径は 0.5、1、1.5、2、2.5 cm なので、それぞれの中央の点は外側の半径の 0、0.3、0.5、0.7、0.9 の位置にあります。

次の関数は、Python の OpenCV でこれを行います。中心と半径を見つけるには、たとえば[迷路を進む](/docs/programming/navigate-the-maze/)のように、ターゲットの輪郭を使えます。

<CodeTabs file="readRings" />

実際の走行では、ターゲットを斜めから見ることがあり、その場合は楕円に見えます。ターゲットの正面に回る、おかしく見える色を警告として扱う、複数のフレームを読み取る、といった工夫で結果の信頼性が上がります。

## 種類を計算する \{#calculating-the-type\}
5 つの色がわかれば、報告するコードはその合計から決まります。隣り合う色が同じでも、5 つの部分はそれぞれ必ず数えます。

<CodeTabs file="targetCode" />

たとえば、`['Y', 'B', 'R', 'K', 'G']` の合計は 0 なので `F` になり、`['B', 'Y', 'K', 'K', 'K']` の合計は -4 なので偽物です。

## 偽の被災者を見分ける \{#detecting-fake-victims\}
偽の被災者（Fake victims）は本物と同じ記号ですが、文字が立体的になっています。正面からでは、カメラだけでは見分けられないことがあります。

![正面から見た偽の被災者](../../../../docs/programming/wall-tokens/fake_victim_front.png)


ルールでは、奥行きは Robot Customizer で使えるセンサーのいずれかで検出できるとされています。試してみるとよいアイデアをいくつか紹介します。

- LiDAR や距離センサーでトークンをまたいで測った距離を比べ、高さの差を探す。
- トークンを斜めから見る。凹凸があると記号の形が変わります。

ワールド `world3.wbt` と `world4.wbt` には偽の被災者が含まれていて、[World Editor](/docs/tools/world-editor/#victims-and-cognitive-targets) で自作のマップに追加することもできます。Erebus には、既存のワールドの被災者をランダムに偽物に変えるスクリプト `scripts/update_maps_with_fakes.py` も含まれています。

偽物を報告すると誤識別として 5 点の減点になりますが、エリア 1 のリニアタイルにいる本物の被災者は、種類まで正しければ 15 点になり、ほかのエリアではさらに高くなります。報告する前にロボットがどのくらい確信している必要があるかを決めるときは、このことを考えに入れましょう。
