## 背景 {#background}

ロボットが付属のマップや簡単な迷路を走れるようになったら、もっと難しいものに挑戦したくなったり、付属のマップにはない特定の状況をテストしたくなったりするでしょう。
そんなときは、オンラインの [Erebus World Editor](https://world.erebus.rcj.cloud/) を使います。ブラウザーでマップを描くと、Erebus で実行できる `.wbt` ワールドファイルとして書き出せます。

![World Editor で完成したマップ](../../../../docs/tools/world-editor/overview.png)

テスト用の小さなマップを作るだけなら、フィールドがルールどおりかどうかはそれほど重要ではありません。しかし、競技用のフィールドを作るつもりなら、公式の[シミュレーションルール](https://junior.robocup.org/wp-content/uploads/2026/09/RCJRescueSimulation2027-draft.pdf)を読んでおきましょう。エディターは、作業中にマップがルールに合っているかをチェックしてくれます。

エディターにはガイドが組み込まれています。右下の **Guide** を押すと、サンプルマップを作る実践レッスン（約 15 分）、画面のツアー、Room 4 のレッスンを選べます。その横でエディターの言語を変更できます。

## マップを始める {#starting-a-map}
エディターを開いたら、従う**年のルール**を選び、**New map** を押します。**Erebus v27 には 2027 年のルールを選んでください。** 2026 年のルールは Erebus v26 用です。地図のルールは、後から上部バーで変更できます。

![World Editor のスタート画面](../../../../docs/tools/world-editor/start.png)

作業内容はブラウザーに保存されますが、別のブラウザーでは見られず、閲覧データを消去すると失われます。大切なマップは、上部バーの保存ボタンで JSON として保存し、開くボタンで開き直しましょう。

作業の順番は、サイズと外形、部屋、通路、壁、床、障害物と被災者、Room 4、最後にチェックと書き出し、がおすすめです。ツールは左側にあり、それぞれキーボードショートカットがあります。選んだツールの設定は、その横のパネルに表示されます。

| ツール | キー | 用途 |
|---|---|---|
| Select | `S` | マップの一部を選択、移動、コピー、貼り付けする |
| Move | `H` | 表示を移動する |
| Outline | `X` | マップのサイズと形を設定する |
| Rooms | `M` | Room 1 〜 4（ルールでいうエリア）を塗る |
| Passages | `P` | 部屋どうしを通路でつなぐ |
| Line | `L` | 壁を描く |
| Curve | `A` | Room 3 に曲がった壁を描く |
| Eraser | `E` | 壁、床、障害物、被災者を削除する |
| Floor | `F` | チェックポイント、穴、沼地、コンタクトタイル、スタートタイルを設定する |
| Obstacle | `O` | 障害物を置く |
| Victims | `V` | スマイリーの被災者、コグニティブターゲット、偽物を置く |

マウスホイールでズームし、Space キーを押しながらドラッグすると表示を移動できます。元に戻すのは `⌘Z` または `Ctrl+Z` です。

## サイズと外形 {#size-and-outline}
**Outline** ツールで、マップのサイズをタイル単位で設定します。外側の壁は自動で付きます。**Outline (uneven)** では、タイルをクリックしてマップから外せます。また、クリックした位置に行や列を挿入したり削除したりもできます。

![Outline ツール](../../../../docs/tools/world-editor/outline.png)

## 部屋と通路 {#rooms-and-passages}
**Rooms** ツールで、各部屋のタイルを塗ります。部屋と部屋の境界には、自動で壁が立ちます。次に、**Passages** ツールで部屋どうしをつなぎます。各通路の色は、つなぐ部屋に応じて選ばれます。

![Rooms ツール](../../../../docs/tools/world-editor/rooms.png)

![Passages ツール](../../../../docs/tools/world-editor/passages.png)

## 壁 {#walls}
**Line** ツールで壁を描きます。Room 1 ではタイルの辺に、Room 2 と 3 では 4 分の 1 タイルの辺に描きます。Room 3 では **Curve** ツールを使い、タイルの 4 分の 1 の部分を指して曲線を選びます。同じものをもう一度クリックすると削除されます。

![壁を描く Line ツール](../../../../docs/tools/world-editor/walls.png)

## 床と障害物 {#floors-and-obstacles}
**Floor** ツールで床の種類を選び、タイルをクリックして設定します: チェックポイント、穴、沼地、コンタクトタイル、スタート。スタートタイルはルーム 1 のタイルでなければならず、スタートタイルがないとワールドを書き出せません。1 つのタイルは、穴、沼地、チェックポイント、コンタクトタイル、障害物、スタート、通路のうち 1 つにしかなれません。

![Floor ツール](../../../../docs/tools/world-editor/floors.png)

**Obstacle** ツールで形を選び、タイルをクリックします。Room 1 〜 3 では、タイル 1 つにつき障害物は 1 つで、その中心はタイルの上にあります。障害物をクリックすると、ハンドルとパネルでサイズ、高さ、色、回転を変更できます。

![Obstacle ツール](../../../../docs/tools/world-editor/obstacles.png)

## 被災者とコグニティブターゲット {#victims-and-cognitive-targets}
**Victims** ツールで種類を選び、壁の近くをクリックします。次のものを置けます。

- 本物のスマイリーの被災者: 負傷、安定、無傷
- 立体的な顔の偽物のスマイリーの被災者
- コグニティブターゲット: 危険物の種類を選び、必要ならリングの色も選びます。合計が表示され、それによって種類が決まります
- 偽のターゲット: リングの合計が 0 〜 3 以外になるもの

Room 1 では、タイルの各辺に被災者を 1 つ置けます。Room 2 と 3 では 6 cm の壁の面に置き、曲線には内側と外側の 2 か所があります。**Turn** で、固定の回転か、新しいトークンごとにランダムな回転かを選びます。置いたトークンをクリックすると変更や削除ができ、ドラッグすると壁に沿って動かせます。

![Victims ツール](../../../../docs/tools/world-editor/victims.png)

## Room 4 {#room-4}
Room 4 はタイルにもとづいていないので、絵として描きます。**Rooms** ツールで Room 4 を塗り、**Draw room 4** を押す（または部屋をダブルクリックする）と、Room 4 の作成画面が開きます。

![Room 4 の作成画面](../../../../docs/tools/world-editor/room4.png)

黒で描いたものが壁になります。作成画面には、フリーハンドで描くツール、直線・曲線・円弧・長方形・楕円・多角形・アイコンの形を描くツール、被災者と障害物のツールがあります。Room 4 には障害物をいくつでも置けます。赤い縞模様はロボットが到達できない場所を示します。ロボットが通り抜けられるよう、タイル 1 枚分ほどの幅を空けておく必要があります。

完成したら **OK** を押します。絵がマップ上に Room 4 として表示され、書き出したワールドに含まれます。作成画面の右上のボタンで、絵を PNG として保存して別のマップで同じ Room 4 を使ったり、PNG や JPEG の画像を開いたりできます。

## マップをチェックする {#checking-your-map}
変更するたびに、右上の **Checks** カードでルールに照らしたチェックが行われます。赤い ✕ はワールドの書き出しを妨げる問題で、黄色い ! は確認したほうがよい警告です。項目をクリックすると、その場所に移動します。**Fix** は 1 つの項目を、**Fix all that can be fixed** は修正できるものすべてを修正します。

![World Editor の新しいマップと Checks カード](../../../../docs/tools/world-editor/new_map.png)

上部バーの **Linear** ボタンを押すと、各タイルがリニアタイルかフローティングタイルかで色分けされます。これによってトークンの得点が決まります。

![マップ上に表示されたリニアタイルとフローティングタイル](../../../../docs/tools/world-editor/linear.png)

上部バーのトロフィーは、得点ルールで計算したマップの **最大スコア** を、各部屋の内訳や、脱出ボーナスと地図ボーナスを含めたスコアとともに表示します。

![マップの最大スコア](../../../../docs/tools/world-editor/max_score.png)

## ワールドを書き出して実行する {#exporting-and-running-your-world}
上部バーでマップの名前を設定し、右上の **.wbt** ボタンを押します。続いて、次の手順を行います。

1. `.wbt` ファイルを Erebus の `game/worlds` フォルダーにコピーします。ワールドは Erebus のファイルを使うので、必ずこのフォルダーに置いてください。
1. Webots で開くか、[コントロールウィンドウ](/docs/getting-started/)の **Worlds** ボタンで選びます。

![Erebus v27 で実行している、エディターのガイドのサンプルマップ](../../../../docs/tools/world-editor/exported_world.png)

*Erebus v27 で実行している、エディターのガイドのサンプルマップ。*

`.wbt` ファイルは編集可能なマップに戻せないので、JSON も保存しておきましょう。
