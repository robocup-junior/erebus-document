<Steps>

1. ターミナルを開き、pip と必要なライブラリをインストールします。

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   Ubuntu 24.04 では、pip がシステムの Python へのライブラリのインストールを `externally-managed-environment` エラーで拒否します。2 つ目のコマンドに `--break-system-packages` を付けるか、[仮想環境](https://docs.python.org/3/library/venv.html)にライブラリをインストールして、その Python を Webots の設定で指定してください。

2. **Webots R2025a** をダウンロードしてインストールします。

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. <DownloadErebus /> をダウンロードして展開します。

</Steps>

## 環境を起動する \{#run-the-environment\}

ターミナルからワールドを開きます。パスは自分の Erebus フォルダーに合わせて変更してください。

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots が、Web ブラウザーで Erebus のコントロールウィンドウを開きます。初回は Erebus がいくつかの Python ライブラリをインストールし、ロボットモデルを準備するので、少し時間がかかることがあります。ウィンドウに **Ready** と 08:00 のゲームタイマーが表示されたら準備完了です。

![開始準備ができた Erebus のコントロールウィンドウ](../../../../docs/installation/linux/../control-window-ready.png)

初回は、Webots のコンソールに `ERROR: Skipped PROTO 'custom_robot'` と表示されることもあります。これは無視してかまいません。Erebus がロボットモデルを準備して、自動でワールドを再読み込みします。

次は[ルールの概要](/docs/rules/)を読んで、ゲームを理解しましょう。うまくいかないときは[トラブルシューティング](/docs/troubleshooting/)を見てください。
