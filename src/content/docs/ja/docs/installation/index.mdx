## 必要なソフトウェア \{#software-requirements\}
シミュレーションシステムは 3 つの構成要素でできていて、それぞれをインストールする必要があります。インストールは簡単ですが、Webots のダウンロードとインストールには少し時間がかかることがあります。3 つの構成要素は次のとおりです。

1. Webots ロボットシミュレーター（バージョン **R2025a**）: シミュレーション環境です。Erebus v27 は、ほかのバージョンの Webots には対応していません。
1. Erebus: ワールドと、ルールを適用して得点を計算する Main Supervisor です。最新バージョンは **v<span data-erebus-version>{latestVersion}</span>** です。
1. Python（バージョン **3.10 以降**）: Erebus 自体の実行と、ロボットのコントローラーを書くのに必要です。コントローラーは C/C++ でも書けます。

## 最小システム要件 \{#minimum-system-requirements\}
* Linux: Ubuntu 22.04 LTS または 24.04 LTS
* Windows: Windows 10 または 11（64 ビット）
* macOS: macOS 12「Monterey」、13「Ventura」または 14「Sonoma」。これらは Webots R2025a が対応しているバージョンです。より新しい macOS でも動作することがあり、このドキュメントは macOS 26 でテストしています。
* CPU: デュアルコア、2 GHz
* RAM: 2 GB
* グラフィックス: OpenGL 3.3 に対応し、512 MB のメモリーを搭載した NVIDIA または AMD のグラフィックスカード

## Python ライブラリ \{#python-libraries\}
Erebus には、以下の Python ライブラリが必要です。ほとんどは起動時に自動でインストールされますが、**OpenCV はインストールされない** ので、自分でインストールする必要があります。各 OS のガイドにはこの手順が含まれています。 Erebus フォルダーの `requirements.txt` には、Erebus のテストに使われたバージョンが書かれています。

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```

## オプション：Wireshark \{#optional-wireshark\}
Erebus は、試合中にゲームへの不正なアクセスがないかネットワークを監視できます。これは大会で運営者が使う機能で、[Wireshark](https://www.wireshark.org/download.html) が必要です。練習には必要ありません。Wireshark がない場合、コントロールウィンドウにネットワークアクセスが監視されていないという警告が出ますが、確認して無視してかまいません。
