---
title: v26 の新機能
description: Erebus v26 と 2026 年ルールの変更点のうち、ロボットに影響するものです。
---

Erebus v26 は 2026 年ルールを実装しています。以前のバージョンから移行する場合、ロボットに影響する変更点は次のとおりです。

| 項目 | 2025 年まで | 2026 年から |
|---|---|---|
| 文字の被災者（Letter victims） | 文字 H、S、U | 記号 Φ（harmed、負傷）、Ψ（stable、安定）、Ω（unharmed、無傷）。報告はこれまでどおり `H`、`S`、`U` で行います。 |
| 危険物標識（Hazmat signs） | 4 種類の危険物ラベル | [コグニティブターゲット](/docs/rules/#cognitive-targets)に置き換え: 色付きの同心リングで、その値の合計が種類を表します。報告はこれまでどおり `F`、`P`、`C`、`O` で行います。 |
| 偽のトークン | - | 新規: 立体的な文字の[偽の被災者](/docs/rules/#fake-victims)と、合計が 0 〜 3 にならないコグニティブターゲット。報告も地図への記入もしないでください。 |
| 沼地 | 時間の消費が 5 倍速 | 沼地への最初の進入で x5、同じ沼地に入り直すたびに 1 ずつ上がり、最大 x10。 |
| 地図上の障害物 | 地図に記入しない | 障害物のあるタイルは `x` として地図に記入します。 |
| 地図ボーナス | 最大 x2 | 倍率は 正確さ × 1.2 + 1 になりました。 |
| センサーのノイズ | - | GPS にノイズがあります。競技でも運営者はノイズのレベルを変更しません。 |
| ゲームの実行 | イベントごとに告知 | サーバー・クライアント構成: コントローラーは自分のコンピューターで実行し、イーサネットでゲームサーバーに接続します。[Remote Controller](/docs/competition/remote-controller/) を参照してください。 |
| 提出書類 | TDP、ポスター、ビデオ | それに加えて、サーバー・クライアント構成でコントローラーを実行する様子を示した短いビデオ。 |
| 欠場したゲーム | -50 点 | 0 点。 |

Webots のバージョンは変わっていません。Erebus v26 も引き続き Webots **R2023b** で動作します。

v26.0.0 の後にリリースされた 2 つのバージョンでは、ルールは変わっていません。v26.0.1 では、偽の被災者を含むサンプルワールドと、既存のワールドの被災者を偽物に変換するスクリプトが追加されました。v26.1 では、エリア 4 での障害物のマークのしかたが修正されました。

## プログラムを更新する {#updating-your-program}

1. 被災者の検出を新しい記号に対応させます。報告する文字は変わりません。
2. 危険物標識の検出を、[コグニティブターゲットの読み取り](/docs/programming/wall-tokens/#reading-a-cognitive-target)に置き換えます。
3. プログラムが偽物を報告せず、地図にも含めないようにします。
4. 障害物を `x` として地図に追加します。
5. 新しい沼地のルールを考慮してルートを計画します。ロボットが同じ沼地に入るたびに、より多くの時間がかかります。
6. [サーバー・クライアント構成](/docs/competition/remote-controller/)を練習します。
