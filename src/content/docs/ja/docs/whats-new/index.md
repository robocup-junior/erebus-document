title: v27 の新機能
description: Erebus v27 と 2027 年ルールの変更点のうち、ロボットに影響するものです。
---

Erebus v27 は 2027 年ルールを実装しています。v26 から移行する場合、ロボットに影響する変更点は次のとおりです。

| 項目 | 2026 年まで | 2027 年から |
|---|---|---|
| バッテリー | - | 新規: ロボットには、モーターの速さに応じて減る[バッテリー](/docs/rules/#the-battery)があります。切れるとゲームは終わります。 |
| コンタクトタイル | - | 新規: シアンの[コンタクトタイル](/docs/rules/#contact-tiles)。上で 5 秒間止まるとバッテリーが交換されます。地図では `k` で表します。 |
| 沼地 | ゲーム時間が速く進む: 最初の進入で x5、最大 x10 | バッテリーが速く減ります。ゲーム時間には影響しません。 |
| 被災者 | 記号 Φ、Ψ、Ω | [スマイリーの顔](/docs/rules/#smiley-victims): 悲しい顔（負傷）、普通の顔（安定）、笑顔（無傷）。報告するコードは今までどおり `H`、`S`、`U` です。 |
| 偽物の被災者 | 立体的な記号 | 立体的なスマイリーの顔 |
| ゲーム情報 | `G` の返信は 16 バイト | `G` の返信は 20 バイトで、最後にバッテリー残量が入ります。[ゲーム情報](/docs/programming/communication/#game-information)を参照してください。 |
| 報告できる距離 | Erebus v26 はトークンから 9 cm までの報告を受け付けていました | ルールのとおり、タイル半分（6 cm） |
| エリア | 4 つのエリア、エリア 4 は任意 | 最大 4 つのエリア: エリア 1 は必ずあり、運営者はエリア 2 から 4 を省くことがあります |
| Webots | R2023b | **R2025a** |
| Python | 3.9 以降 | 3.10 以降 |

Erebus v27 のコントロールウィンドウの使い方は、[初めての実行](/docs/getting-started/)で説明しています。

## プログラムを更新する {#updating-your-program}

1. `G` の返信を 20 バイトとして読みます。16 バイトしか受け付けないプログラムは、ゲーム情報を受け取れなくなります。
1. バッテリー残量を見て、バッテリーが切れる前にコンタクトタイルに着けるようにルートを計画します。[バッテリー](/docs/programming/battery/)を参照してください。
1. コンタクトタイルを `k` として地図に加えます。
1. 被災者の検出をスマイリーの顔に合わせて更新します。報告する文字は変わりません。
1. トークンにもっと近づいて報告します。ロボットの中心と、送る位置の両方が、トークンからタイル半分以内でなければなりません。
1. 沼地は時間ではなくバッテリーを消費するようになったので、バッテリーの計画に入れます。
1. Webots R2025a と Python 3.10 以降をインストールし、プログラムが動くか確認します。[インストール](/docs/installation/)を参照してください。
