---
title: 用語集
description: Erebus とルールで使われる用語です。
---

| 用語 | 意味 |
|---|---|
| **エリア（Area）** | フィールドを構成する 4 つの部分の 1 つで、それぞれ独自の種類の壁があります。World Editor では部屋（room）と呼びます。 |
| **エリア倍率（Area multiplier, AM）** | 1、1.25、1.5、2 のいずれかで、各エリアの得点に掛けられます |
| **バッテリー（Battery）** | モーターの速さに応じて減ります。切れるとゲームは終わります。 |
| **チェックポイント（Checkpoint）** | 銀色のタイルです。競技進行停止の後、ロボットは最後に訪れたチェックポイントに戻ります。 |
| **コグニティブターゲット（Cognitive target）** | 5 色の同心円でできた壁のトークンで、その合計が危険物の種類を表します。2026 年に危険物標識に代わって導入されました。 |
| **コンタクトタイル（Contact tile）** | シアンのタイル。ロボットが上で 5 秒間止まっていると、バッテリーが交換されます |
| **コントロールウィンドウ（Control window）** | プログラムを読み込み、ゲームを実行する Web ページです。ロボットウィンドウとも呼びます。 |
| **コントローラー（Controller）** | あなたのプログラムです |
| **カスタムロボット（Custom robot）** | Robot Customizer で設計し、`.json` ファイルから読み込むロボットです |
| **脱出ボーナス（Exit bonus, EB）** | スタートタイルに戻って `E` を送ると得られる +10% です |
| **偽物（Fake）** | 報告してはいけないトークンです。立体的なスマイリーの被災者と、合計が無効なコグニティブターゲットがあります |
| **フローティングタイル（Floating tile）** | スタートにつながる壁をたどっても到達できないタイルです。ここにあるトークンは得点が高くなります。 |
| **競技進行停止（Lack of progress, LoP）** | ロボットが動けなくなったり、穴に落ちたりしたときです。ロボットは最後のチェックポイントに戻り、5 点を失います。 |
| **リニアタイル（Linear tile）** | スタートにつながる壁をたどって到達できるタイルです |
| **Main Supervisor** | ゲームを管理する Erebus の部分です。スーパーバイザーやゲームマネージャーとも呼びます。 |
| **地図ボーナス（Mapping bonus, MB）** | 正確さ × 1.2 + 1 のスコア倍率です |
| **地図行列（Map matrix）** | 地図を表す配列です |
| **通路（Passage）** | 2 つのエリアをつなぐ色付きのタイルです |
| **4 分の 1 タイル（Quarter tile）** | タイルの 4 分の 1 の大きさで幅 6 cm、エリア 2 と 3 で使われます |
| **サーバー・クライアント構成（Server-client setup）** | ゲームを 1 台のコンピューターで、プログラムを別のコンピューターで実行します。Remote Controller を参照してください。 |
| **スマイリーの被災者（Smiley victim）** | 悲しい顔、普通の顔、笑顔のいずれかの壁のトークン。2027 年に文字の被災者に代わって導入されました。 |
| **沼地（Swamp）** | バッテリーが速く減る茶色のタイル |
| **TDP** | Technical Description Paper（技術説明書） |
| **タイル（Tile）** | フィールドの単位で、幅 12 cm です |
| **TI、TT、CN、TMI** | 得点計算での、トークンの識別、トークンの種類、チェックポイントの通過、トークンの誤識別 |
| **壁のトークン（Wall token）** | 壁にある識別すべきもの。スマイリーの被災者とコグニティブターゲットです |
| **ワールド（World）** | `.wbt` ファイル形式のマップです |
