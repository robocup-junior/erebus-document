## フィールド {#field}

| パラメーター | 値 |
|---|---|
| タイル | 12 cm × 12 cm |
| 4 分の 1 タイル（エリア 2 と 3） | 6 cm × 6 cm |
| 壁 | 厚さ 1 cm、高さ 6 cm |
| スマイリーの被災者 | 2 cm × 2 cm |
| コグニティブターゲット | 直径 5 cm |

## ゲーム {#game}

| パラメーター | 値 |
|---|---|
| ゲーム時間 | シミュレーション時間で 8 分 |
| 実時間 | 10 分 |
| 自動の競技進行停止 | 同じ場所に 20 秒とどまった後 |
| 壁のトークンを報告するための停止時間 | 1 秒以上 |
| 壁のトークンを報告できる距離 | タイル半分（6 cm）。ロボットの中心と送る位置の両方 |
| バッテリー | 開始時は 100%。車輪の速さに応じて減り、2 つの車輪が全速力のときは 1 秒あたり約 1.25% |
| 沼地でのバッテリー | 5 倍速く減る |
| バッテリーの交換 | コンタクトタイルの上で 5 秒間止まる |
| エリア倍率 | エリア 1、2、3、4 でそれぞれ 1、1.25、1.5、2 |
| 脱出ボーナス | +10% |
| 地図ボーナスの倍率 | 正確さ × 1.2 + 1 |

## ロボット {#robot}

| パラメーター | 値 |
|---|---|
| 予算 | 3000 |
| カメラの最大数 | 3 |
| 距離センサーの最大数 | 8 |
| 距離センサーの範囲 | 0 〜 0.8 m |
| GPS の精度 | 0.0025 m |
| 車輪の最大速度 | 6.28 rad/s |
| LiDAR | 1 レイヤーあたり 512 点、4 レイヤー、0.01 〜 1 m |

`timeStep` は、センサーが更新される間隔をミリ秒で設定します。`int(robot.getBasicTimeStep())` でワールドの基本タイムステップを取得できます。Erebus v27 のワールドでは 16 ms です。

## スターターロボットのデバイス名 {#device-names-of-the-starter-robot}

[スターターロボット](/docs/robot/)で `robot.getDevice()` に渡す名前です。自作のロボットでは、[Robot Customizer](/docs/robot/customizer/#components) で名前を決めます。エミッターとレシーバーはいつでも使えます。

| デバイス | 名前 |
|---|---|
| 車輪のモーター | `left wheel motor`、`right wheel motor` |
| 車輪のエンコーダー | `left wheel sensor`、`right wheel sensor` |
| 距離センサー | `leftDist`、`frontDist`、`rightDist` |
| カメラ | `camera` |
| カラーセンサー | `color` |
| GPS | `gps` |
| ジャイロスコープ | `gyro` |
| 加速度センサー | `accelerometer` |
| LiDAR | `lidar` |
| エミッター | `emitter` |
| レシーバー | `receiver` |
