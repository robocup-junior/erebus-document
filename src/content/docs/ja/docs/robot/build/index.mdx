このチュートリアルでは、[Robot Customizer](https://robot.erebus.rcj.cloud/) で[スターターロボット](/docs/robot/#the-starter-robot)を組み立てます。このドキュメントのすべての例で使うロボットなので、最後まで進めれば、プログラミングの準備がすべて整います。

コストは、予算 3000 のうち 2400 です。

:::tip
各構成要素には名前があり、プログラムはその名前で構成要素を見つけます。例が動くように、以下の名前をそのまま使ってください。
:::

## ロボットを設計する \{#design-the-robot\}

[Robot Customizer](https://robot.erebus.rcj.cloud/) を開きます。最初は、2 つの車輪と 4 つの距離センサーというデフォルトの部品が付いています。以前に使ったことがある場合は、上部のリセットボタンを押して最初からやり直してください。

入力欄には mm と書かれていますが、位置の単位は 0.1 ミリメートルです。ロボットの本体の半径は約 370 です。

<Steps>

1. **距離センサーを設定します。** **Distance sensors** で `−` を 1 回押して、3 つにします。次に、それぞれをクリックして開き、名前、位置、回転を設定します。

   | センサー | 名前 | X | Y | Z | 回転 |
   |---|---|---:|---:|---:|---|
   | Distance Sensor 1 | `leftDist` | -370 | 335 | 0 | Left |
   | Distance Sensor 2 | `frontDist` | 0 | 335 | -370 | Front |
   | Distance Sensor 3 | `rightDist` | 370 | 335 | 0 | Right |

   スライダーの横の入力欄に値を入力し、回転のボタンを押します。**Top** を押すと、前を上にしてロボットを上から見られるので、各センサーが正しい方向を向いているかを確認できます。

   ![上から見た 3 つの距離センサー。左、前、右を向いている](../../../../docs/robot/build/distance-sensors.png)

2. **車輪に名前を付けます。** ロボットの右側にある **Wheel 1** を開き、`right wheel` という名前にします。**Wheel 2** は `left wheel` にします。**In your controller** に表示されているとおり、プログラムではこれらを `right wheel motor` と `left wheel motor` として使います。

3. **カメラを追加します。** **Camera 1** をオンにして、次のように設定します。

   - 名前: `camera`
   - 解像度: 幅 **64px**、高さ **40px**
   - 位置: X `0`、Y `90`、Z `-370`
   - 回転: **Front**

   ![カメラの設定](../../../../docs/robot/build/camera.png)

4. **カラーセンサーを追加します。** **Colour sensor** をオンにして、次のように設定します。

   - 名前: `color`
   - 位置: X `0`、Y `-41`、Z `-370`
   - 回転: **Down**

   カラーセンサーは、床を見るために下を向いている必要があります。前方に付けると、車輪が穴に落ちる前にロボットが穴を見つけられます。

5. **GPS、ジャイロ、加速度センサーを追加します。** **GPS**、**Gyro**、**Accelerometer** をオンにします。デフォルトの名前 `gps`、`gyro`、`accelerometer` と、デフォルトの位置のままでかまいません。

6. **LiDAR を追加します。** **Lidar** をオンにして、次のように設定します。

   - 位置: X `0`、Y `370`、Z `0`
   - 回転: X `90`、Y `0`、Z `0` と入力

   LiDAR はロボットの上部に付ける必要があります。そうしないと本体にさえぎられます。また、周囲全体をスキャンするには水平になっている必要があります。回転のボタンでは水平にならないので、値を入力してください。

   ![LiDAR の設定](../../../../docs/robot/build/lidar.png)

7. **ロボットを確認します。** 右上の予算に **2,400 / 3,000 used** と表示されているはずです。**Labels** をオンにするとすべての名前が、**Camera view** をオンにするとカメラに写るものが見られます。

   ![ラベルとカメラビューを表示した、完成したロボット](../../../../docs/robot/build/finished.png)

8. **書き出します。** 上部のファイル名に `starter-robot` と入力し、**Export** を押します。`starter-robot.json` ファイルは保存しておきましょう。後で **Import** して、ロボットを変更できます。

</Steps>

うまくいかなかった場合は、完成したロボットと比べてみましょう。[`starter-robot.json` をダウンロード](/downloads/starter-robot.json)して、インポートしてください。
