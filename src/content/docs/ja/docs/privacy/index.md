このドキュメントは静的なウェブサイトです。アカウントはなく、個人情報を求めることもありません。

## アクセス解析 {#analytics}
このサイトでは、どのページが閲覧されているかを知ってページを改善するために、[Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) を使っています。Cookie を使わず、個々の訪問者を特定せずに訪問数を数えます。

## ブラウザーに保存される内容 {#what-is-stored-in-your-browser}
このサイトは、いくつかの設定をブラウザーに保存します。これらはどこにも送信されません。

- テーマ
- コード例で選んだ言語タブ

このサイトは Cookie を使用しません。
