このページは、2026 年ルールのもとでの世界大会向けのガイドです。地域大会やブロック大会では異なる場合があるので、運営者に確認してください。常に公式の[ルール](/docs/rules/)が適用されます。

## スケジュール {#timeline}

| 時期 | 内容 |
|---|---|
| 年間を通して | [イベントページ](/docs/events/upcoming-events/)と、ルールの明確化（Clarifications）が投稿される[フォーラム](https://junior.forum.robocup.org/)をチェックする |
| 4 週間以上前 | 運営者が、インタビュー準備のための Web フォームについて案内する |
| 初日の 3 週間前 | 書類の提出期限 |
| セットアップ日 | 受付、インタビュー、チームミーティングのため、早めに会場に到着する |
| 各ラウンド | ワールドはゲームの直前に公開されます。各ラウンドの締め切り後は、プログラムを変更できません。 |
| 得点走行の後 | テクニカルチャレンジ（Technical Challenge） |

## 提出する書類 {#documents-to-submit}
テンプレートと評価基準（ルーブリック）は [RCJ Rescue コミュニティサイト](https://rescue.rcj.cloud/)にあります。

- [ ] **技術説明書（Technical Description Paper, TDP）。** テンプレートに厳密に従ってください。従わない場合、書類の得点は 0 になります。
- [ ] **ポスター。** ファイルとして提出し、会場には A1 以下の実物のポスターを掲示します。
- [ ] プロジェクトを紹介する **ビデオ**。
- [ ] 2026 年からの新項目 **サーバー・クライアントビデオ**: サーバー・クライアント構成で、サンプルマップに対してコントローラーを実行する様子を示した短いビデオ。
- [ ] インタビュー用の **ソースコード** と **Web フォーム**。

## 競技の構成 {#competition-setup}
ゲームはサーバー・クライアント構成で実行されます。運営者がゲームサーバーを用意して RJ-45 ソケットを 1 つ提供し、プログラムは自分のコンピューターで実行します。[Remote Controller](/docs/competition/remote-controller/) を参照してください。

持ち物:

- [ ] プログラムと必要なライブラリ、Webots R2023b をすべてインストールしたコンピューター
- [ ] イーサネットケーブルと、必要であればコンピューター用のアダプター
- [ ] カスタムロボットを使う場合は、ロボットの `.json` ファイル
- [ ] 実物のポスター

## OpenGL の設定 {#opengl-settings}
運営者から別の発表がない限り、次の設定が使われます。カメラに写るものに影響するので、この設定でテストしてください。設定は Webots の Preferences の OpenGL タブにあります。

| 設定 | 値 |
|---|---|
| Ambient Occlusion | Low |
| Texture Quality | Low |
| Max Texture Filtering | 4 |
| Shadows | Disabled |
| Anti-aliasing | Disabled |

## ロボットのテスト {#testing-your-robot}
- [ ] 付属のすべてのワールドで実行する。特に、偽物を含む `world3.wbt` と `world4.wbt` は必ず試す。
- [ ] [World Editor](/docs/tools/world-editor/) で、4 つのエリアすべてを含む自作のマップを作る。
- [ ] ゲーム全体を確認する。最後まで動き、時間内に地図を提出してスタートに戻れるか？
- [ ] 競技進行停止の後にどうなるかをテストする。
- [ ] 持っていくコンピューターで、上記の OpenGL の設定でテストする。

## 競技中 {#during-the-competition}
- 審判から別の指示がない限り、競技エリアに入れるのはキャプテンと副キャプテンだけです。
- シミュレーションは審判が操作します。ゲームが始まったら、ゲーム用の機器に触れてはいけません。
- 競技中、メンターは手助けできません。
- 自分たちの取り組みを説明できるようにしておきましょう。チームの各メンバーが技術的な役割を持ち、そのしくみを理解しているべきです。

## 最終スコア {#final-score}
世界大会の最終スコアは、次の要素を組み合わせたものです。

| 要素 | 重み | 内容 |
|---|---|---|
| フィールドスコア | 0.6 | 正規化したフィールドスコアの平均。最も悪いラウンド（1 つまたは複数）は除外されます。 |
| ルーブリック | 0.2 | TDP（0.6）、ビデオ（0.2）、ポスター（0.2） |
| テクニカルチャレンジ | 0.2 | 競技会で発表されるミニ課題で、限られた時間内にロボットをプログラムし直して解きます |

同点の場合は、正規化したフィールドスコアの平均で順位を決めます。SuperTeam Challenge は別のイベントで、独自の賞があります。
