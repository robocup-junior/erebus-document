## 基本概念 {#general-idea}
建圖會以倍數的形式套用在比賽中獲得的總分上。要獲得地圖加成倍數，機器人必須把一個矩陣提交給比賽的 Main Supervisor（主監督程式）。提交的矩陣會與「標準答案」比較，算出正確率，而倍數是：

**地圖加成（Mapping bonus）倍數 = 正確率 × 1.2 + 1**

所以完美的地圖會讓你的分數乘以 2.2。如何傳送矩陣，請參閱[提交地圖教學](/docs/programming/map-bonus/)。

## 建圖規則 {#rules-for-mapping}
* 每個四分之一地塊（quarter tile），以及它周圍的邊和頂點，都以一個格子（值）表示。因此，W × H 個地塊的地圖是一個有 (4 × H + 1) 列和 (4 × W + 1) 行的矩陣。
* 世界中的每個元素以下列方式表示：

| 元素 | 值 |
|---|---|
| 牆壁 | `1` |
| 坑洞 | `2` |
| 沼澤 | `3` |
| 檢查點 | `4` |
| 起始地塊 | `5` |
| 有障礙物的地塊 | `x` |
| 區域 1 與 2 之間的通道（藍色） | `b` |
| 區域 1 與 3 之間的通道（黃色） | `y` |
| 區域 1 與 4 之間的通道（綠色） | `g` |
| 區域 2 與 3 之間的通道（紫色） | `p` |
| 區域 2 與 4 之間的通道（橘色） | `o` |
| 區域 3 與 4 之間的通道（紅色） | `r` |
| 牆上的標記 | 對應的代碼（`H`、`S`、`U`、`F`、`P`、`C`、`O`） |
| 區域 4 的所有地塊、邊和頂點，包括它的邊界 | `*` |
| 其他所有地塊、邊和頂點 | `0` |

* 地板元素（`2`、`3`、`4`、`5`、`x` 和通道）寫在每個四分之一地塊中央的四個格子上，如下方範例所示。
* 一個地塊不會同時是以下多種之一：沼澤、坑洞、檢查點、起始地塊、有障礙物的地塊，或區域通道。
* 對於區域 3 中的弧形牆，頂點應以 `0` 表示。
* 牆上的標記應標示在它所在牆壁的格子中。如果同一面牆上有好幾個牆上的標記（例如牆的兩側都有），請把它們的代碼串接在同一個格子中，依照它們在地圖上的絕對位置排序：先從上到下，再從左到右。
* 假標記不可以包含在地圖中：假受害者（fake victims）和總和無效的認知目標都不行。
* 完整地塊（非四分之一地塊）中的牆上標記可能位於牆上的任何位置。它們應該放在比較靠近的那個四分之一地塊的格子中；如果靠近地塊邊的中央，則放在中間的格子中。
* 只要旋轉角度是 90° 的倍數，地圖可以用任何方向儲存。Erebus 會利用起始地塊把你的矩陣與答案對齊，嘗試每一種方向，並保留最好的結果。

## 正確率如何計算 {#how-correctness-is-calculated}
1. 矩陣會以起始地塊為基準對齊。這表示**你的地圖必須包含起始地塊**。
1. 提交的矩陣或答案中，所有值不為零的位置都會被比較。如果值相符，正確數就加一；否則，錯誤數就加一。兩者都是 `0` 的位置會被忽略。
1. 正確率 = 正確數 / (正確數 + 錯誤數)。

因為只有上面有東西的位置才會計算，所以標示不存在的東西，和漏掉存在的東西一樣，都會降低你的正確率。

例外的是以下情況：牆的一側是一般的直角，另一側是弧形，這時的表示方式和兩側都是一般牆壁時相同。
