<Steps>

1. 開啟終端機，安裝 pip 和所需的函式庫：

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   在 Ubuntu 24.04 上，pip 會以 `externally-managed-environment` 錯誤拒絕把函式庫安裝到系統的 Python。請在第二個指令加上 `--break-system-packages`，或把函式庫安裝到[虛擬環境](https://docs.python.org/3/library/venv.html)中，並在 Webots 偏好設定裡設定它的 Python。

2. 下載並安裝 **Webots R2025a**：

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. 下載 <DownloadErebus />，然後解壓縮。

</Steps>

## 執行環境 \{#run-the-environment\}

從終端機開啟世界檔，並把路徑改成你的 Erebus 資料夾：

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots 會在你的網頁瀏覽器中開啟 Erebus 控制視窗。第一次執行時，Erebus 會安裝一些 Python 函式庫並準備機器人模型，可能需要一點時間。當視窗顯示 **Ready** 和 08:00 的比賽計時器時，就準備好了：

![Erebus 控制視窗，已準備好開始](../../../../docs/installation/linux/../control-window-ready.png)

第一次執行時，Webots 主控台還可能顯示 `ERROR: Skipped PROTO 'custom_robot'`。可以忽略它：Erebus 會準備好機器人模型，並自動重新載入世界。
