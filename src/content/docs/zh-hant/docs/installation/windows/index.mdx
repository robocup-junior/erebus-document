<Steps>

1. 從[官方網站](https://www.python.org/downloads/windows/)安裝 64 位元的 **Python 3.10 或更新版本**。安裝時，請務必將 Python 加入 PATH：

   ![Python 安裝程式中的 Add Python to PATH 選項](../../../../docs/installation/windows/python-path.png)

2. 開啟 PowerShell，安裝所需的函式庫：

   ```powershell
   python -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. 從[官方儲存庫](https://github.com/cyberbotics/webots/releases/download/R2025a/webots-R2025a_setup.exe)安裝 **Webots R2025a**。

4. 下載 <DownloadErebus />，然後解壓縮。

</Steps>

## 執行環境 \{#run-the-environment\}

雙擊世界檔 `game/worlds/world1.wbt`，在 Webots 中開啟它。

Webots 會在你的網頁瀏覽器中開啟 Erebus 控制視窗。第一次執行時，Erebus 會安裝一些 Python 函式庫並準備機器人模型，可能需要一點時間。當視窗顯示 **Ready** 和 08:00 的比賽計時器時，就準備好了：

![Erebus 控制視窗，已準備好開始](../../../../docs/installation/windows/../control-window-ready.png)

第一次執行時，Webots 主控台還可能顯示 `ERROR: Skipped PROTO 'custom_robot'`。可以忽略它：Erebus 會準備好機器人模型，並自動重新載入世界。

接下來，請閱讀[規則摘要](/docs/rules/)以了解比賽。如果發生問題，請參閱[疑難排解](/docs/troubleshooting/)。
