## 軟體需求 \{#software-requirements\}
模擬系統由三個元件組成，每一個都需要安裝。安裝很簡單，但下載和安裝 Webots 可能需要一段時間。這三個元件是：

1. Webots 機器人模擬器，**R2023b** 版：模擬環境。Erebus v26 不支援其他版本的 Webots。
1. Erebus：包含各個世界和 Main Supervisor（主監督程式），負責套用規則並計算分數。最新版本是 **v26.1**。
1. Python，**3.9 或更新版本**：執行 Erebus 本身，以及撰寫機器人控制器時都需要它。你也可以用 C/C++ 撰寫控制器。

## 最低系統需求 \{#minimum-system-requirements\}
* Linux：Ubuntu 20.04 LTS 或 22.04 LTS
* Windows：Windows 10 或 11，64 位元
* macOS：macOS 11「Big Sur」或 12「Monterey」。這些是 Webots R2023b 支援的版本。較新版本的 macOS 也可能可以運作：本文件已在 macOS 26 上測試過。
* CPU：雙核心，2 GHz
* RAM：2 GB
* 顯示卡：支援 OpenGL、具備 512 MB 記憶體的 NVIDIA 或 AMD 顯示卡

## Python 函式庫 \{#python-libraries\}
Erebus 需要以下的 Python 函式庫。其中大部分會在 Erebus 啟動時自動安裝，但 **OpenCV 不會**，所以你必須自己安裝。各作業系統的安裝指南都包含這個步驟。

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```
