Erebus 是一個機器人模擬比賽環境。你要設計一台機器人，並為它撰寫程式，讓它自主探索迷宮、找到並辨識牆上的標記、避開障礙物和陷阱、維持電池電量，並建立環境的地圖。

本文件介紹的是 **Erebus v27**，適用於 **RoboCupJunior Rescue Simulation 2027** 規則。其他支援的版本請參閱[版本](/docs/reference/versions/)。

## 學習路線 {#the-learning-path}
請依序完成這些步驟。每個步驟都建立在前一個步驟之上。

| 步驟 | 頁面 | 你將會…… |
|---|---|---|
| **開始** | [什麼是 Erebus？](/docs/introduction/)、[安裝](/docs/installation/) | 知道自己要做什麼，並安裝好所有東西 |
| **1. 比賽** | [規則摘要](/docs/rules/) | 了解任務、場地和計分方式 |
| **2. 你的機器人** | [取得機器人](/docs/robot/)、[組裝機器人](/docs/robot/build/) | 在 Erebus 中載入入門機器人 |
| **3. 首次執行** | [首次執行](/docs/getting-started/) | 看著你的機器人探索，並認識控制視窗 |
| **4. 程式設計基礎** | [第一個程式](/docs/programming/first-program/)、[移動](/docs/programming/movement/)、[感測器](/docs/programming/sensors/) | 讓你的機器人移動和感測 |
| **5. 進行比賽** | [迷宮導航](/docs/programming/navigate-the-maze/)、[通訊](/docs/programming/communication/)、[牆上的標記](/docs/programming/wall-tokens/)、[電池](/docs/programming/battery/)、[探索與建圖](/docs/programming/exploring/)、[地圖規則](/docs/rules/mapping/)、[提交地圖](/docs/programming/map-bonus/) | 用各種方式得分 |
| **6. 參加比賽** | [賽前準備](/docs/competition/)、[Remote Controller](/docs/competition/remote-controller/) | 做好參加比賽的準備 |

每個範例都使用[入門機器人](/docs/robot/)，所以執行前請先載入它。
