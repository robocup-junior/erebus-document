Erebus v27 實作了 2027 年規則。如果你是從 v26 過來的，以下是會影響你的機器人的變更。

| 主題 | 2026 年以前 | 2027 年起 |
|---|---|---|
| 電池 | - | 新增：機器人有一顆[電池](/docs/rules/#the-battery)，會依馬達的速度消耗。電池用完時比賽結束。 |
| 接觸地塊 | - | 新增：青色的[接觸地塊](/docs/rules/#contact-tiles)。在上面靜止 5 秒即可更換電池。在地圖中記為 `k`。 |
| 沼澤 | 比賽時間流逝更快：第一次進入為 x5，最多 x10 | 電池消耗更快。比賽時間不受影響。 |
| 受害者 | 符號 Φ、Ψ、Ω | [笑臉](/docs/rules/#smiley-victims)：難過（受傷）、平靜（穩定）和開心（未受傷）。回報時仍使用 `H`、`S`、`U`。 |
| 假受害者 | 立體的符號 | 立體的笑臉 |
| 比賽資訊 | `G` 的回覆為 16 位元組 | `G` 的回覆為 20 位元組，最後是電池電量。請參閱[比賽資訊](/docs/programming/communication/#game-information)。 |
| 回報距離 | Erebus v26 接受距離標記 9 cm 以內的回報 | 依規則為半個地塊（6 cm） |
| 區域 | 四個區域，區域 4 為選用 | 最多四個區域：區域 1 一定存在，主辦單位可以省略區域 2 到 4 |
| Webots | R2023b | **R2025a** |
| Python | 3.9 或更新版本 | 3.10 或更新版本 |

[第一次執行](/docs/getting-started/)說明了 Erebus v27 控制視窗的用法。

## 更新你的程式 {#updating-your-program}

1. 把 `G` 的回覆以 20 位元組讀取。只接受 16 位元組的程式將收不到比賽資訊。
1. 注意電池電量，規劃路線，讓機器人在電池用完之前到達接觸地塊。請參閱[電池](/docs/programming/battery/)。
1. 把接觸地塊以 `k` 加入地圖。
1. 把受害者辨識更新為笑臉。回報的字母不變。
1. 在更近的地方回報標記：機器人的中心和你傳送的位置都必須在離標記半個地塊以內。
1. 沼澤現在消耗的是電池而不是時間，請在電池計畫中考慮它們。
1. 安裝 Webots R2025a 和 Python 3.10 或更新版本，並檢查你的程式是否仍能執行。請參閱[安裝](/docs/installation/)。
