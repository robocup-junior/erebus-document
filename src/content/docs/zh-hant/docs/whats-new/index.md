Erebus v26 實作了 2026 年規則。如果你是從較早的版本升級，以下是會影響你的機器人的變更。

| 主題 | 到 2025 年為止 | 從 2026 年開始 |
|---|---|---|
| 字母受害者 | 字母 H、S、U | 符號 Φ（受傷）、Ψ（穩定）、Ω（未受傷）。回報時仍然使用 `H`、`S`、`U`。 |
| 危險物品標誌 | 四種危險物品標籤 | 由[認知目標](/docs/rules/#cognitive-targets)取代：同心的彩色圓環，數值加總後即為類型。回報時仍然使用 `F`、`P`、`C`、`O`。 |
| 假標記 | - | 新增：帶有立體字母的[假受害者](/docs/rules/#fake-victims)，以及總和不在 0 到 3 之間的認知目標。不要回報它們，也不要把它們畫進地圖。 |
| 沼澤 | 時間消耗快 5 倍 | 第一次進入沼澤為 x5，每次重新進入同一個沼澤加 1，最高 x10。 |
| 地圖上的障礙物 | 不畫入地圖 | 有障礙物的地塊以 `x` 畫入地圖。 |
| 地圖加成 | 最高 x2 | 倍數現在是正確率 × 1.2 + 1。 |
| 感測器雜訊 | - | GPS 有雜訊。主辦單位不會在比賽時改變雜訊程度。 |
| 比賽執行方式 | 依各活動公告 | 伺服器－用戶端架構：你的控制器在你自己的電腦上執行，透過乙太網路連接到比賽伺服器。請參閱 [Remote Controller](/docs/competition/remote-controller/)。 |
| 文件 | TDP、海報、影片 | 另外還需要一段短片，展示你如何在伺服器－用戶端架構中執行控制器。 |
| 未出賽的比賽 | -50 分 | 0 分。 |

Webots 版本沒有改變：Erebus v26 仍然在 Webots **R2023b** 上執行。

v26.0.0 之後發布的兩個版本沒有改變規則。v26.0.1 新增了含有假受害者的範例世界，以及一個把現有世界中的受害者轉換成假受害者的腳本；v26.1 則修正了區域 4 中障礙物的標示方式。

## 更新你的程式 {#updating-your-program}

1. 把受害者偵測更新為新的符號。你回報的字母不變。
2. 把危險物品標誌的偵測改為[讀取認知目標](/docs/programming/wall-tokens/#reading-a-cognitive-target)。
3. 確保你的程式不會回報假目標，並且不把它們畫進地圖。
4. 把障礙物以 `x` 加入地圖。
5. 規劃路線時考慮新的沼澤規則：機器人每次進入同一個沼澤，都會花費更多時間。
6. 練習[伺服器－用戶端架構](/docs/competition/remote-controller/)。
