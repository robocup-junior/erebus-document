本文件是一個靜態網站。它沒有帳號，也不會要求你提供任何個人資料。

## 流量分析 {#analytics}
本網站使用 [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) 了解哪些頁面被瀏覽，以便改善內容。它不使用 Cookie 統計瀏覽次數，也不會識別個別訪客。

## 儲存在瀏覽器中的資料 {#what-is-stored-in-your-browser}
本網站會在你的瀏覽器中儲存幾項設定，這些設定不會傳送到任何地方：

- 你的佈景主題
- 程式碼範例中所選的語言分頁

本網站不使用 Cookie。
