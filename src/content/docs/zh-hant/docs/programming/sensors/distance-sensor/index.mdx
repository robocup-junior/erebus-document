距離感測器會測量它正前方第一個物體的距離，單位是**公尺**，最遠 0.8 m。入門機器人有三個距離感測器：`leftDist`、`frontDist` 和 `rightDist`，分別朝向左方、前方和右方。

![從上方看到的三個距離感測器，分別朝向左方、前方和右方](../../../../../docs/robot/build/distance-sensors.png)

感測器是從它在機器人上的位置開始測量，而不是從機器人的中心。把機器人放在牆邊印出數值，再決定你自己的門檻值。
