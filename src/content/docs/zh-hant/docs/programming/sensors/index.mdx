感測器讓你的機器人了解周圍的世界。每種感測器的使用方式都一樣：

1. 用 `robot.getDevice()` 依名稱取得感測器。
2. 用 `enable(timeStep)` 啟用它。在啟用之前，它不會提供任何數值。
3. 在主迴圈中讀取它。每次執行 `robot.step()` 之後，數值都會更新。

和真實的感測器一樣，它們也有雜訊：同一個讀數在不同步之間可能會稍有變化。主辦單位不會在比賽時改變雜訊，所以請讓你的程式能夠應付雜訊，例如比較多次讀數。
