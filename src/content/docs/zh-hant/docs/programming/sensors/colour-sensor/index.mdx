顏色感測器會看向地板，讓機器人知道哪裡有坑洞、沼澤、接觸地塊和通道。它其實是一台只有一個像素、朝下的攝影機。在入門機器人上，它的名稱是 `color`，位於機器人前端，這樣就能在輪子到達坑洞之前先看到它。

## 地板顏色 \{#floor-colours\}

這些數值是用入門機器人在 `world2.wbt` 和 `mapping_example_1_cyan_tiles.wbt` 上測得的：

| 地板 | 紅 | 綠 | 藍 |
|---|---:|---:|---:|
| 一般地板 | 242 | 242 | 242 |
| 檢查點 | 254 | 254 | 254 |
| 沼澤 | 225 | 193 | 115 |
| 接觸地塊（青色） | 0 | 242 | 242 |
| 坑洞（黑色邊緣） | 34 | 34 | 34 |
| 區域 1 與 2 之間的通道（藍色） | 72 | 72 | 254 |
| 區域 2 與 3 之間的通道（紫色） | 161 | 72 | 238 |
| 區域 1 與 4 之間的通道（綠色） | 38 | 253 | 38 |
| 區域 3 與 4 之間的通道（紅色） | 254 | 72 | 72 |

:::caution
這些值可能會隨世界和圖形設定而改變。請使用範圍而不是精確值，並用 Erebus 的 `player_controllers` 資料夾中的 `calibrateColourSensor.py` 檢查它們。
:::

坑洞有黑色邊緣，所以在坑洞前地板會變暗。檢查點只比一般地板亮一點點，所以在依賴它之前，請先在你的世界裡的檢查點上校正。
