顏色感測器會看向地板，讓機器人知道哪裡有坑洞、沼澤和通道。它其實是一台只有一個像素、朝下的攝影機。在入門機器人上，它的名稱是 `color`，位於機器人前端，這樣就能在輪子到達坑洞之前先看到它。

<CodeTabs file="read" />

## 地板顏色 \{#floor-colours\}

這些數值是用入門機器人在 `world2.wbt` 上測得的：

| 地板 | 紅 | 綠 | 藍 |
|---|---:|---:|---:|
| 一般地板 | 252 | 252 | 252 |
| 沼澤 | 245 | 222 | 142 |
| 區域 1 與 2 之間的通道（藍色） | 91 | 91 | 255 |
| 區域 2 與 3 之間的通道（紫色） | 193 | 91 | 251 |
| 區域 1 與 4 之間的通道（綠色） | 48 | 255 | 48 |
| 區域 3 與 4 之間的通道（紅色） | 255 | 91 | 91 |

:::caution
數值會隨世界而改變：在 `world1.wbt` 中，一般地板的讀數大約是 240。請使用範圍而不是精確的數值，並用 Erebus `player_controllers` 資料夾中的 `calibrateColourSensor.py` 檢查它們。
:::

坑洞有黑色的邊緣，所以在坑洞前方，地板會先變暗。對這個感測器來說，檢查點看起來幾乎和一般地板一樣，所以請在你的世界中的檢查點上進行校正。
