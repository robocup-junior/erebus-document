光達（LIDAR）會測量機器人周圍一整圈的距離，單位是**公尺**，就像同時使用許多個距離感測器。在入門機器人上，它的名稱是 `lidar`，位於機器人頂部。

它會在機器人周圍測量 512 個點，分成上下堆疊的 4 層，最遠 1 m。沒有碰到任何物體的點會讀到 `inf`。

## 讀取距離 \{#reading-distances\}

`getLayerRangeImage(0)` 會提供一層的 512 個距離。第一個點在機器人正前方，接著**順時針**排列：四分之一處在右方，一半處在後方，四分之三處在左方。

![光達一層的點在機器人周圍的位置：0 在前方，128 在右方，256 在後方，384 在左方](../../../../../docs/programming/sensors/lidar/lidar-order.svg)

## 點雲 \{#point-cloud\}

光達也可以把每個點提供為相對於光達的位置，這對畫出機器人所見的地圖很有用。計算點雲需要額外的時間，所以只有在會用到時才啟用它。

<CodeTabs file="pointcloud" />

:::caution[放置光達]
在你自己的機器人中，請把光達放在頂部，並使用與[入門機器人](/docs/robot/build/)相同的旋轉角度，讓它保持水平。如果放在機身內部或傾斜放置，它會測量到機器人本身。
:::
