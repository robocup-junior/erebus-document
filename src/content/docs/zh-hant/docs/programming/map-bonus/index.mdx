地圖加成（Map bonus）最高可以讓你的分數乘以 2.2，所以非常值得爭取。依照以下步驟就能獲得：

1. 依照[地圖規則](/docs/rules/mapping/)中的說明，把地圖放進一個陣列
1. 傳送陣列的大小，接著傳送攤平後以逗號分隔、並以 UTF-8 編碼的陣列
1. 傳送地圖評估請求 `M`
1. 結束比賽。比賽結束時，Erebus 會把加成套用到你的分數上

## 須知事項 \{#things-to-know\}

- 你可以在比賽中的任何時間提交地圖，但**地圖只會被評估一次**。之後的 `M` 訊息會被忽略，所以請在地圖已經盡可能完整時再傳送。
- 請確保還有剩餘時間。如果比賽在你傳送 `M` 之前就結束了，就沒有地圖可以評估。
- 你不一定要傳送 `E` 才能獲得加成：時間用完時也會套用加成。但 `E` 是獲得出口加成（Exit bonus）的方式，而出口加成會在套用地圖加成之前先加上去。
- 地圖必須包含起始地塊（`5`），它用來將地圖與正確答案對齊。沒有它，地圖就無法評估。
- 結果會以 `Map Correctness` 顯示在控制視窗的歷史紀錄中。如果在 Webots 主控台看到 `Map scoring error`，請檢查你的格式。

下面的範例會傳送 `world1.wbt` 的正確答案，可以用來檢查你的通訊程式碼。如果你在比賽一開始就執行它，比賽會立刻結束，而且分數會維持 0，因為倍數沒有東西可以相乘。
