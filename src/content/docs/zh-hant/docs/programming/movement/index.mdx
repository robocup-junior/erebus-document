機器人有兩個輪子，各自有一個馬達：在[入門機器人](/docs/robot/)上是 `left wheel motor` 和 `right wheel motor`。你可以設定每個輪子的速度來駕駛它：

| 左輪 | 右輪 | 機器人會…… |
|---|---|---|
| 前進 | 前進 | 往前走 |
| 後退 | 後退 | 往後退 |
| 後退 | 前進 | 原地向左轉 |
| 前進 | 後退 | 原地向右轉 |
| 快 | 慢 | 向右彎 |

![機器人往前走、往後退、原地向左轉、原地向右轉和向右彎，箭頭代表每個輪子的速度](../../../../docs/programming/movement/wheel-speeds.svg)

速度的單位是**弧度每秒**，最高 6.28（每秒轉一圈）。負的速度會讓輪子向後轉。

## 駕駛 \{#driving\}

1. 依名稱取得每個馬達。
2. 把它的位置設為無限大，讓它可以不受限制地轉動。
3. 設定它的速度。

馬達會維持你最後設定的速度，所以在程式做其他事情時，機器人會繼續移動。這個程式會讓機器人往前、往後，再原地向左轉，各一秒：

## 測量輪子轉了多少 \{#measuring-how-far-a-wheel-turned\}

每個馬達都有一個位置感測器，也稱為編碼器（encoder），它會計算輪子轉了多少，單位是弧度。這對行駛固定距離很有用。向後轉時，計數會減少。

<CodeTabs file="encoders" />

用時間控制移動很簡單，但結果會隨速度而改變。編碼器測量的是移動本身，所以更可靠。若要精確轉彎，[陀螺儀](/docs/programming/sensors/imu/)效果更好。
