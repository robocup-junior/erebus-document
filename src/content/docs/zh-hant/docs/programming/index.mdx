title: 為機器人撰寫程式
description: 從第一個程式，到一台能完成整場比賽的機器人。
---

程式（也稱為**控制器**，controller）會在一個迴圈中執行：讀取感測器、做出判斷、設定馬達，然後讓模擬前進一步。機器人做的每一件事都來自這個迴圈。

這裡所有的範例都在[入門機器人](/docs/robot/)上執行。執行前請先載入入門機器人，範例就能直接運作。每個範例都有 Python 和 C/C++ 兩種版本：在分頁中選擇你的語言，整個網站都會套用你的選擇。

## 學習路線 \{#the-path\}

| 步驟 | 你會學到…… |
|---|---|
| 1. [第一個程式](/docs/programming/first-program/) | 撰寫、載入並執行程式 |
| 2. [移動](/docs/programming/movement/) | 前進與轉彎 |
| 3. [感測器](/docs/programming/sensors/) | 找出牆壁、坑洞、標記和自己的位置 |
| 4. [迷宮導航](/docs/programming/navigate-the-maze/) | 把所學整合成一個完整的程式 |
| 5. [通訊](/docs/programming/communication/) | 回報標記並得分 |
| 6. [牆上的標記](/docs/programming/wall-tokens/) | 分辨受害者、目標和假目標 |
| 7. [探索與建圖](/docs/programming/exploring/) | 有系統地探索並記住迷宮 |
| 8. [地圖規則](/docs/rules/mapping/)與[提交地圖](/docs/programming/map-bonus/) | 獲得地圖加成 |

每個步驟都建立在前面的步驟之上。如果你還沒讀過[規則摘要](/docs/rules/)，請先閱讀它：它說明了你的機器人要做什麼，以及哪些行為可以得分。

如果你使用 C 或 C++，請先閱讀 [C++ 控制器](/docs/programming/cpp/)，了解如何編譯和執行程式。
