## 為 Erebus 平台做出貢獻 {#contributions-to-the-erebus-platform}

你可以透過以下幾種方式為 Erebus 平台做出貢獻：
- 在[儲存庫中建立 issue](https://github.com/robocup-junior/erebus/issues)：如果你發現平台的錯誤，或有你認為它應該具備的功能，請告訴我們。
- 提出 pull request：如果你自己修好了錯誤，可以用 pull request 提交這項修改，讓它經過審查後合併。
- 在 [Discord 伺服器](https://discord.com/invite/6FJxZxk)上與我們交流：你可以在那裡聯繫開發者和 RCJ Rescue 委員會。歡迎與我們分享你的想法！

### 更深入的參與 {#deeper-involvement}
我們目前沒有積極招募模擬平台的新開發者。不過，我們一直在尋找新的人才，讓這個平台能為未來的世代延續下去。如果你具備相關技能，並希望加入開發團隊，請在 Discord 伺服器上聯繫平台開發團隊或 RoboCupJunior Rescue 委員會。

## 為文件做出貢獻 {#contributions-to-the-documentation}

- 在[文件儲存庫](https://github.com/robocup-junior/erebus-document/issues)中建立 issue。
- 在 [Discord 伺服器](https://discord.com/invite/6FJxZxk)上與我們交流：你可以在那裡聯繫開發者和 RCJ Rescue 委員會。歡迎與我們分享你的想法！
- 成為文件編輯者！如果你想協助撰寫文件，請在 Discord 伺服器上聯繫平台開發團隊。

本文件是使用 [Starlight](https://starlight.astro.build/) 主題的 [Astro](https://astro.build/) 網站。頁面是位於 `src/content/docs` 中的 Markdown 檔案，每一頁底部都有**編輯頁面**連結。如何在本機執行，請參閱文件儲存庫的 [README](https://github.com/robocup-junior/erebus-document#readme)。
