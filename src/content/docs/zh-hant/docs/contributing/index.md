## 為 Erebus 平台做出貢獻  {#contributions-to-the-erebus-platform}

如果你想為 Erebus 平台做出貢獻，目前有以下幾種方式：
- 在[儲存庫中提出 issue](https://github.com/robocup-junior/erebus/issues)：如果你發現平台的任何錯誤，或有你認為一定要加入的功能，請告訴我們。
- Pull request：如果你自己修好了錯誤，可以提出 pull request，讓這項修改有機會被採用。
- 透過 [Discord 伺服器](https://discord.com/invite/6FJxZxk)與我們交流：你可以透過 Discord 伺服器與我們（開發者、RCJ Rescue 委員會）聯繫。歡迎與我們分享你的想法！

### 更深入的參與 {#deeper-involvement}
我們目前沒有積極招募模擬平台的新開發者。不過，我們一直在尋找新的人才，讓這個平台能為下一代延續下去。如果你確信自己具備相關技能，並希望成為這個平台開發團隊的一員，請透過 Discord 伺服器聯繫平台開發團隊或 RoboCupJunior Rescue 委員會。

## 為文件做出貢獻 {#contributions-to-the-documentation}

- 點選 [Documentation issue](https://github.com/robocup-junior/erebus-document/issues)，在專案儲存庫中建立 issue。
- 透過 [Discord 伺服器](https://discord.com/invite/6FJxZxk)與我們交流：你可以透過 Discord 伺服器與我們（開發者、RCJ Rescue 委員會）聯繫。歡迎與我們分享你的想法！
- 成為活躍的文件編輯者！如果你想積極參與撰寫文件，請在 Discord 伺服器上聯繫平台開發團隊。

本文件是使用 [Starlight](https://starlight.astro.build/) 主題的 [Astro](https://astro.build/) 網站。頁面是位於 `src/content/docs` 中的 Markdown 檔案，每一頁底部都有**編輯頁面**連結。如何在本機執行，請參閱文件儲存庫的 [README](https://github.com/robocup-junior/erebus-document#readme)。
