本頁是依照 2027 年規則參加國際賽的指南。地區和區域比賽可能有所不同，請向主辦單位確認。官方[規則](/docs/rules/)永遠適用。

## 時程 {#timeline}

| 時間 | 內容 |
|---|---|
| 全年 | 關注[活動頁面](/docs/events/upcoming-events/)和[論壇](https://junior.forum.robocup.org/)，規則釐清會公布在那裡 |
| 至少 4 週前 | 主辦單位會提供網路表單的說明，用來準備面談 |
| 第一天的 3 週前 | 文件繳交截止 |
| 設置日 | 提早抵達會場，完成報到、面談和隊伍會議 |
| 每一輪 | 世界會在比賽開始前才公布。每一輪的截止時間過後，程式就不能再更改。 |
| 計分賽之後 | 技術挑戰（Technical Challenge） |

## 要繳交的文件 {#documents-to-submit}
範本和評分標準都在 [RCJ Rescue 社群網站](https://rescue.rcj.cloud/)上。

- [ ] **技術說明文件（Technical Description Paper，TDP）。** 請嚴格遵守範本：否則該文件的分數為 0。
- [ ] **海報**，包括電子檔，以及在會場展示的實體海報，尺寸不得大於 A1。
- [ ] 展示你的專案的**影片**。
- [ ] **伺服器－用戶端影片：** 一段短影片，展示你如何在伺服器－用戶端架構下，在範例地圖上執行控制器。
- [ ] 面談用的**原始碼**和**網路表單**。

## 比賽架構 {#competition-setup}
比賽以伺服器－用戶端架構進行：主辦單位執行比賽伺服器並提供一個 RJ-45 插座，你的程式則在你的電腦上執行。請參閱 [Remote Controller](/docs/competition/remote-controller/)。

請攜帶：

- [ ] 一台電腦，裝有你的程式和它需要的所有函式庫，以及 Webots R2025a
- [ ] 一條乙太網路線，如果你的電腦需要，也請攜帶轉接器
- [ ] 如果你有自訂機器人，請攜帶機器人的 `.json` 檔案
- [ ] 實體海報

## OpenGL 設定 {#opengl-settings}
除非主辦單位另有公告，否則會使用以下設定。這些設定會影響攝影機看到的畫面，所以請用它們進行測試。你可以在 Webots 偏好設定（Preferences）的 OpenGL 分頁中找到它們。

| 設定 | 數值 |
|---|---|
| Ambient Occlusion | Low |
| Texture Quality | Low |
| Max Texture Filtering | 4 |
| Shadows | Disabled |
| Anti-aliasing | Disabled |

## 測試你的機器人 {#testing-your-robot}
- [ ] 在所有內附的世界中執行，特別是四個 `2027_` 世界，它們含有接觸地塊和假標記。
- [ ] 用 [World Editor](/docs/tools/world-editor/) 製作你自己的地圖，並包含全部四個區域。
- [ ] 檢查整場比賽：能否執行到最後、及時更換電池、提交地圖並回到起點？
- [ ] 測試發生缺乏進展後會怎樣。
- [ ] 在你要帶去的電腦上，並使用上述的 OpenGL 設定進行測試。

## 比賽期間 {#during-the-competition}
- 除非裁判另有指示，否則只有隊長和副隊長可以進入比賽區域。
- 由裁判操作模擬。比賽開始後，你不能碰觸比賽設備。
- 指導老師在比賽期間不能提供協助。
- 準備好說明你們的作品：每位隊員都應該負責一項技術工作，並了解它是如何運作的。

## 最終分數 {#final-score}
國際賽的最終分數由以下部分組成：

| 部分 | 權重 | 內容 |
|---|---|---|
| 場地分數 | 0.6 | 標準化場地分數的平均值。表現最差的一輪或數輪不計入。 |
| 評分標準 | 0.2 | TDP（0.6）、影片（0.2）、海報（0.2） |
| 技術挑戰 | 0.2 | 在比賽現場公布的小任務，需在有限時間內重新為機器人撰寫程式來解決 |

同分時，以標準化場地分數的平均值決定名次。SuperTeam Challenge 是另一項獨立的活動，有自己的獎項。
