The colour sensor looks at the floor, so it tells the robot about holes, swamps and passages. It is a camera of a single pixel, pointing down. On the starter robot it is named `color`, at the front of the robot, so that it sees a hole before the wheels reach it.

<CodeTabs file="read" />

## Floor colours

These values were measured with the starter robot on `world2.wbt`:

| Floor | Red | Green | Blue |
|---|---:|---:|---:|
| Normal | 252 | 252 | 252 |
| Swamp | 245 | 222 | 142 |
| Passage between areas 1 and 2 (blue) | 91 | 91 | 255 |
| Passage between areas 2 and 3 (purple) | 193 | 91 | 251 |
| Passage between areas 1 and 4 (green) | 48 | 255 | 48 |
| Passage between areas 3 and 4 (red) | 255 | 91 | 91 |

:::caution
Values change with the world: normal floor reads about 240 in `world1.wbt`. Use ranges instead of exact values, and check them with `calibrateColourSensor.py` in the `player_controllers` folder of Erebus.
:::

Holes have a black edge, so the floor gets dark just before a hole. Checkpoints look almost like normal floor to this sensor, so calibrate on one in your world.
