## Basics

The emitter and receiver are used to communicate with the Main Supervisor, Erebus' game manager. The emitter is used to **report wall tokens**, **submit the map**, ask for game information, call a **lack of progress** and signal the **end of play**. The receiver gets the replies, and tells the robot controller when a lack of progress has happened.

The messages are listed in the [Reference](/docs/reference/messages/). They are explained below.

### Scoring Wall Tokens

To earn points for a letter victim or a cognitive target, the robot must:

1. Stop for **at least 1 second**, close to the wall token. Erebus ignores the report if the robot has moved in the last second.
2. Send the position and type of the wall token.

The message to the Main Supervisor should be formatted as follows:

X Pos **(integer),** Z Pos **(integer),** Type **(character)**

| Wall token | Type |
|---|---|
| Letter victim Φ (harmed) | `H` |
| Letter victim Ψ (stable) | `S` |
| Letter victim Ω (unharmed) | `U` |
| Cognitive target, sum 0 (Flammable Gas) | `F` |
| Cognitive target, sum 1 (Poison) | `P` |
| Cognitive target, sum 2 (Corrosive) | `C` |
| Cognitive target, sum 3 (Organic Peroxide) | `O` |

Note that the types are letters, even though victims show symbols since 2026.

:::note
The X position and Z position should be in **centimeters.** Thus, it is important to multiply the position given by the GPS by 100 to convert meters to centimeters.
:::

<CodeTabs file="scoring" />

The robot has to be on the same side of the wall as the token, and both the robot and the position you send must be close to it. The rules require them to be at most half a tile away, so that is what you should aim for. Erebus v26.1 currently checks a distance of 9 cm.

The position you send does not need to be exact, so the position of the robot is usually good enough. A report that does not match a token, including a report of a fake, is a misidentification and costs 5 points. Each token can only be scored once.

### Signaling End of Play

To end the game, send the character **'E'** using the emitter. If the robot is on the starting tile and has identified at least one wall token, it receives the exit bonus.

<CodeTabs file="endOfRun" />

:::note
The game ends wherever the robot is when it sends **'E'**, and the robot cannot continue afterwards. Make sure it has returned to the starting tile first.
:::

### Lack of Progress

The receiver can be used to detect lack of progress messages sent by the Main Supervisor, so that the robot controller can respond accordingly. This is important for navigation: the robot has been moved to the last visited checkpoint, so anything it assumed about its position is no longer valid.

### Game Information

Your program can retrieve the robot's current game score and the time remaining in your run. Use the emitter to send the character **'G'** to the supervisor, and it will send back a 16 byte packet with the letter **'G'**, the score, the remaining game time and the remaining real-world time. The times are in seconds.

<CodeTabs file="gameInfo" />

Use both times to plan your return to the starting tile. The game time runs faster in swamps, and the game ends when either of them runs out.
