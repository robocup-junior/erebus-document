The map bonus multiplies your score by up to 2.2, so it is worth a lot. It can be earned by following these steps:

1. Put the map into an array, as explained in the [Mapping rules](/docs/rules/mapping/)
1. Send the size of the array, followed by the array flattened with comma separators and encoded with UTF-8
1. Send the map evaluate request `M`
1. End the game. Erebus applies the bonus to your score when the game ends

## Things to know

- You can submit the map at any time during the game, but **it is only evaluated once**. Later `M` messages are ignored, so send it when the map is as complete as it is going to be.
- Make sure there is time left. If the game ends before you send `M`, there is no map to evaluate.
- You do not have to send `E` to get the bonus: it is also applied if the time runs out. But `E` is the way to get the exit bonus, and that bonus is added before the map bonus is applied.
- The map must contain the starting tile (`5`), which is used to align it to the correct answer. Without it, the map cannot be evaluated.
- The result is shown as `Map Correctness` in the history of the control window. If you get a `Map scoring error` in the Webots console, check your format.

The example below sends the correct answer for `world1.wbt`, which is useful to check your communication code. If you run it from the start of the game it ends the game immediately, and the score stays at 0 since a multiplier has nothing to multiply.
