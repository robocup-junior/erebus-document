A controller is a program that runs in a loop: read the sensors, decide, set the motors, and let the simulation advance one step. Everything your robot does comes from this loop.

If you have not done so yet, start with [Your first run](/docs/getting-started/), and with [Movement](/docs/robot/movement/) and [Sensors](/docs/robot/sensors/).
