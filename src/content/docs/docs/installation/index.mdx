## Software Requirements
The simulation system is made up of three components, and you need to install each of them. Installation is easy, but downloading and installing Webots can take a while. The three components are:

1. Webots robot simulator, version **R2025a**: the simulation environment. Erebus v27 does not support other versions of Webots.
1. Erebus: the worlds and the Main Supervisor, which applies the rules and calculates the score. The latest version is **v<span data-erebus-version>{latestVersion}</span>**.
1. Python, version **3.10 or later** (64-bit): needed to run Erebus itself, and to write controllers for the robots. You can also write controllers in C/C++.

## Minimum System Requirements
* Linux: Ubuntu 22.04 LTS or 24.04 LTS
* Windows: Windows 10 or 11, 64-bit
* macOS: macOS 12 "Monterey", 13 "Ventura" or 14 "Sonoma". These are the versions supported by Webots R2025a. Newer versions of macOS may also work: this documentation was tested on macOS 26.
* CPU: dual-core, 2 GHz
* RAM: 2 GB
* Graphics: NVIDIA or AMD graphics card with OpenGL 3.3 support and 512 MB of memory

## Python libraries
Erebus needs the Python libraries below. Most of them are installed automatically when it starts, but **OpenCV is not**, so you must install it yourself. The guide for each operating system includes this step. The `requirements.txt` file in the Erebus folder lists the versions that Erebus was tested with.

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```

## Optional: Wireshark
Erebus can watch the network for unauthorized access to the game while a match runs, which organizers use at competitions. This needs [Wireshark](https://www.wireshark.org/download.html). You do not need it to practice: without it, the control window shows a warning that network access is not monitored, which you can acknowledge and ignore.
