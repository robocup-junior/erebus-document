## Software Requirements
The simulation system is made up of three components, and you need to install each of them. Installation is easy, but downloading and installing Webots can take a while. The three components are:

1. Webots robot simulator, version **R2023b**: the simulation environment. Erebus v26 does not support other versions of Webots.
1. Erebus: the worlds and the Main Supervisor, which applies the rules and calculates the score. The latest version is **v26.1**.
1. Python, version **3.9 or later**: needed to run Erebus itself, and to write controllers for the robots. You can also write controllers in C/C++.

## Minimum System Requirements
* Linux: Ubuntu 20.04 LTS or 22.04 LTS
* Windows: Windows 10 or 11, 64-bit
* macOS: macOS 11 "Big Sur" or 12 "Monterey". These are the versions supported by Webots R2023b. Newer versions of macOS may also work: this documentation was tested on macOS 26.
* CPU: dual-core, 2 GHz
* RAM: 2 GB
* Graphics: NVIDIA or AMD graphics card with OpenGL support and 512 MB of memory

## Python libraries
Erebus needs the Python libraries below. Most of them are installed automatically when it starts, but **OpenCV is not**, so you must install it yourself. The guide for each operating system includes this step.

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```
