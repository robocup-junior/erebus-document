import { Steps } from '@astrojs/starlight/components';

<Steps>

1. Open the terminal, and install pip and the required libraries:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

2. Download and install **Webots R2023b**:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2023b/webots_2023b_amd64.deb
   sudo apt install ./webots_2023b_amd64.deb
   ```

3. Download the latest [Erebus release](https://github.com/robocup-junior/erebus/releases): open **Assets** and choose **Source code (zip)**. Unzip it.

</Steps>

## Run the environment

Open the world from the terminal, changing the path to your Erebus folder:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots opens the Erebus control window in your web browser. The first time, Erebus installs some Python libraries, which may take a while. It is ready when the window shows the 08:00 game timer:

![The Erebus control window, ready to start](../control-window-ready.png)

Next, try [your first run](/docs/getting-started/). If something goes wrong, see [Troubleshooting](/docs/troubleshooting/).
