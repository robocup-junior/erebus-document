<Steps>

1. Open the terminal, and install pip and the required libraries:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   On Ubuntu 24.04, pip refuses to install libraries into the Python of the system, with an `externally-managed-environment` error. Add `--break-system-packages` to the second command, or install the libraries in a [virtual environment](https://docs.python.org/3/library/venv.html) and set its Python in the Webots preferences.

2. Download and install **Webots R2025a**:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. Download <DownloadErebus /> and unzip it.

</Steps>

## Run the environment

Open the world from the terminal, changing the path to your Erebus folder:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots opens the Erebus control window in your web browser. The first time, Erebus installs some Python libraries and prepares the robot model, which may take a while. It is ready when the window shows **Ready** and the 08:00 game timer:

![The Erebus control window, ready to start](../control-window-ready.png)

The first time, the Webots console may also show `ERROR: Skipped PROTO 'custom_robot'`. You can ignore it: Erebus prepares the robot model and reloads the world by itself.

Next, read the [Rules summary](/docs/rules/) to understand the game. If something goes wrong, see [Troubleshooting](/docs/troubleshooting/).
