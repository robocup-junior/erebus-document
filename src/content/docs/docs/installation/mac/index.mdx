<Steps>

1. Install **Python 3.9 or later** from the [official website](https://www.python.org/downloads/macos/).

   Even if you already have Python through Homebrew, Anaconda or a similar tool, we recommend installing it this way. Otherwise, the simulation may not work properly.

2. Open the terminal and install the required libraries:

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. Install **Webots R2023b** from the [official repository](https://github.com/cyberbotics/webots/releases/download/R2023b/webots-R2023b.dmg).

4. Download <DownloadErebus /> and unzip it.

</Steps>

## Run the environment

Double-click the world file `game/worlds/world1.wbt` to open it in Webots.

Webots opens the Erebus control window in your web browser. The first time, Erebus installs some Python libraries, which may take a while. It is ready when the window shows the 08:00 game timer:

![The Erebus control window, ready to start](../control-window-ready.png)

Next, read the [Rules summary](/docs/rules/) to understand the game. If something goes wrong, see [Troubleshooting](/docs/troubleshooting/).
