import { archivedVersion, versions } from '@/data/versions';

Use the documentation that matches the rules of your competition. We support the versions of the latest two years, and the menu next to the logo lists them on every page.

<table>

			versions.map((version) => (
				<tr>

					<td>{version.webots}</td>
					<td>
						<a href={version.current ? '/docs/' : version.url}>{version.current ? 'You are here' : 'Open'}</a>

				</tr>
			))
		}
	</tbody>
</table>

All the releases of Erebus are on the [Releases page](https://github.com/robocup-junior/erebus/releases), and the changes in each one are in the [changelog](https://github.com/robocup-junior/erebus/blob/master/CHANGELOG.md).

The rules of each year are published on the [RoboCupJunior website](https://junior.robocup.org/rescue/).
