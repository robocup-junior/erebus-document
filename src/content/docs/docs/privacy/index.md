This documentation is a static website. It has no accounts, and it asks for no personal information.

## Analytics
This site uses [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) to see which pages are visited, so that we can improve them. It counts visits without cookies and without identifying individual visitors.

## What is stored in your browser
The site stores a few settings in your browser, which are not sent anywhere:

- Your theme
- The selected language tab of code examples

This site does not use cookies.
