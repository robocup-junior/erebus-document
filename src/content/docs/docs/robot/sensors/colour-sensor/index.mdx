## Basics

The colour sensor looks at the floor, so it tells the robot about swamps, passages and holes. In Erebus it is a camera of 1 × 1 pixel, pointing down. In the default robot it is named `colour_sensor`.

It is used like any [camera](/docs/robot/sensors/rgb-camera/):

<CodeTabs file="read" />

## Floor colours

These values were measured with the default robot on `world2.wbt`:

| Floor | Red | Green | Blue |
|---|---:|---:|---:|
| Normal | 252 | 252 | 252 |
| Swamp | 245 | 222 | 142 |
| Passage between areas 1 and 2 (blue) | 91 | 91 | 255 |
| Passage between areas 2 and 3 (purple) | 193 | 91 | 251 |
| Passage between areas 1 and 4 (green) | 48 | 255 | 48 |
| Passage between areas 3 and 4 (red) | 255 | 91 | 91 |

:::caution
Values change with the world: normal floor reads about 240 in `world1.wbt`. Do not hard-code exact values. Use ranges, and check them with `calibrateColourSensor.py` in the `player_controllers` folder.
:::
