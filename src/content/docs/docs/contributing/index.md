## Contributions to the Erebus platform

There are several ways to contribute to the Erebus platform:
- Open an [issue in the repository](https://github.com/robocup-junior/erebus/issues): let us know if you find a bug in the platform, or if there is a feature you think it should have.
- Make a pull request: if you fix a bug yourself, you can submit the change in a pull request so that it can be reviewed and merged.
- Talk to us on the [Discord server](https://discord.com/invite/6FJxZxk): you can reach the developers and the RCJ Rescue Committee there. Please share your ideas with us!

### Deeper involvement
We are not actively looking for new developers for the simulation platform at the moment. However, we are always looking for new talent to sustain the platform for future generations. If you have the skills and would like to join the development team, please contact the platform development team or the RoboCupJunior Rescue Committee on the Discord server.

## Contributions to the documentation

- Open an issue in the [documentation repository](https://github.com/robocup-junior/erebus-document/issues).
- Talk to us on the [Discord server](https://discord.com/invite/6FJxZxk): you can reach the developers and the RCJ Rescue Committee there. Please share your ideas with us!
- Become a documentation editor! If you would like to help write the documentation, please contact the platform development team on the Discord server.

The documentation is an [Astro](https://astro.build/) site using the [Starlight](https://starlight.astro.build/) theme. Pages are Markdown files in `src/content/docs`, and every page has an **Edit page** link at the bottom. See the [README](https://github.com/robocup-junior/erebus-document#readme) of the documentation repository for how to run it locally.
