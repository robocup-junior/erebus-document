Erebus is a robot simulation competition environment. You develop a controller for a robot that autonomously explores a maze, finds and identifies wall tokens, avoids obstacles and traps, and builds a map of the environment.

This documentation covers **Erebus v26**, which implements the **RoboCupJunior Rescue Simulation 2026** rules. See [Versions](/docs/reference/versions/) for the supported versions.
