## Kompetisi Internasional RoboCupJunior 2027 {#robocupjunior-2027-international-competition}

RoboCup 2027 akan diadakan di Nuremberg, Jerman, pada 17 hingga 21 Juni 2027. Simulator Erebus akan digunakan oleh tim-tim yang bertanding di kompetisi RoboCupJunior Rescue Simulation.

Aturan dan rilis Erebus untuk kompetisi ini belum final. Dokumentasi ini menjelaskan Erebus v26 dan aturan 2026, jadi silakan cek [halaman acara](https://rescue.rcj.cloud/events/2027/RoboCup2027/simulation/index.html) untuk draf aturan, versi Erebus untuk kompetisi, dan berita terbaru.
