Erebus adalah lingkungan kompetisi simulasi robot. Kamu merancang robot, lalu memprogramnya agar secara mandiri menjelajahi labirin, menemukan dan mengidentifikasi penanda dinding, menghindari rintangan dan jebakan, serta membuat peta lingkungannya.

Dokumentasi ini membahas **Erebus v26**, untuk aturan **RoboCupJunior Rescue Simulation 2026**. Lihat [Versi](/docs/reference/versions/) untuk versi lain yang didukung.

## Jalur belajar {#the-learning-path}
Ikuti langkah-langkahnya secara berurutan. Setiap langkah dibangun di atas langkah sebelumnya.

| Langkah | Halaman | Kamu akan... |
|---|---|---|
| **Mulai** | [Apa itu Erebus?](/docs/introduction/), [Instalasi](/docs/installation/) | Tahu apa yang kamu kerjakan, dan sudah menginstal semuanya |
| **1. Permainan** | [Ringkasan aturan](/docs/rules/) | Memahami misi, arena, dan cara mencetak poin |
| **2. Robotmu** | [Dapatkan robotmu](/docs/robot/), [Rakit robotmu](/docs/robot/build/) | Memuat robot pemula di Erebus |
| **3. Percobaan pertama** | [Percobaan pertamamu](/docs/getting-started/) | Melihat robotmu menjelajah, dan mengenal jendela kontrol |
| **4. Dasar pemrograman** | [Program pertamamu](/docs/programming/first-program/), [Gerakan](/docs/programming/movement/), [Sensor](/docs/programming/sensors/) | Membuat robotmu bergerak dan mengindra |
| **5. Mainkan permainannya** | [Menavigasi labirin](/docs/programming/navigate-the-maze/), [Komunikasi](/docs/programming/communication/), [Penanda dinding](/docs/programming/wall-tokens/), [Menjelajah dan memetakan](/docs/programming/exploring/), [Aturan pemetaan](/docs/rules/mapping/), [Mengirim peta](/docs/programming/map-bonus/) | Mencetak poin dengan segala cara |
| **6. Bertanding** | [Persiapan kompetisi](/docs/competition/), [Remote Controller](/docs/competition/remote-controller/) | Siap untuk kompetisi |

Setiap contoh menggunakan [robot pemula](/docs/robot/), jadi muat robot itu sebelum menjalankannya.
