<Steps>

1. Instal **Python 3.10 atau yang lebih baru** (64-bit) dari [situs web resminya](https://www.python.org/downloads/windows/). Selama instalasi, pastikan Python ditambahkan ke PATH-mu:

   ![Opsi Add Python to PATH pada installer Python](../../../../docs/installation/windows/python-path.png)

2. Buka PowerShell dan instal library yang dibutuhkan:

   ```powershell
   python -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. Instal **Webots R2025a** dari [repositori resminya](https://github.com/cyberbotics/webots/releases/download/R2025a/webots-R2025a_setup.exe).

4. Unduh <DownloadErebus />, lalu ekstrak berkas zip-nya.

</Steps>

## Menjalankan lingkungan \{#run-the-environment\}

Klik dua kali berkas world `game/worlds/world1.wbt` untuk membukanya di Webots.

Webots membuka jendela kontrol Erebus di browser web-mu. Saat pertama kali, Erebus menginstal beberapa library Python dan menyiapkan model robot, yang mungkin butuh waktu cukup lama. Erebus sudah siap saat jendela menampilkan **Ready** dan pewaktu permainan 08:00:

![Jendela kontrol Erebus, siap untuk dimulai](../../../../docs/installation/windows/../control-window-ready.png)

Saat pertama kali, konsol Webots juga mungkin menampilkan `ERROR: Skipped PROTO 'custom_robot'`. Kamu bisa mengabaikannya: Erebus menyiapkan model robot dan memuat ulang world dengan sendirinya.

Selanjutnya, baca [Ringkasan aturan](/docs/rules/) untuk memahami permainannya. Jika ada yang tidak beres, lihat [Pemecahan masalah](/docs/troubleshooting/).
