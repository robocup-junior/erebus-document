<Steps>

1. Instal **Python 3.9 atau yang lebih baru** dari [situs web resminya](https://www.python.org/downloads/macos/).

   Meskipun kamu sudah punya Python melalui Homebrew, Anaconda, atau sejenisnya, kami sarankan untuk menginstalnya dengan cara ini. Jika tidak, simulasi mungkin tidak berjalan dengan benar.

2. Buka terminal dan instal library yang dibutuhkan:

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. Instal **Webots R2023b** dari [repositori resminya](https://github.com/cyberbotics/webots/releases/download/R2023b/webots-R2023b.dmg).

4. Unduh <DownloadErebus />, lalu ekstrak file zip-nya.

</Steps>

## Menjalankan lingkungan \{#run-the-environment\}

Klik dua kali file world `game/worlds/world1.wbt` untuk membukanya di Webots.

Webots membuka jendela kontrol Erebus di browser web-mu. Saat pertama kali, Erebus menginstal beberapa library Python, yang mungkin butuh waktu cukup lama. Erebus sudah siap saat jendela menampilkan pewaktu permainan 08:00:

![Jendela kontrol Erebus, siap untuk dimulai](../../../../docs/installation/mac/../control-window-ready.png)

Selanjutnya, baca [Ringkasan aturan](/docs/rules/) untuk memahami permainannya. Jika ada yang tidak beres, lihat [Pemecahan masalah](/docs/troubleshooting/).
