## Persyaratan perangkat lunak \{#software-requirements\}
Sistem simulasi ini terdiri atas tiga komponen, dan kamu perlu menginstal semuanya. Instalasinya mudah, tetapi mengunduh dan menginstal Webots bisa memakan waktu cukup lama. Ketiga komponen itu adalah:

1. Simulator robot Webots, versi **R2023b**: lingkungan simulasinya. Erebus v26 tidak mendukung versi Webots lainnya.
1. Erebus: world dan Main Supervisor, yang menerapkan aturan dan menghitung skor. Versi terbarunya adalah **v26.1**.
1. Python, versi **3.9 atau yang lebih baru**: dibutuhkan untuk menjalankan Erebus itu sendiri, dan untuk menulis controller bagi robot. Kamu juga bisa menulis controller dalam C/C++.

## Persyaratan sistem minimum \{#minimum-system-requirements\}
* Linux: Ubuntu 20.04 LTS atau 22.04 LTS
* Windows: Windows 10 atau 11, 64-bit
* macOS: macOS 11 "Big Sur" atau 12 "Monterey". Ini adalah versi yang didukung oleh Webots R2023b. Versi macOS yang lebih baru mungkin juga bisa dipakai: dokumentasi ini sudah diuji di macOS 26.
* CPU: dual-core, 2 GHz
* RAM: 2 GB
* Grafis: kartu grafis NVIDIA atau AMD dengan dukungan OpenGL dan memori 512 MB

## Library Python \{#python-libraries\}
Erebus membutuhkan library Python di bawah ini. Sebagian besar terinstal otomatis saat Erebus dijalankan, tetapi **OpenCV tidak**, jadi kamu harus menginstalnya sendiri. Panduan untuk setiap sistem operasi sudah mencakup langkah ini.

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```
