---
title: Glosarium
description: Istilah-istilah yang digunakan di Erebus dan di aturan.
---

| Istilah | Arti |
|---|---|
| **Area** | Salah satu dari empat bagian arena, masing-masing dengan jenis dindingnya sendiri. World Editor menyebutnya ruangan (room). |
| **Pengali area (Area multiplier, AM)** | 1; 1,25; 1,5; atau 2, diterapkan pada poin di setiap area |
| **Baterai (Battery)** | Berkurang sesuai kecepatan motor. Permainan berakhir saat baterai habis. |
| **Checkpoint** | Ubin berwarna perak. Setelah terjadi kurangnya kemajuan, robot kembali ke checkpoint terakhir yang dikunjunginya. |
| **Target kognitif (Cognitive target)** | Penanda dinding dengan lima warna konsentris, yang jumlahnya menentukan jenis hazmat. Menggantikan tanda hazmat sejak 2026. |
| **Ubin kontak (Contact tile)** | Ubin sian tempat baterai diganti, jika robot diam di atasnya selama 5 detik |
| **Jendela kontrol (Control window)** | Halaman web tempat kamu memuat program dan menjalankan permainan. Juga disebut jendela robot (robot window). |
| **Controller** | Programmu |
| **Robot kustom (Custom robot)** | Robot yang dirancang dengan Robot Customizer dan dimuat dari berkas `.json` |
| **Bonus keluar (Exit bonus, EB)** | +10% karena kembali ke ubin awal dan mengirim `E` |
| **Palsu (Fake)** | Penanda yang tidak boleh dilaporkan: korban smiley tiga dimensi, dan target kognitif dengan jumlah yang tidak valid |
| **Ubin mengambang (Floating tile)** | Ubin yang tidak bisa dicapai dengan menyusuri dinding yang tersambung ke ubin awal. Penanda di sini bernilai lebih tinggi. |
| **Kurangnya kemajuan (Lack of progress, LoP)** | Saat robot terjebak atau jatuh ke lubang. Robot kembali ke checkpoint terakhir dan kehilangan 5 poin. |
| **Ubin linear (Linear tile)** | Ubin yang bisa dicapai dengan menyusuri dinding yang tersambung ke ubin awal |
| **Main Supervisor** | Bagian dari Erebus yang mengelola permainan. Juga disebut supervisor atau pengelola permainan (game manager). |
| **Bonus pemetaan (Mapping bonus, MB)** | Pengali skor sebesar ketepatan × 1,2 + 1 |
| **Matriks peta (Map matrix)** | Array yang merepresentasikan peta |
| **Lorong penghubung (Passage)** | Ubin berwarna yang menghubungkan dua area |
| **Seperempat ubin (Quarter tile)** | Seperempat dari satu ubin, selebar 6 cm, digunakan di Area 2 dan 3 |
| **Pengaturan server-klien (Server-client setup)** | Permainan berjalan di satu komputer dan programmu di komputer lain. Lihat Remote Controller. |
| **Korban smiley (Smiley victim)** | Penanda dinding dengan wajah sedih, datar, atau senang. Menggantikan korban huruf pada 2027. |
| **Rawa (Swamp)** | Ubin cokelat yang membuat baterai berkurang lebih cepat |
| **TDP** | Technical Description Paper (makalah deskripsi teknis) |
| **Ubin (Tile)** | Satuan arena, selebar 12 cm |
| **TI, TT, CN, TMI** | Dalam penilaian: identifikasi penanda (token identification), jenis penanda (token type), melewati checkpoint (checkpoint negotiation), dan salah identifikasi penanda (token misidentification) |
| **Penanda dinding (Wall token)** | Apa pun yang harus diidentifikasi di dinding: korban smiley dan target kognitif |
| **World** | Sebuah peta, berupa berkas `.wbt` |
