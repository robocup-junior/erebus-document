Programmu berkomunikasi dengan permainan melalui dua perangkat yang dimiliki setiap robot:

- **Emitter** mengirim pesan ke permainan. Perangkat ini tidak perlu diaktifkan.
- **Receiver** menerima pesan dari permainan. Aktifkan receiver seperti mengaktifkan sensor.

Setiap bagian di bawah ini adalah program lengkap untuk [robot pemula](/docs/robot/). Semua pesan tercantum di [Referensi pesan](/docs/reference/messages/).

## Mencetak poin dari penanda dinding \{#scoring-wall-tokens\}

Untuk mencetak poin dari korban smiley (letter victim) atau target kognitif (cognitive target), robot harus:

1. **Berhenti lebih dari 1 detik** di dekat penanda. Erebus mengabaikan laporan jika robot bergerak dalam satu detik terakhir.
2. **Mengirim posisi dan jenis** penanda: X dan Z dalam **sentimeter**, dan jenisnya sebagai satu huruf.

| Penanda dinding | Jenis |
|---|---|
| Korban smiley, wajah sedih (terluka) | `H` |
| Korban smiley, wajah datar (stabil) | `S` |
| Korban smiley, wajah senang (tidak terluka) | `U` |
| Target kognitif, jumlah 0 (Gas Mudah Terbakar) | `F` |
| Target kognitif, jumlah 1 (Racun) | `P` |
| Target kognitif, jumlah 2 (Korosif) | `C` |
| Target kognitif, jumlah 3 (Peroksida Organik) | `O` |

Jenisnya berupa huruf, meskipun korban menampilkan wajah. GPS memberikan meter, jadi kalikan dengan 100.

<CodeTabs file="report" />

Robot harus berada di sisi dinding yang sama dengan penanda, dan titik tengah robot maupun posisi yang kamu kirim harus berada dalam setengah ubin (6 cm) dari penanda.

Jalankan program ini di awal `world1.wbt`: tidak ada penanda di sana, jadi event pertandingan di jendela kontrol menampilkan `Misidentification of Victim -5`. Laporan yang salah, termasuk melaporkan penanda palsu, mengurangi 5 poin, dan setiap penanda hanya bisa mendapat poin sekali.

## Kurangnya kemajuan \{#lack-of-progress\}

Saat robot terjebak, kurangnya kemajuan (lack of progress) memindahkannya kembali ke checkpoint terakhir dan mengurangi 5 poin. Ini terjadi otomatis setelah robot tidak bergerak selama 20 detik, dan programmu juga bisa memicunya dengan mengirim `L`. Setiap kali terjadi, permainan mengirim `L` ke robot, agar programmu tahu posisinya sudah berubah.

<CodeTabs file="lop" />

Receiver bisa menerima pesan yang berbeda-beda, jadi periksa panjang setiap pesan sebelum membacanya, seperti pada contoh.

## Informasi permainan \{#game-information\}

Kirim `G` untuk mendapatkan skor, sisa waktu, dan level baterai. Permainan membalas dengan pesan 20 byte: huruf `G`, skor, sisa waktu permainan dan waktu nyata dalam detik, dan level baterai dalam persen.

<CodeTabs file="gameinfo" />

Permainan berakhir saat salah satu waktu habis, atau saat baterai kosong. Gunakan nilai-nilai ini untuk mengetahui kapan kembali ke start, dan kapan [mengganti baterai](/docs/programming/battery/).

## Mengakhiri permainan \{#ending-the-game\}

Kirim `E` untuk mengakhiri permainan. Jika robot berada di ubin awal dan sudah mengidentifikasi minimal satu penanda dinding, robot mendapat bonus keluar (exit bonus) 10%.

<CodeTabs file="exit" />

:::caution
Permainan berakhir di mana pun robot berada saat mengirim `E`, dan robot tidak bisa melanjutkan. Pastikan robot sudah kembali ke ubin awal terlebih dahulu, dan sudah [mengirim petanya](/docs/programming/map-bonus/).
:::

Selanjutnya, pelajari cara membedakan jenis-jenis penanda di [Penanda dinding](/docs/programming/wall-tokens/).
