---
title: Memprogram robotmu
description: Jalur belajar dari program pertamamu hingga robot yang memainkan seluruh permainan.
---

Program, atau **controller**, berjalan dalam sebuah loop: membaca sensor, mengambil keputusan, mengatur motor, lalu membiarkan simulasi maju satu langkah. Semua yang dilakukan robotmu berasal dari loop ini.

Semua contoh di sini berjalan di [robot pemula](/docs/robot/). Muat robot itu sebelum menjalankannya, dan contohnya langsung bekerja apa adanya. Setiap contoh punya versi Python dan C/C++: pilih bahasamu di tab, dan seluruh situs akan mengikuti pilihanmu.

## Jalur belajar \{#the-path\}

| Langkah | Kamu belajar untuk... |
|---|---|
| 1. [Program pertamamu](/docs/programming/first-program/) | Menulis, memuat, dan menjalankan program |
| 2. [Gerakan](/docs/programming/movement/) | Melaju dan berbelok |
| 3. [Sensor](/docs/programming/sensors/) | Menemukan dinding, lubang, penanda, dan posisimu |
| 4. [Menavigasi labirin](/docs/programming/navigate-the-maze/) | Menggabungkan semuanya dalam program lengkap |
| 5. [Komunikasi](/docs/programming/communication/) | Melaporkan penanda dan mencetak poin |
| 6. [Penanda dinding](/docs/programming/wall-tokens/) | Membedakan korban, target, dan yang palsu |
| 7. [Menjelajah dan memetakan](/docs/programming/exploring/) | Menjelajah secara sistematis dan mengingat labirin |
| 8. [Aturan pemetaan](/docs/rules/mapping/) dan [Mengirim peta](/docs/programming/map-bonus/) | Mendapatkan bonus peta |

Setiap langkah dibangun di atas langkah sebelumnya. Jika belum, baca dulu [Ringkasan aturan](/docs/rules/): halaman itu menjelaskan apa yang harus dilakukan robotmu, dan apa saja yang menghasilkan poin.

Jika kamu menulis dalam C atau C++, baca dulu [Controller C++](/docs/programming/cpp/), untuk mengompilasi dan menjalankan programmu.
