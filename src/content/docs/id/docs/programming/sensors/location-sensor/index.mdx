Sensor lokasi, atau **GPS**, memberikan posisi robot dalam **meter**. Pada robot pemula, namanya `gps`. Kamu membutuhkannya untuk [melaporkan penanda dinding](/docs/programming/communication/#scoring-wall-tokens), dan sensor ini sangat membantu untuk [menjelajah secara sistematis](/docs/programming/exploring/).

`getValues()` mengembalikan `[x, y, z]`. **X dan Z adalah sumbu horizontal**, dan Y vertikal, jadi gunakan X dan Z untuk posisi di labirin:

![Sumbu X dan Z pada bidang horizontal, dengan Y vertikal](../../../../../docs/programming/sensors/location-sensor/coordinate_systems_right_handed.png)

<CodeTabs file="read" />

GPS memiliki derau (noise) beberapa milimeter, jadi nilainya sedikit berubah bahkan saat robot diam. Jangan pernah membandingkan posisi untuk kesamaan yang persis.
