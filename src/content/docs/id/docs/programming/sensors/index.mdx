Sensor memberi tahu robotmu tentang dunia di sekitarnya. Semua sensor digunakan dengan cara yang sama:

1. Ambil sensor berdasarkan namanya dengan `robot.getDevice()`.
2. Aktifkan dengan `enable(timeStep)`. Sebelum itu, sensor tidak memberikan nilai apa pun.
3. Baca sensor di dalam loop utama. Nilainya diperbarui setelah setiap `robot.step()`.

Seperti sensor sungguhan, sensor ini punya derau (noise): pembacaan yang sama bisa sedikit berubah dari satu langkah ke langkah berikutnya. Panitia tidak mengubah derau untuk kompetisi, jadi buat programmu tahan terhadapnya, misalnya dengan membandingkan beberapa pembacaan.

Halaman-halaman di bawah ini menggunakan sensor dari [robot pemula](/docs/robot/).
