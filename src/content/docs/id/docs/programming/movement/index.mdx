Robot punya dua roda, masing-masing dengan motornya sendiri: `left wheel motor` dan `right wheel motor` pada [robot pemula](/docs/robot/). Kamu menggerakkannya dengan mengatur kecepatan setiap roda:

| Roda kiri | Roda kanan | Robotnya... |
|---|---|---|
| Maju | Maju | Melaju maju |
| Mundur | Mundur | Melaju mundur |
| Mundur | Maju | Berputar ke kiri |
| Maju | Mundur | Berputar ke kanan |
| Cepat | Lambat | Berbelok melengkung ke kanan |

![Robot melaju maju, melaju mundur, berputar ke kiri, berputar ke kanan, dan berbelok melengkung ke kanan, dengan panah untuk kecepatan setiap roda](../../../../docs/programming/movement/wheel-speeds.svg)

Kecepatan dinyatakan dalam **radian per detik**, hingga 6,28 (satu putaran roda per detik). Kecepatan negatif memutar roda ke belakang.

## Melaju \{#driving\}

1. Ambil setiap motor berdasarkan namanya.
2. Atur posisinya ke tak hingga, agar motor berputar tanpa batas.
3. Atur kecepatannya.

Motor mempertahankan kecepatan terakhir yang kamu atur, jadi robot tetap bergerak sementara programmu melakukan hal lain. Program ini membuat robot maju, mundur, dan berputar ke kiri, masing-masing selama satu detik:

## Mengukur seberapa jauh roda berputar \{#measuring-how-far-a-wheel-turned\}

Setiap motor punya sensor posisi, yang juga disebut encoder, yang menghitung seberapa jauh roda sudah berputar, dalam radian. Sensor ini berguna untuk melaju sejauh jarak tertentu. Berputar mundur membuat hitungannya berkurang.

<CodeTabs file="encoders" />

Mengendalikan gerakan berdasarkan waktu itu mudah, tetapi hasilnya berubah tergantung kecepatan. Encoder mengukur gerakannya secara langsung, jadi lebih andal. Untuk belokan yang presisi, [giroskop](/docs/programming/sensors/imu/) lebih baik lagi.

Selanjutnya, pelajari cara membaca [sensor](/docs/programming/sensors/).
