## Kontribusi untuk platform Erebus  {#contributions-to-the-erebus-platform}

Jika kamu ingin berkontribusi untuk platform Erebus, saat ini ada beberapa cara untuk melakukannya.
- Membuat [issue di repositori](https://github.com/robocup-junior/erebus/issues): Beri tahu kami jika kamu menemukan bug pada platform atau fitur yang menurutmu harus ditambahkan.
- Pull request: Jika kamu berhasil memperbaiki bug sendiri, kamu bisa membuat pull request agar perubahan itu bisa diterapkan.
- Ngobrol dengan kami di [server Discord](https://discord.com/invite/6FJxZxk): Kamu bisa berkomunikasi dengan kami (developer, komite RCJ Rescue) melalui server Discord. Silakan bagikan idemu kepada kami!

### Keterlibatan lebih dalam {#deeper-involvement}
Saat ini kami tidak sedang aktif mencari developer baru untuk platform simulasi ini. Namun, kami selalu mencari talenta baru untuk menjaga platform ini tetap berjalan bagi generasi mendatang. Jika kamu sangat yakin punya kemampuannya dan ingin menjadi bagian dari tim pengembang platform ini, silakan hubungi tim pengembang platform atau Komite RoboCupJunior Rescue melalui server Discord.

## Kontribusi untuk dokumentasi {#contributions-to-the-documentation}

- Membuat issue dengan mengklik [Documentation issue](https://github.com/robocup-junior/erebus-document/issues) dan membuat issue di repositori proyek.
- Ngobrol dengan kami di [server Discord](https://discord.com/invite/6FJxZxk): Kamu bisa berkomunikasi dengan kami (developer, komite RCJ Rescue) melalui server Discord. Silakan bagikan idemu kepada kami!
- Jadilah editor dokumentasi yang aktif! Jika kamu ingin terlibat aktif dalam menulis dokumentasi, silakan hubungi tim pengembang platform di server Discord.

Dokumentasi ini adalah situs [Astro](https://astro.build/) yang menggunakan tema [Starlight](https://starlight.astro.build/). Halaman-halamannya adalah file Markdown di `src/content/docs`, dan setiap halaman punya tautan untuk mengedit halaman di bagian bawah. Lihat [README](https://github.com/robocup-junior/erebus-document#readme) repositori dokumentasi untuk cara menjalankannya secara lokal.
