## Kontribusi untuk platform Erebus {#contributions-to-the-erebus-platform}

Ada beberapa cara untuk berkontribusi pada platform Erebus:
- Buat [issue di repositori](https://github.com/robocup-junior/erebus/issues): beri tahu kami jika kamu menemukan bug pada platform, atau jika ada fitur yang menurutmu perlu ditambahkan.
- Buat pull request: jika kamu memperbaiki bug sendiri, kamu bisa mengirimkan perubahannya melalui pull request agar dapat ditinjau dan digabungkan (merge).
- Ngobrol dengan kami di [server Discord](https://discord.com/invite/6FJxZxk): di sana kamu bisa menghubungi para developer dan Komite RCJ Rescue. Silakan bagikan idemu kepada kami!

### Keterlibatan lebih dalam {#deeper-involvement}
Saat ini kami tidak sedang aktif mencari developer baru untuk platform simulasi ini. Namun, kami selalu mencari talenta baru untuk menjaga keberlangsungan platform ini bagi generasi mendatang. Jika kamu punya kemampuannya dan ingin bergabung dengan tim pengembang, silakan hubungi tim pengembang platform atau Komite RoboCupJunior Rescue di server Discord.

## Kontribusi untuk dokumentasi {#contributions-to-the-documentation}

- Buat issue di [repositori dokumentasi](https://github.com/robocup-junior/erebus-document/issues).
- Ngobrol dengan kami di [server Discord](https://discord.com/invite/6FJxZxk): di sana kamu bisa menghubungi para developer dan Komite RCJ Rescue. Silakan bagikan idemu kepada kami!
- Jadilah editor dokumentasi! Jika kamu ingin ikut menulis dokumentasi, silakan hubungi tim pengembang platform di server Discord.

Dokumentasi ini adalah situs [Astro](https://astro.build/) yang menggunakan tema [Starlight](https://starlight.astro.build/). Halaman-halamannya berupa berkas Markdown di `src/content/docs`, dan setiap halaman punya tautan **Edit halaman** di bagian bawah. Lihat [README](https://github.com/robocup-junior/erebus-document#readme) repositori dokumentasi untuk cara menjalankannya secara lokal.
