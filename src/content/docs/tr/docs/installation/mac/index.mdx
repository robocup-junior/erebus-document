<Steps>

1. [Resmî web sitesinden](https://www.python.org/downloads/macos/) **Python 3.10 ya da daha yenisini** kur.

   Python'u Homebrew, Anaconda ya da benzeri bir araçla zaten kurduysan bile bu şekilde kurmanı öneririz. Aksi halde simülasyon düzgün çalışmayabilir.

2. Terminali aç ve gerekli kütüphaneleri kur:

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. **Webots R2025a**'yi [resmî depodan](https://github.com/cyberbotics/webots/releases/download/R2025a/webots-R2025a.dmg) kur.

4. <DownloadErebus /> dosyasını indir ve zip'ten çıkar.

</Steps>

## Ortamı çalıştır \{#run-the-environment\}

Webots'ta açmak için `game/worlds/world1.wbt` dünya dosyasına çift tıkla.

Webots, Erebus kontrol penceresini web tarayıcında açar. İlk açılışta Erebus bazı Python kütüphanelerini kurar ve robot modelini hazırlar; bu biraz zaman alabilir. Pencerede **Ready** ve 08:00 oyun süresi göründüğünde Erebus hazırdır:

![Erebus kontrol penceresi, başlamaya hazır](../../../../docs/installation/mac/../control-window-ready.png)

İlk açılışta Webots konsolu `ERROR: Skipped PROTO 'custom_robot'` mesajını da gösterebilir. Bunu görmezden gelebilirsin: Erebus robot modelini hazırlar ve dünyayı kendiliğinden yeniden yükler.

Ardından oyunu anlamak için [Kural özeti](/docs/rules/) sayfasını oku. Bir sorun çıkarsa [Sorun giderme](/docs/troubleshooting/) sayfasına bak.
