Mesafe sensörü, önündeki ilk nesneye olan uzaklığı **metre** cinsinden, en fazla 0,8 m'ye kadar ölçer. Başlangıç robotunda üç tane vardır: sola, öne ve sağa bakan `leftDist`, `frontDist` ve `rightDist`.
