## RoboCupJunior 2027 국제 대회 {#robocupjunior-2027-international-competition}

RoboCup 2027은 2027년 6월 17일부터 6월 21일까지 독일 뉘른베르크에서 열려요. RoboCupJunior Rescue Simulation 대회에 참가하는 팀들은 Erebus 시뮬레이터를 사용해요.

이 대회의 규칙과 Erebus 릴리스는 아직 확정되지 않았어요. 이 문서는 Erebus v26과 2026년 규칙을 설명하므로, 규칙 초안, 대회용 Erebus 버전, 최신 소식은 [이벤트 페이지](https://rescue.rcj.cloud/events/2027/RoboCup2027/simulation/index.html)에서 확인하세요.
