이 페이지는 2026년 규칙에 따른 국제 대회 가이드예요. 지역 대회와 권역 대회는 다를 수 있으니 주최 측에 확인하세요. 공식 [규칙](/docs/rules/)이 항상 우선해요.

## 일정 {#timeline}

| 시기 | 할 일 |
|---|---|
| 1년 내내 | 규칙 해석이 올라오는 [이벤트 페이지](/docs/events/upcoming-events/)와 [포럼](https://junior.forum.robocup.org/)을 확인하세요 |
| 최소 4주 전 | 주최 측이 인터뷰 준비용 웹 양식에 대한 안내를 줘요 |
| 첫날 3주 전 | 문서 제출 마감 |
| 설치일 | 등록, 인터뷰, 팀 미팅을 위해 일찍 대회장에 도착하세요 |
| 각 라운드 | 월드는 게임 직전에 공개돼요. 각 라운드의 마감 후에는 프로그램을 바꿀 수 없어요. |
| 점수 경기 후 | 기술 챌린지(Technical Challenge) |

## 제출할 문서 {#documents-to-submit}
템플릿과 평가 기준은 [RCJ Rescue 커뮤니티 웹사이트](https://rescue.rcj.cloud/)에 있어요.

- [ ] **기술 설명서(Technical Description Paper, TDP).** 템플릿을 엄격히 따르세요. 그렇지 않으면 문서 점수는 0점이에요.
- [ ] **포스터.** 파일로 제출하고, 대회장에는 A1 이하 크기의 실물 포스터를 준비하세요.
- [ ] 프로젝트를 소개하는 **동영상**.
- [ ] **서버-클라이언트 동영상.** 2026년에 새로 생겼어요. 서버-클라이언트 구성에서 예제 맵으로 컨트롤러를 실행하는 방법을 보여 주는 짧은 동영상이에요.
- [ ] 인터뷰를 위한 **소스 코드**와 **웹 양식**.

## 대회 구성 {#competition-setup}
게임은 서버-클라이언트 구성으로 진행돼요. 주최 측이 게임 서버를 운영하고 RJ-45 소켓 하나를 제공하며, 프로그램은 여러분의 컴퓨터에서 실행돼요. [Remote Controller](/docs/competition/remote-controller/)를 참고하세요.

가져올 것:

- [ ] 프로그램과 필요한 모든 라이브러리, Webots R2023b가 설치된 컴퓨터
- [ ] 이더넷 케이블, 그리고 컴퓨터에 필요하다면 어댑터
- [ ] 커스텀 로봇이 있다면 로봇의 `.json` 파일
- [ ] 실물 포스터

## OpenGL 설정 {#opengl-settings}
주최 측이 따로 공지하지 않으면 다음 설정을 사용해요. 카메라에 보이는 모습에 영향을 주므로, 이 설정으로 테스트하세요. Webots 환경 설정(Preferences)의 OpenGL 탭에서 찾을 수 있어요.

| 설정 | 값 |
|---|---|
| Ambient Occlusion | Low |
| Texture Quality | Low |
| Max Texture Filtering | 4 |
| Shadows | Disabled |
| Anti-aliasing | Disabled |

## 로봇 테스트하기 {#testing-your-robot}
- [ ] 포함된 모든 월드에서 실행해 보세요. 특히 가짜가 포함된 `world3.wbt`와 `world4.wbt`에서요.
- [ ] [World Editor](/docs/tools/world-editor/)로 네 구역이 모두 들어간 나만의 맵을 만들어 보세요.
- [ ] 게임 전체를 확인하세요. 끝까지 실행되고, 지도를 제출하고, 시간 안에 출발점으로 돌아오나요?
- [ ] 진행 불능(Lack of Progress) 이후 어떻게 되는지 테스트하세요.
- [ ] 가져갈 컴퓨터와 위의 OpenGL 설정으로 테스트하세요.

## 대회 중에 {#during-the-competition}
- 심판이 따로 말하지 않는 한, 주장과 부주장만 경기 구역에 들어갈 수 있어요.
- 시뮬레이션은 심판이 조작해요. 게임이 시작되면 게임 장비를 만질 수 없어요.
- 대회 중에는 멘토가 도와줄 수 없어요.
- 자신의 작업을 설명할 준비를 하세요. 팀원 모두가 기술적인 역할을 맡고, 그것이 어떻게 작동하는지 알아야 해요.

## 최종 점수 {#final-score}
국제 대회의 최종 점수는 다음을 합쳐서 계산해요.

| 항목 | 가중치 | 내용 |
|---|---|---|
| 경기장 점수 | 0.6 | 정규화된 경기장 점수의 평균. 가장 낮은 라운드(들)는 제외돼요. |
| 평가 기준 | 0.2 | TDP (0.6), 동영상 (0.2), 포스터 (0.2) |
| 기술 챌린지 | 0.2 | 대회에서 공개되는 작은 과제로, 제한된 시간 안에 로봇을 다시 프로그래밍해서 해결해요 |

동점은 정규화된 경기장 점수의 평균으로 가려요. SuperTeam Challenge는 별도의 상이 있는 별개의 이벤트예요.
