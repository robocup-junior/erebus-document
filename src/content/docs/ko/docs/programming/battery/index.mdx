로봇에는 배터리가 있고, 배터리가 다 떨어지면 게임이 끝나요. 이 페이지에서는 배터리가 얼마나 빨리 줄어드는지, 프로그램이 배터리를 어떻게 읽는지, 그리고 어떻게 교체하는지 배워요.

## 배터리의 작동 방식 \{#how-the-battery-works\}

- 배터리는 100%에서 시작하고, **바퀴의 속도에 따라 줄어들어요**. 바퀴가 빨리 돌수록 더 빨리 줄어요. 기본 설정에서는 멈춰 있는 로봇은 배터리를 쓰지 않아요.
- **늪**에서는 더 빨리 줄어요.
- 교체하려면 로봇이 **접촉 타일 위에서 5초 동안 가만히 있어야** 해요. 그러면 배터리가 다시 100%가 돼요. 움직이거나 타일을 벗어나면 5초를 처음부터 다시 세요.
- 배터리가 0%가 되면 게임은 `Battery depleted`로 끝나요. 다 떨어진 배터리는 교체할 수 없어요.

제어 창에는 타이머 위에 배터리 잔량이 표시돼요. 20% 아래로 내려가면 "Low battery"라고 표시돼요.

![배터리가 부족할 때 제어 창의 점수, 배터리 잔량, 타이머](../../../../docs/programming/battery/battery-low.png)

규칙은 배터리가 얼마나 빨리 줄어드는지 알려 주지 않아요. 팀이 테스트로 알아내야 해요. Erebus v27의 기본 설정에서는 두 바퀴가 최고 속도(6.28 rad/s)로 돌면 초당 약 1.25%를 쓰기 때문에, 한 번도 멈추지 않는 로봇은 1분 30초도 안 되어 배터리가 떨어져요. 게임 시간 8분보다 훨씬 짧아요. 운영자가 이 설정을 바꿀 수 있으므로, 이 숫자에 기대지 말고 프로그램에서 직접 측정하세요.

## 배터리 교체하기 \{#replacing-the-battery\}

접촉 타일은 청록색이므로 [컬러 센서](/docs/programming/sensors/colour-sensor/)로 볼 수 있어요. 빨강은 0에 가깝고, 초록과 파랑은 높아요.

스타터 로봇의 컬러 센서는 앞쪽에 있지만, Erebus는 로봇 **중심**의 위치를 확인해요. 그래서 센서가 청록색을 보면, 로봇은 조금 더 나아간 다음 멈춰요. 그런 다음 배터리가 가득 찰 때까지 기다리는데, 5초가 걸려요.

## 계획 세우기 \{#planning\}
- 접촉 타일이 어디 있는지 알아 두세요. 지도처럼 탐색하면서 기억해 두면 돼요.
- 배터리가 부족해지기 전에, 알고 있는 가장 가까운 접촉 타일로 가세요. 돌아가는 길이 생각보다 오래 걸릴 수 있으니 여유를 두세요.
- 가능하면 늪을 피하거나, 빨리 지나가세요.
- 멈추면 게임 시간은 들지만, 기본 설정에서는 배터리가 줄지 않아요. 벽 토큰을 보고하려고 1초 멈추는 것도 배터리에는 영향이 없어요.
