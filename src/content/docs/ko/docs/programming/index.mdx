---

프로그램, 즉 **컨트롤러**는 루프로 실행돼요. 센서를 읽고, 판단하고, 모터를 설정한 뒤, 시뮬레이션을 한 스텝 진행시켜요. 로봇이 하는 모든 일은 이 루프에서 나와요.

여기의 모든 예제는 [스타터 로봇](/docs/robot/)에서 실행돼요. 실행하기 전에 스타터 로봇을 불러오면 예제가 그대로 작동해요. 각 예제에는 Python 버전과 C/C++ 버전이 있어요. 탭에서 언어를 선택하면 사이트 전체가 그 선택을 따라요.

## 학습 과정 \{#the-path\}

| 단계 | 배우는 내용 |
|---|---|
| 1. [첫 번째 프로그램](/docs/programming/first-program/) | 프로그램 작성, 불러오기, 실행 |
| 2. [이동](/docs/programming/movement/) | 주행과 회전 |
| 3. [센서](/docs/programming/sensors/) | 벽, 구멍, 토큰, 자신의 위치 찾기 |
| 4. [미로 탐색](/docs/programming/navigate-the-maze/) | 하나의 완성된 프로그램으로 합치기 |
| 5. [통신](/docs/programming/communication/) | 토큰을 보고하고 점수 얻기 |
| 6. [벽 토큰](/docs/programming/wall-tokens/) | 피해자, 표적, 가짜 구별하기 |
| 7. [탐색과 지도 작성](/docs/programming/exploring/) | 체계적으로 탐색하고 미로 기억하기 |
| 8. [지도 작성 규칙](/docs/rules/mapping/)과 [지도 제출](/docs/programming/map-bonus/) | 지도 보너스 얻기 |

각 단계는 앞 단계를 바탕으로 해요. 아직 읽지 않았다면 [규칙 요약](/docs/rules/)을 먼저 읽으세요. 로봇이 해야 할 일과 점수를 얻는 방법을 설명해요.

C나 C++로 작성한다면 먼저 [C++ 컨트롤러](/docs/programming/cpp/)를 읽고 프로그램을 컴파일하고 실행하는 방법을 알아 두세요.
