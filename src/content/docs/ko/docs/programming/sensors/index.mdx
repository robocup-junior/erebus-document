센서는 로봇에게 세상에 대해 알려 줘요. 모든 센서는 같은 방법으로 사용해요.

1. `robot.getDevice()`로 이름을 지정해 센서를 가져와요.
2. `enable(timeStep)`으로 활성화해요. 그 전에는 아무 값도 주지 않아요.
3. 메인 루프 안에서 읽어요. 값은 `robot.step()`을 실행할 때마다 업데이트돼요.

실제 센서처럼 노이즈가 있어서, 같은 측정값도 스텝마다 조금씩 바뀔 수 있어요. 대회에서 주최 측이 노이즈를 바꾸지 않으므로, 예를 들어 여러 측정값을 비교하는 식으로 노이즈에 강한 프로그램을 만드세요.
