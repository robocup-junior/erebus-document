컬러 센서는 바닥을 보기 때문에 로봇에게 구멍, 늪, 통로에 대해 알려 줘요. 아래를 향하는 1픽셀짜리 카메라예요. 스타터 로봇에서는 이름이 `color`이고, 바퀴가 닿기 전에 구멍을 볼 수 있도록 로봇 앞쪽에 달려 있어요.

## 바닥 색 \{#floor-colours\}

다음 값은 `world2.wbt`에서 스타터 로봇으로 측정한 거예요.

| 바닥 | 빨강 | 초록 | 파랑 |
|---|---:|---:|---:|
| 일반 | 252 | 252 | 252 |
| 늪 | 245 | 222 | 142 |
| 구역 1과 2 사이의 통로 (파랑) | 91 | 91 | 255 |
| 구역 2와 3 사이의 통로 (보라) | 193 | 91 | 251 |
| 구역 1과 4 사이의 통로 (초록) | 48 | 255 | 48 |
| 구역 3과 4 사이의 통로 (빨강) | 255 | 91 | 91 |

:::caution
값은 월드에 따라 달라요. `world1.wbt`에서는 일반 바닥이 약 240으로 읽혀요. 정확한 값 대신 범위를 사용하고, Erebus의 `player_controllers` 폴더에 있는 `calibrateColourSensor.py`로 확인하세요.
:::

구멍에는 검은 테두리가 있어서 구멍 바로 앞에서 바닥이 어두워져요. 체크포인트는 이 센서에게 일반 바닥과 거의 똑같이 보이므로, 자신의 월드에 있는 체크포인트에서 보정하세요.
