컬러 센서는 바닥을 보기 때문에 로봇에게 구멍, 늪, 접촉 타일, 통로에 대해 알려 줘요. 아래를 향하는 1픽셀짜리 카메라예요. 스타터 로봇에서는 이름이 `color`이고, 바퀴가 닿기 전에 구멍을 볼 수 있도록 로봇 앞쪽에 달려 있어요.

## 바닥 색 \{#floor-colours\}

다음은 `world2.wbt`와 `mapping_example_1_cyan_tiles.wbt`에서 스타터 로봇으로 측정한 값이에요.

| 바닥 | 빨강 | 초록 | 파랑 |
|---|---:|---:|---:|
| 일반 | 242 | 242 | 242 |
| 체크포인트 | 254 | 254 | 254 |
| 늪 | 225 | 193 | 115 |
| 접촉 타일(청록색) | 0 | 242 | 242 |
| 구멍(검은 테두리) | 34 | 34 | 34 |
| 구역 1과 2 사이의 통로 (파랑) | 72 | 72 | 254 |
| 구역 2와 3 사이의 통로 (보라) | 161 | 72 | 238 |
| 구역 1과 4 사이의 통로 (초록) | 38 | 253 | 38 |
| 구역 3과 4 사이의 통로 (빨강) | 254 | 72 | 72 |

:::caution
값은 월드와 그래픽 설정에 따라 달라질 수 있어요. 정확한 값 대신 범위를 쓰고, Erebus의 `player_controllers` 폴더에 있는 `calibrateColourSensor.py`로 확인하세요.
:::

구멍에는 검은 테두리가 있어서 구멍 바로 앞에서 바닥이 어두워져요. 체크포인트는 보통 바닥보다 조금 밝을 뿐이므로, 이 값에 의존하기 전에 자신의 월드에 있는 체크포인트에서 보정하세요.
