지도 보너스(Mapping bonus)는 점수를 최대 2.2배로 만들어 주므로 아주 가치가 커요. 보너스를 얻는 방법은 다음과 같아요.

1. [지도 작성 규칙](/docs/rules/mapping/)에 설명된 대로 지도를 배열에 넣어요.
1. 배열의 크기를 보내고, 이어서 1차원으로 펼친 배열을 쉼표로 구분한 UTF-8 텍스트로 보내요.
1. `M`을 보내 지도 평가를 요청해요.
1. 게임을 끝내요. 게임이 끝나면 Erebus가 점수에 보너스를 적용해요.

## 알아 둘 점 \{#things-to-know\}

- 지도는 게임 중 언제든 제출할 수 있지만, **평가는 한 번만 돼요**. 이후의 `M` 메시지는 무시되므로, 지도가 최대한 완성되었을 때 보내세요.
- 시간이 남아 있는지 확인하세요. `M`을 보내기 전에 게임이 끝나면 평가할 지도가 없어요.
- 보너스를 받기 위해 `E`를 보낼 필요는 없어요. 시간이 다 되어도 적용돼요. 하지만 탈출 보너스(Exit bonus)를 얻는 방법은 `E`뿐이고, 그 보너스는 지도 보너스가 적용되기 전에 더해져요.
- 지도에는 시작 타일(`5`)이 있어야 해요. 시작 타일은 지도를 정답에 맞춰 정렬하는 데 사용돼요. 시작 타일이 없으면 지도를 평가할 수 없어요.
- 결과는 제어 창의 기록에 `Map Correctness`로 표시돼요. Webots 콘솔에 `Map scoring error`가 나오면 형식을 확인하세요.
