첫 번째 프로그램은 로봇을 앞으로 주행시키다가 벽 앞에서 멈춰 세워요. 짧지만, 모든 프로그램에 필요한 것이 다 들어 있어요.

<CodeTabs file="hello" />

## 작동 방식 \{#how-it-works\}

1. **로봇을 만들어요.** `Robot()`은 프로그램을 시뮬레이터 안의 로봇과 연결해요.
2. **타임 스텝을 가져와요.** 시뮬레이션은 몇 밀리초 단위의 스텝으로 진행돼요. `getBasicTimeStep()`은 월드의 스텝을 줘요.
3. **장치를 가져와요.** 각 모터와 센서는 이름으로 찾아요. [로봇을 조립할 때](/docs/robot/build/) 붙인 이름이에요.
4. **센서를 활성화해요.** 센서는 활성화되기 전에는 값을 주지 않아요. 타임 스텝은 얼마나 자주 업데이트할지 알려 줘요.
5. **루프를 돌아요.** `robot.step(timeStep)`은 시뮬레이션을 한 스텝 진행시키고, 시뮬레이션이 끝나면 -1을 반환해요. 로봇이 하는 모든 일은 이 루프 안에서 일어나요.

## 실행하기 \{#run-it\}

1. 프로그램을 `hello.py`로 저장하세요.
2. `game/worlds/mapping_example_1.wbt`를 열고, 오른쪽 LOAD 버튼으로 [스타터 로봇](/docs/robot/)을 불러오세요.
3. 왼쪽 LOAD 버튼으로 `hello.py`를 불러오고, 시작 버튼을 누르세요.

로봇이 앞으로 주행하고, 로봇이 멈출 때까지 Webots 콘솔에 앞쪽 벽까지의 거리가 표시돼요. 대신 오류가 보이면 [문제 해결](/docs/troubleshooting/#your-program)을 확인하세요.

:::tip
로봇이 무엇을 하는지 이해하려면 `print`를 사용하세요. 문제를 찾는 가장 간단하고 유용한 도구예요.
:::
