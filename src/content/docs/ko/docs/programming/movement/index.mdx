로봇에는 바퀴가 두 개 있고, 각 바퀴에 모터가 하나씩 달려 있어요. [스타터 로봇](/docs/robot/)에서는 `left wheel motor`와 `right wheel motor`예요. 각 바퀴의 속도를 설정해서 로봇을 움직여요.

| 왼쪽 바퀴 | 오른쪽 바퀴 | 로봇은... |
|---|---|---|
| 앞으로 | 앞으로 | 앞으로 이동 |
| 뒤로 | 뒤로 | 뒤로 이동 |
| 뒤로 | 앞으로 | 제자리에서 왼쪽으로 회전 |
| 앞으로 | 뒤로 | 제자리에서 오른쪽으로 회전 |
| 빠르게 | 느리게 | 오른쪽으로 곡선 주행 |

속도의 단위는 **초당 라디안**이고, 최대 6.28(초당 바퀴 한 바퀴)이에요. 음수 속도는 바퀴를 뒤로 돌려요.

## 주행하기 \{#custom-mdx-id\}

1. 이름으로 각 모터를 가져와요.
2. 제한 없이 돌도록 위치를 무한대로 설정해요.
3. 속도를 설정해요.

모터는 마지막으로 설정한 속도를 유지하므로, 프로그램이 다른 일을 하는 동안에도 로봇은 계속 움직여요. 이 프로그램은 앞으로, 뒤로, 왼쪽으로 제자리 회전을 각각 1초씩 해요.

<CodeTabs file="drive" />

:::note
Webots의 각도는 라디안 단위예요. 변환 방법: 라디안 = 도 × π / 180.
:::

## 바퀴가 얼마나 돌았는지 측정하기 \{#measuring-how-far-a-wheel-turned\}

각 모터에는 인코더라고도 하는 위치 센서가 있어서, 바퀴가 얼마나 돌았는지 라디안 단위로 세요. 정해진 거리를 이동할 때 유용해요. 뒤로 돌면 값이 줄어들어요.

<CodeTabs file="encoders" />

시간으로 동작을 재는 방법은 간단하지만, 결과가 속도에 따라 달라져요. 인코더는 동작 자체를 측정하므로 더 믿을 만해요. 정확하게 회전하려면 [자이로](/docs/programming/sensors/imu/)가 더 좋아요.
