import { Steps } from '@astrojs/starlight/components';

<Steps>

1. [공식 웹사이트](https://www.python.org/downloads/macos/)에서 **Python 3.9 이상**을 설치하세요.

   Homebrew, Anaconda 등으로 이미 Python을 설치했더라도 이 방법으로 설치하는 것을 권장해요. 그렇지 않으면 시뮬레이션이 제대로 작동하지 않을 수 있어요.

2. 터미널을 열고 필요한 라이브러리를 설치하세요.

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. [공식 저장소](https://github.com/cyberbotics/webots/releases/download/R2023b/webots-R2023b.dmg)에서 **Webots R2023b**를 설치하세요.

4. <DownloadErebus />를 다운로드한 뒤 압축을 푸세요.

</Steps>

## 환경 실행하기 \{#run-the-environment\}

월드 파일 `game/worlds/world1.wbt`를 더블 클릭하여 Webots에서 여세요.

Webots가 웹 브라우저에서 Erebus 제어 창을 열어요. 처음 실행할 때는 Erebus가 Python 라이브러리 몇 개를 설치하므로 시간이 좀 걸릴 수 있어요. 창에 08:00 게임 타이머가 표시되면 준비가 끝난 거예요.

![시작할 준비가 된 Erebus 제어 창](../../../../docs/installation/mac/../control-window-ready.png)

다음으로 [규칙 요약](/docs/rules/)을 읽고 게임을 이해하세요. 문제가 생기면 [문제 해결](/docs/troubleshooting/)을 참고하세요.
