<Steps>

1. 터미널을 열고 pip와 필요한 라이브러리를 설치하세요.

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   Ubuntu 24.04에서는 pip가 `externally-managed-environment` 오류를 내며 시스템 Python에 라이브러리 설치를 거부해요. 두 번째 명령에 `--break-system-packages`를 붙이거나, [가상 환경](https://docs.python.org/3/library/venv.html)에 라이브러리를 설치하고 그 Python을 Webots 환경설정에서 지정하세요.

2. **Webots R2025a**를 다운로드하고 설치하세요.

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. <DownloadErebus /> 파일을 다운로드하고 압축을 푸세요.

</Steps>

## 환경 실행하기 \{#run-the-environment\}

터미널에서 월드를 여세요. 경로는 자신의 Erebus 폴더로 바꾸세요.

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots가 웹 브라우저에서 Erebus 제어 창을 열어요. 처음 실행할 때는 Erebus가 Python 라이브러리 몇 개를 설치하고 로봇 모델을 준비하므로 시간이 좀 걸릴 수 있어요. 창에 **Ready**와 08:00 게임 타이머가 표시되면 준비가 끝난 거예요.

![시작할 준비가 된 Erebus 제어 창](../../../../docs/installation/linux/../control-window-ready.png)

처음 실행할 때는 Webots 콘솔에 `ERROR: Skipped PROTO 'custom_robot'`이 표시될 수도 있어요. 무시해도 돼요. Erebus가 로봇 모델을 준비하고 월드를 알아서 다시 불러와요.

다음으로 [규칙 요약](/docs/rules/)을 읽고 게임을 이해하세요. 문제가 생기면 [문제 해결](/docs/troubleshooting/)을 참고하세요.
