import { Steps } from '@astrojs/starlight/components';
import DownloadErebus from '@/components/DownloadErebus.astro';

<Steps>

1. [공식 웹사이트](https://www.python.org/downloads/windows/)에서 64비트 **Python 3.9 이상**을 설치하세요. 설치하는 동안 Python이 PATH에 추가되도록 꼭 설정하세요.

   ![Python 설치 프로그램의 Add Python to PATH 옵션](../../../../docs/installation/windows/python-path.png)

2. PowerShell을 열고 필요한 라이브러리를 설치하세요.

   ```powershell
   python -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. [공식 저장소](https://github.com/cyberbotics/webots/releases/download/R2023b/webots-R2023b_setup.exe)에서 **Webots R2023b**를 설치하세요.

4. <DownloadErebus /> 파일을 다운로드하고 압축을 푸세요.

</Steps>

## 환경 실행하기 \{#run-the-environment\}

월드 파일 `game/worlds/world1.wbt`를 더블클릭해 Webots에서 여세요.

Webots가 웹 브라우저에서 Erebus 제어 창을 열어요. 처음 실행할 때는 Erebus가 Python 라이브러리 몇 개를 설치하므로 시간이 좀 걸릴 수 있어요. 창에 08:00 게임 타이머가 표시되면 준비가 끝난 거예요.

![시작할 준비가 된 Erebus 제어 창](../../../../docs/installation/windows/../control-window-ready.png)

다음으로 [규칙 요약](/docs/rules/)을 읽고 게임을 이해하세요. 문제가 생기면 [문제 해결](/docs/troubleshooting/)을 참고하세요.
