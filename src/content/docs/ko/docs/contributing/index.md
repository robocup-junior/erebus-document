## Erebus 플랫폼에 기여하기 {#contributions-to-the-erebus-platform}

Erebus 플랫폼에 기여하는 방법은 여러 가지가 있어요.
- [저장소에 이슈](https://github.com/robocup-junior/erebus/issues) 올리기: 플랫폼에서 버그를 발견했거나 꼭 있었으면 하는 기능이 있다면 알려 주세요.
- 풀 리퀘스트 보내기: 버그를 직접 고쳤다면 변경 사항을 풀 리퀘스트로 보내 주세요. 검토를 거쳐 병합될 수 있어요.
- [Discord 서버](https://discord.com/invite/6FJxZxk)에서 이야기하기: Discord 서버에서 개발자와 RCJ Rescue 위원회에 연락할 수 있어요. 아이디어를 함께 나눠 주세요!

### 더 깊이 참여하기 {#deeper-involvement}
현재 시뮬레이션 플랫폼의 새 개발자를 적극적으로 찾고 있지는 않아요. 하지만 다음 세대를 위해 이 플랫폼을 유지해 나갈 새로운 인재는 언제나 찾고 있어요. 필요한 기술이 있고 개발 팀에 함께하고 싶다면 Discord 서버에서 플랫폼 개발 팀이나 RoboCupJunior Rescue 위원회에 연락하세요.

## 문서에 기여하기 {#contributions-to-the-documentation}

- [문서 저장소](https://github.com/robocup-junior/erebus-document/issues)에 이슈 올리기.
- [Discord 서버](https://discord.com/invite/6FJxZxk)에서 이야기하기: Discord 서버에서 개발자와 RCJ Rescue 위원회에 연락할 수 있어요. 아이디어를 함께 나눠 주세요!
- 문서 편집자 되기! 문서 작성을 돕고 싶다면 Discord 서버에서 플랫폼 개발 팀에 연락하세요.

이 문서는 [Starlight](https://starlight.astro.build/) 테마를 사용하는 [Astro](https://astro.build/) 사이트예요. 페이지는 `src/content/docs`에 있는 Markdown 파일이고, 모든 페이지 아래쪽에 **페이지 편집** 링크가 있어요. 로컬에서 실행하는 방법은 문서 저장소의 [README](https://github.com/robocup-junior/erebus-document#readme)를 참고하세요.
