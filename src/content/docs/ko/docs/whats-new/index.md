Erebus v26은 2026년 규칙을 구현해요. 이전 버전에서 넘어왔다면, 다음 변경 사항이 로봇에 영향을 줘요.

| 항목 | 2025년까지 | 2026년부터 |
|---|---|---|
| 문자 피해자 (Letter victims) | 문자 H, S, U | 기호 Φ (부상), Ψ (안정), Ω (무사). 보고는 여전히 `H`, `S`, `U`로 해요. |
| 위험물 표지 (Hazmat signs) | 네 가지 위험물 라벨 | [인지 표적(Cognitive targets)](/docs/rules/#cognitive-targets)으로 대체: 값을 더하면 종류가 되는 동심원 색깔 고리예요. 보고는 여전히 `F`, `P`, `C`, `O`로 해요. |
| 가짜 토큰 | - | 신규: 입체 문자로 된 [가짜 피해자(Fake victims)](/docs/rules/#fake-victims)와, 합이 0~3이 아닌 인지 표적. 보고하거나 지도에 표시하지 마세요. |
| 늪 (Swamps) | 시간이 5배 빠르게 소모 | 늪에 처음 들어가면 x5이고, 같은 늪에 다시 들어갈 때마다 1씩 올라가 최대 x10이 돼요. |
| 지도의 장애물 | 지도에 표시 안 함 | 장애물이 있는 타일은 `x`로 표시해요. |
| 지도 보너스 | 최대 x2 | 이제 배율은 정확도 × 1.2 + 1이에요. |
| 센서 노이즈 | - | GPS에 노이즈가 있어요. 대회에서 주최 측이 노이즈 수준을 바꾸지 않아요. |
| 게임 진행 방식 | 이벤트마다 공지 | 서버-클라이언트 구성: 컨트롤러는 자신의 컴퓨터에서 실행되고, 이더넷으로 게임 서버에 연결돼요. [Remote Controller](/docs/competition/remote-controller/)를 참고하세요. |
| 제출 문서 | TDP, 포스터, 동영상 | 추가로, 서버-클라이언트 구성에서 컨트롤러를 실행하는 방법을 보여 주는 짧은 동영상. |
| 불참한 게임 | -50점 | 0점. |

Webots 버전은 바뀌지 않았어요. Erebus v26도 Webots **R2023b**에서 실행돼요.

v26.0.0 이후에 나온 두 버전은 규칙을 바꾸지 않아요. v26.0.1은 가짜 피해자가 있는 예제 월드와, 기존 월드의 피해자를 가짜로 바꾸는 스크립트를 추가했고, v26.1은 구역 4에서 장애물을 표시하는 방식을 수정했어요.

## 프로그램 업데이트하기 {#updating-your-program}

1. 피해자 감지를 새 기호에 맞게 업데이트하세요. 보고하는 문자는 바뀌지 않아요.
2. 위험물 감지를 [인지 표적 읽기](/docs/programming/wall-tokens/#reading-a-cognitive-target)로 바꾸세요.
3. 프로그램이 가짜를 보고하지 않고, 지도에서도 빼도록 하세요.
4. 지도에 장애물을 `x`로 추가하세요.
5. 새로운 늪을 고려해 경로를 계획하세요. 로봇이 같은 늪에 들어갈 때마다 시간이 더 들어요.
6. [서버-클라이언트 구성](/docs/competition/remote-controller/)을 연습하세요.
