title: v27의 새로운 점

---

Erebus v27은 2027년 규칙을 구현해요. v26에서 넘어온다면, 로봇에 영향을 주는 변경 사항은 다음과 같아요.

| 주제 | 2026년까지 | 2027년부터 |
|---|---|---|
| 배터리 | - | 새로 추가: 로봇에 모터 속도에 따라 줄어드는 [배터리](/docs/rules/#the-battery)가 있어요. 다 떨어지면 게임이 끝나요. |
| 접촉 타일 | - | 새로 추가: 청록색 [접촉 타일](/docs/rules/#contact-tiles). 위에서 5초 동안 가만히 있으면 배터리가 교체돼요. 지도에는 `k`로 표시해요. |
| 늪 | 게임 시간이 더 빨리 흘러요: 처음 들어가면 x5, 최대 x10 | 배터리가 더 빨리 줄어요. 게임 시간에는 영향이 없어요. |
| 피해자 | 기호 Φ, Ψ, Ω | [스마일리 얼굴](/docs/rules/#smiley-victims): 슬픈 얼굴(부상), 무표정(안정), 웃는 얼굴(무사). 보고할 때는 여전히 `H`, `S`, `U`를 써요. |
| 가짜 피해자 | 입체적인 기호 | 입체적인 스마일리 얼굴 |
| 게임 정보 | `G`의 응답은 16바이트 | `G`의 응답은 20바이트이고, 마지막에 배터리 잔량이 들어 있어요. [게임 정보](/docs/programming/communication/#game-information)를 참고하세요. |
| 보고 거리 | Erebus v26은 토큰에서 9cm까지의 보고를 받아들였어요 | 규칙대로 반 타일(6cm) |
| 구역 | 네 개의 구역, 구역 4는 선택 | 최대 네 개의 구역: 구역 1은 항상 있고, 운영자는 구역 2~4를 뺄 수 있어요 |
| Webots | R2023b | **R2025a** |
| Python | 3.9 이상 | 3.10 이상 |

Erebus v27 제어 창의 사용법은 [첫 실행](/docs/getting-started/)에서 설명해요.

## 프로그램 업데이트하기 {#updating-your-program}

1. `G`의 응답을 20바이트로 읽어요. 16바이트만 받아들이는 프로그램은 더 이상 게임 정보를 받지 못해요.
1. 배터리 잔량을 보면서, 배터리가 떨어지기 전에 로봇이 접촉 타일에 도착하도록 경로를 계획해요. [배터리](/docs/programming/battery/)를 참고하세요.
1. 접촉 타일을 `k`로 지도에 추가해요.
1. 피해자 감지를 스마일리 얼굴에 맞게 업데이트해요. 보고하는 문자는 바뀌지 않아요.
1. 토큰을 더 가까이에서 보고해요. 로봇의 중심과 보내는 위치 모두 토큰에서 반 타일 이내여야 해요.
1. 이제 늪은 시간 대신 배터리를 소모하므로, 배터리 계획에 넣어요.
1. Webots R2025a와 Python 3.10 이상을 설치하고, 프로그램이 여전히 작동하는지 확인해요. [설치](/docs/installation/)를 참고하세요.
