---
title: 용어집
description: Erebus와 규칙에서 사용하는 용어.
---

| 용어 | 의미 |
|---|---|
| **구역 (Area)** | 경기장을 이루는 네 부분 중 하나로, 구역마다 벽의 종류가 달라요. World Editor에서는 방(room)이라고 불러요. |
| **구역 배율 (Area multiplier, AM)** | 1, 1.25, 1.5 또는 2로, 각 구역의 점수에 적용돼요 |
| **체크포인트 (Checkpoint)** | 은색 타일이에요. 진행 불능 후 로봇은 마지막으로 방문한 체크포인트로 돌아가요. |
| **인지 표적 (Cognitive target)** | 다섯 개의 동심원 색으로 이루어진 벽 토큰으로, 그 합이 위험물 종류를 나타내요. 2026년에 위험물 표지를 대체했어요. |
| **제어 창 (Control window)** | 프로그램을 불러오고 게임을 실행하는 웹 페이지예요. 로봇 창(robot window)이라고도 해요. |
| **컨트롤러 (Controller)** | 여러분의 프로그램 |
| **커스텀 로봇 (Custom robot)** | Robot Customizer로 설계하고 `.json` 파일에서 불러오는 로봇 |
| **탈출 보너스 (Exit bonus, EB)** | 시작 타일로 돌아와 `E`를 보내면 받는 +10% |
| **가짜 (Fake)** | 보고하면 안 되는 토큰: 입체 문자 피해자와 합이 유효하지 않은 인지 표적 |
| **떠 있는 타일 (Floating tile)** | 시작점과 이어진 벽을 따라가서는 도달할 수 없는 타일이에요. 여기에 있는 토큰은 점수가 더 높아요. |
| **진행 불능 (Lack of progress, LoP)** | 로봇이 갇히거나 구멍에 빠졌을 때예요. 로봇은 마지막 체크포인트로 돌아가고 5점을 잃어요. |
| **문자 피해자 (Letter victim)** | Φ, Ψ 또는 Ω 기호가 있는 벽 토큰 |
| **선형 타일 (Linear tile)** | 시작점과 이어진 벽을 따라가서 도달할 수 있는 타일 |
| **Main Supervisor** | 게임을 관리하는 Erebus의 부분이에요. 게임 매니저라고도 해요. |
| **지도 보너스 (Mapping bonus, MB)** | 정확도 × 1.2 + 1의 점수 배율 |
| **지도 행렬 (Map matrix)** | 지도를 나타내는 배열 |
| **통로 (Passage)** | 두 구역을 잇는 색깔 타일 |
| **4분의 1 타일 (Quarter tile)** | 타일의 4분의 1로 너비 6 cm이며, 구역 2와 3에서 사용돼요 |
| **서버-클라이언트 구성 (Server-client setup)** | 게임은 한 컴퓨터에서, 프로그램은 다른 컴퓨터에서 실행돼요. Remote Controller를 참고하세요. |
| **늪 (Swamp)** | 게임 시간이 더 빨리 흐르게 하는 갈색 타일 |
| **TDP** | 기술 설명서(Technical Description Paper) |
| **타일 (Tile)** | 경기장의 단위로, 너비 12 cm |
| **TI, TT, CN, TMI** | 점수 계산에서: 토큰 식별, 토큰 종류, 체크포인트 통과, 토큰 오식별 |
| **벽 토큰 (Wall token)** | 벽에서 식별해야 하는 모든 것: 문자 피해자와 인지 표적 |
| **월드 (World)** | `.wbt` 파일로 된 맵 |
