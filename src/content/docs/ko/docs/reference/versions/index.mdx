import { archivedVersion, versions } from '@/data/versions';

참가하는 대회의 규칙에 맞는 문서를 사용하세요. 최근 2년간의 버전을 지원하며, 모든 페이지의 로고 옆 메뉴에서 버전 목록을 볼 수 있어요.

<table>
	<thead>
		<tr>
			<th>버전</th>
			<th>규칙</th>
			<th>Webots</th>
			<th>문서</th>
		</tr>
	</thead>
	<tbody>
		{
			versions.map((version) => (
				<tr>
					<td>{version.name}{version.current && !archivedVersion && ' (최신)'}</td>
					<td>{version.rules}</td>
					<td>{version.webots}</td>
					<td>
						<a href={version.current ? '/docs/' : version.url}>{version.current ? '현재 페이지' : '열기'}</a>
					</td>
				</tr>
			))
		}
	</tbody>
</table>

Erebus의 모든 릴리스는 [Releases 페이지](https://github.com/robocup-junior/erebus/releases)에 있고, 각 릴리스의 변경 사항은 [변경 로그](https://github.com/robocup-junior/erebus/blob/master/CHANGELOG.md)에 있어요.

연도별 규칙은 [RoboCupJunior 웹사이트](https://junior.robocup.org/rescue/)에 공개돼요.
