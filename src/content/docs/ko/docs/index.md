Erebus는 로봇 시뮬레이션 대회 환경이에요. 로봇을 설계하고, 그 로봇이 자율적으로 미로를 탐색하고, 벽 토큰을 찾아 식별하고, 장애물과 함정을 피하고, 배터리가 떨어지지 않게 하고, 환경의 지도를 만들도록 프로그래밍해요.

이 문서는 **RoboCupJunior Rescue Simulation 2027** 규칙을 위한 **Erebus v27**을 다뤄요. 지원하는 다른 버전은 [버전](/docs/reference/versions/)을 참고하세요.

## 학습 과정 {#the-learning-path}
단계를 순서대로 따라가세요. 각 단계는 앞 단계를 바탕으로 해요.

| 단계 | 페이지 | 할 수 있게 되는 것 |
|---|---|---|
| **시작** | [Erebus란?](/docs/introduction/), [설치](/docs/installation/) | 무엇을 하는지 알고, 필요한 것을 모두 설치해요 |
| **1. 게임** | [규칙 요약](/docs/rules/) | 미션, 경기장, 점수 얻는 법을 알아요 |
| **2. 로봇** | [로봇 준비하기](/docs/robot/), [로봇 조립하기](/docs/robot/build/) | Erebus에 스타터 로봇을 불러와요 |
| **3. 첫 실행** | [첫 실행](/docs/getting-started/) | 로봇이 탐색하는 모습을 보고, 제어 창을 알아요 |
| **4. 프로그래밍 기초** | [첫 번째 프로그램](/docs/programming/first-program/), [이동](/docs/programming/movement/), [센서](/docs/programming/sensors/) | 로봇을 움직이고 감지하게 만들어요 |
| **5. 게임 플레이** | [미로 탐색](/docs/programming/navigate-the-maze/), [통신](/docs/programming/communication/), [벽 토큰](/docs/programming/wall-tokens/), [배터리](/docs/programming/battery/), [탐색과 지도 작성](/docs/programming/exploring/), [지도 작성 규칙](/docs/rules/mapping/), [지도 제출](/docs/programming/map-bonus/) | 모든 방법으로 점수를 얻어요 |
| **6. 대회 참가** | [대회 준비](/docs/competition/), [Remote Controller](/docs/competition/remote-controller/) | 대회에 나갈 준비를 해요 |

모든 예제는 [스타터 로봇](/docs/robot/)을 사용하므로, 실행하기 전에 스타터 로봇을 불러오세요.
