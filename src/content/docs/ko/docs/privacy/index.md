## 분석 {#analytics}
이 사이트는 어떤 페이지를 방문하는지 파악하여 페이지를 개선하기 위해 [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/)를 사용해요. 쿠키 없이, 개별 방문자를 식별하지 않고 방문 수만 세요.

## 브라우저에 저장되는 것 {#what-is-stored-in-your-browser}
이 사이트는 몇 가지 설정을 브라우저에 저장하며, 이 설정은 어디에도 전송되지 않아요.

- 테마
- 코드 예제에서 선택한 언어 탭

이 사이트는 쿠키를 사용하지 않아요.
