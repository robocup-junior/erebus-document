Usa la documentación que corresponde a las reglas de tu competición. Damos soporte a las versiones de los dos últimos años, y el menú junto al logotipo las muestra en todas las páginas.

	</tbody>
</table>

Todas las versiones de Erebus están en la [página de Releases](https://github.com/robocup-junior/erebus/releases), y los cambios de cada una están en el [registro de cambios](https://github.com/robocup-junior/erebus/blob/master/CHANGELOG.md).

Las reglas de cada año se publican en el [sitio web de RoboCupJunior](https://junior.robocup.org/rescue/).
