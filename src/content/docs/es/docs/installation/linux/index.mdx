import DownloadErebus from '@/components/DownloadErebus.astro';

<Steps>

1. Abre la terminal e instala pip y las bibliotecas necesarias:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

2. Descarga e instala **Webots R2023b**:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2023b/webots_2023b_amd64.deb
   sudo apt install ./webots_2023b_amd64.deb
   ```

3. Descarga <DownloadErebus /> y descomprímelo.

</Steps>

## Ejecutar el entorno \{#run-the-environment\}

Abre el mundo desde la terminal, cambiando la ruta por la de tu carpeta de Erebus:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots abre la ventana de control de Erebus en tu navegador web. La primera vez, Erebus instala algunas bibliotecas de Python, lo que puede tardar un rato. Está lista cuando la ventana muestra el temporizador de partida en 08:00:

![La ventana de control de Erebus, lista para empezar](../../../../docs/installation/linux/../control-window-ready.png)

A continuación, lee el [Resumen de las reglas](/docs/rules/) para entender el juego. Si algo sale mal, consulta [Solución de problemas](/docs/troubleshooting/).
