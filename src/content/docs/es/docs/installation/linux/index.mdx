<Steps>

1. Abre la terminal e instala pip y las bibliotecas necesarias:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   En Ubuntu 24.04, pip se niega a instalar bibliotecas en el Python del sistema, con un error `externally-managed-environment`. Añade `--break-system-packages` al segundo comando, o instala las bibliotecas en un [entorno virtual](https://docs.python.org/3/library/venv.html) y configura su Python en las preferencias de Webots.

2. Descarga e instala **Webots R2025a**:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. Descarga <DownloadErebus /> y descomprímelo.

</Steps>

## Ejecutar el entorno \{#run-the-environment\}

Abre el mundo desde la terminal, cambiando la ruta por la de tu carpeta de Erebus:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots abre la ventana de control de Erebus en tu navegador web. La primera vez, Erebus instala algunas bibliotecas de Python y prepara el modelo del robot, lo que puede tardar un rato. Está lista cuando la ventana muestra **Ready** y el temporizador de partida en 08:00:

![La ventana de control de Erebus, lista para empezar](../../../../docs/installation/linux/../control-window-ready.png)

La primera vez, la consola de Webots también puede mostrar `ERROR: Skipped PROTO 'custom_robot'`. Puedes ignorarlo: Erebus prepara el modelo del robot y vuelve a cargar el mundo por sí solo.

A continuación, lee el [Resumen de las reglas](/docs/rules/) para entender el juego. Si algo sale mal, consulta [Solución de problemas](/docs/troubleshooting/).
