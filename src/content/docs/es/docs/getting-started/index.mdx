En esta página ejecutas un programa completo en tu robot y aprendes a usar la ventana de control de Erebus. Necesitas [Erebus instalado](/docs/installation/) y [tu robot](/docs/robot/).

## La carpeta de Erebus \{#the-erebus-folder\}
Estas son las carpetas principales de la versión que descargaste:

| Carpeta | Contenido |
|---|---|
| `game/worlds` | Los mundos (archivos `.wbt`). Abre uno de ellos para empezar. |
| `game/logs` | Los registros que se escriben al final de cada partida |
| `match-results` | Una carpeta por cada partida, con su repetición y el resultado de su mapa |
| `player_controllers` | Controladores de ejemplo |

## La ventana de control \{#the-control-window\}
1. Abre `game/worlds/world1.wbt` en Webots.
1. Webots abre la ventana de control de Erebus (la ventana de robot del Main Supervisor) en tu navegador web. Aquí cargas tu programa y ejecutas la partida.

![La ventana de control de Erebus](../../../docs/getting-started/control_window.png)

De arriba abajo:

| Parte | Uso |
|---|---|
| Mundo y estado | El nombre del mundo y el estado de la partida: Ready, Running, Paused o Finished |
| **Robot setup** | Carga tu programa y tu robot, y conecta un controlador remoto. Ver más abajo. |
| **Advanced setup** | Opciones, explicadas más abajo |
| **Worlds** | Cambia a otro mundo |
| Puntuación | La puntuación actual |
| **Robot battery** | El nivel de batería del robot. Por debajo del 20 % muestra "Low battery". Consulta [Batería](/docs/programming/battery/). |
| **Simulation remaining** | El tiempo de partida que queda. **Real-world allowance** muestra cuánto tiempo real queda de más respecto al tiempo de partida. La partida termina cuando cualquiera de los dos se agota. |
| Controles de la partida | Ejecutar, pausar, reubicar, reiniciar, rendirse y guardar el mapa. Ver más abajo. |
| **Match events** | El historial de la partida, lo más reciente primero. **Export CSV** lo guarda en un archivo. |

El botón de arriba a la derecha abre la misma ventana como una ventana del navegador aparte y más pequeña.

:::note
Si [Wireshark](/docs/installation/#optional-wireshark) no está instalado, la ventana también muestra un aviso de que el acceso a la red no se vigila y te pide que lo confirmes. Esta vigilancia es para los organizadores en las competiciones, así que puedes confirmar el aviso y practicar como siempre.
:::

### Robot setup \{#robot-setup\}
Pulsa **Robot setup** para cargar tu programa y tu robot.

![El panel Robot setup, con un programa y un robot cargados](../../../docs/getting-started/robot-setup.png)

| Parte | Uso |
|---|---|
| **Controller** | **Load file** carga el programa de tu robot. Los archivos de Python se cargan tal cual. Los programas en C y C++ deben compilarse primero. |
| **Robot JSON** | **Load file** carga tu robot, el archivo `.json` hecho con el [Robot Customizer](/docs/robot/customizer/) |
| **Keep files after Reset** | Mantiene tu programa y tu robot cargados cuando se reinicia la partida. Activado por defecto. |
| **Reload before Run** | Vuelve a cargar tu programa desde **Original controller file** cada vez que ejecutas una partida, para usar tus últimos cambios. Escribe la ruta del archivo en el ordenador que ejecuta Webots. |
| **Remote mode** | Permite que un programa que se ejecuta fuera de Webots controle el robot. Consulta [Controlador remoto](/docs/competition/remote-controller/). **Keep on Reset** lo mantiene activado al reiniciar la partida. |
| **Docker project path** | Carpeta con un `Dockerfile`, para ejecutar tu controlador en un contenedor con **Run Docker**. Consulta el repositorio [erebus-dockerfiles](https://github.com/robocup-junior/erebus-dockerfiles). Es opcional. |

### Controles de la partida \{#match-controls\}

![Los controles de la partida](../../../docs/getting-started/match-controls.png)

| Botón | Uso |
|---|---|
| **Run match** | Inicia la partida. El robot aparece en el mundo y tu programa empieza. |
| **Pause** | Detiene el robot temporalmente. Pulsa **Run match** para continuar. |
| **Relocate** | Declara una falta de progreso: el robot vuelve al último punto de control alcanzado y pierdes 5 puntos |
| **Reset** | Reinicia la partida y el mundo |
| **Give up** | Termina la partida |
| **Save map** | Guarda el resultado del mapa que envió tu robot y lo abre. Consulta [Enviar el mapa](/docs/programming/map-bonus/). |

## Ejecuta un programa \{#run-a-program\}
<a href={mazeUrl} download="maze.py">Descarga maze.py</a>, un programa completo que hace recorrer el laberinto al robot. Es el programa que escribirás tú en [Recorre el laberinto](/docs/programming/navigate-the-maze/).

1. Abre `game/worlds/world1.wbt`.
1. Pulsa **Robot setup** y carga tu robot con **Load file** en **Robot JSON**, si aún no lo has hecho.
1. Carga `maze.py` con **Load file** en **Controller**. El nombre de cada archivo aparece cuando se carga.
1. Pulsa **Run match**. El robot aparece en el mundo y empieza a moverse.
1. Para detener el robot temporalmente, pulsa **Pause**.
1. Si el robot se atasca, pulsa **Relocate** para provocar una falta de progreso.
1. Pulsa **Reset** para reiniciar la partida. Tu programa y tu robot siguen cargados, así que puedes ejecutarla otra vez.

El programa necesita OpenCV, que instalaste con las demás [bibliotecas de Python](/docs/installation/#python-libraries). Los mensajes de tu programa, y los errores, aparecen en la consola de Webots.

Mientras la partida está en marcha, los eventos de la partida aparecen en la parte inferior de la ventana. Te dicen exactamente por qué ganaste o perdiste puntos, así que son la mejor herramienta para comprobar tu programa.

![La ventana de control durante una partida, con los eventos de la partida](../../../docs/getting-started/control_window_running.png)

`maze.py` va a toda velocidad y nunca reemplaza su batería, así que en `world1.wbt` la partida termina en menos de dos minutos, con `Battery depleted`. Aprenderás a cuidar la batería en [Batería](/docs/programming/battery/).

Al final de la partida, la misma información se guarda en la carpeta `game/logs`. La partida también se guarda como repetición 3D interactiva en la carpeta `match-results`: abre `recording/replay.html` en tu navegador para verla de nuevo.

## Usar otros mundos \{#using-other-worlds\}
Pulsa **Worlds** para cambiar a otro mundo. Busca un mundo por su nombre, elígelo y pulsa **Load world**. También puedes añadir los tuyos, hechos con el [World Editor](/docs/tools/world-editor/).

![El panel Worlds de la ventana de control](../../../docs/getting-started/worlds.png)

Los mundos incluidos en Erebus v27 son:

| Mundo | Propósito |
|---|---|
| `2027_d1r1.wbt`, `2027_d1r2.wbt`, `2027_d2r1.wbt`, `2027_d2r2.wbt` | Mundos de ejemplo para las reglas de 2027, con baldosas de contacto y víctimas falsas |
| `world1.wbt`, `world2.wbt` | Mundos de ejemplo. `world2.wbt` incluye el área 4. |
| `world3.wbt`, `world4.wbt` | Mundos de ejemplo más grandes, que también incluyen **víctimas falsas** |
| De `mapping_example_1.wbt` a `mapping_example_3.wbt` | Mundos para probar tu mapeo. Consulta [Mapeo](/docs/rules/mapping/). |
| `mapping_example_1_cyan_tiles.wbt` | `mapping_example_1.wbt` con dos baldosas de contacto |
| `NewPassages.wbt` | Ejemplo de los pasos entre áreas |

## Advanced setup \{#advanced-setup\}
![El panel Advanced setup de la ventana de control](../../../docs/getting-started/settings.png)

| Ajuste | Uso |
|---|---|
| Show head-up display | Muestra la puntuación, el tiempo y los últimos eventos en la ventana de Webots |
| Automatic camera | Hace que la vista siga al robot |
| HTML replay recording | Guarda cada partida como repetición 3D interactiva en la carpeta `match-results` |
| Automatic map result | Guarda y abre el resultado del mapa en cuanto el robot lo envía |
| Disable automatic LoP | Desactiva la falta de progreso automática tras 20 segundos. Solo para depurar. |
| Enable debugging | Muestra información adicional en la consola de Webots, por ejemplo por qué se rechazó el informe de una marca |

Las **References** de la parte inferior de la ventana llevan al registro de cambios, a esta documentación y a las herramientas para crear mundos y robots. Para crear mundos con las reglas de 2027, usa el [World Editor](https://world.erebus.rcj.cloud/).

## Mover el robot a mano adonde quieras \{#manually-move-the-robot-where-you-want-it-to-go\}
Cuando haces clic en un robot en la ventana de simulación, aparecen flechas roja, verde y azul. Arrástralas con el ratón para mover el robot a cualquier posición. Ten en cuenta que el robot no se muestra hasta que el programa ha empezado.
![El robot seleccionado en Webots, con flechas para moverlo](../../../docs/getting-started/manual.png)
