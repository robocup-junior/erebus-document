Erebus es un entorno de competición de simulación de robots. Diseñas un robot y lo programas para que explore un laberinto de forma autónoma, encuentre e identifique marcas en las paredes, evite obstáculos y trampas, mantenga su batería cargada, y construya un mapa del entorno.

Esta documentación trata de **Erebus v27**, para las reglas de **RoboCupJunior Rescue Simulation 2027**. Consulta [Versiones](/docs/reference/versions/) para ver las otras versiones compatibles.

## El itinerario de aprendizaje {#the-learning-path}
Sigue los pasos en orden. Cada uno se basa en el anterior.

| Paso | Páginas | Lo que conseguirás... |
|---|---|---|
| **Inicio** | [¿Qué es Erebus?](/docs/introduction/), [Instalación](/docs/installation/) | Saber lo que estás haciendo y tenerlo todo instalado |
| **1. El juego** | [Resumen de las reglas](/docs/rules/) | Conocer la misión, el campo y cómo puntuar |
| **2. Tu robot** | [Consigue tu robot](/docs/robot/), [Construye tu robot](/docs/robot/build/) | Tener el robot inicial cargado en Erebus |
| **3. Primera ejecución** | [Tu primera ejecución](/docs/getting-started/) | Ver a tu robot explorar y conocer la ventana de control |
| **4. Fundamentos de programación** | [Tu primer programa](/docs/programming/first-program/), [Movimiento](/docs/programming/movement/), [Sensores](/docs/programming/sensors/) | Hacer que tu robot se mueva y perciba |
| **5. Juega** | [Recorre el laberinto](/docs/programming/navigate-the-maze/), [Comunicación](/docs/programming/communication/), [Marcas en las paredes](/docs/programming/wall-tokens/), [Batería](/docs/programming/battery/), [Explorar y mapear](/docs/programming/exploring/), [Reglas del mapa](/docs/rules/mapping/), [Enviar el mapa](/docs/programming/map-bonus/) | Sumar puntos de todas las formas |
| **6. Compite** | [Prepararse para una competición](/docs/competition/), [Remote Controller](/docs/competition/remote-controller/) | Estar listo para una competición |

Todos los ejemplos usan el [robot inicial](/docs/robot/), así que cárgalo antes de ejecutarlos.
