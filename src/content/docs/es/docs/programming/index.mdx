---
title: Programar tu robot
description: El camino desde tu primer programa hasta un robot que juega la partida completa.
---

Un programa, o **controlador** (controller), funciona en bucle: lee los sensores, decide, ajusta los motores y deja que la simulación avance un paso. Todo lo que hace tu robot sale de este bucle.

Todos los ejemplos de aquí funcionan en el [robot inicial](/docs/robot/). Cárgalo antes de ejecutarlos y funcionarán tal cual. Cada ejemplo tiene una versión en Python y otra en C/C++: elige tu lenguaje en las pestañas y todo el sitio seguirá tu elección.

## El camino \{#the-path\}

| Paso | Aprendes a... |
|---|---|
| 1. [Tu primer programa](/docs/programming/first-program/) | Escribir, cargar y ejecutar un programa |
| 2. [Movimiento](/docs/programming/movement/) | Avanzar y girar |
| 3. [Sensores](/docs/programming/sensors/) | Encontrar paredes, agujeros, marcas y tu posición |
| 4. [Recorre el laberinto](/docs/programming/navigate-the-maze/) | Juntarlo todo en un programa completo |
| 5. [Comunicación](/docs/programming/communication/) | Informar de las marcas y sumar puntos |
| 6. [Marcas en las paredes](/docs/programming/wall-tokens/) | Distinguir víctimas, objetivos y falsos |
| 7. [Explorar y mapear](/docs/programming/exploring/) | Explorar de forma sistemática y recordar el laberinto |
| 8. [Reglas del mapa](/docs/rules/mapping/) y [Enviar el mapa](/docs/programming/map-bonus/) | Conseguir la bonificación por mapa |

Cada paso se basa en los anteriores. Si todavía no lo has leído, lee primero el [Resumen de las reglas](/docs/rules/): explica qué tiene que hacer tu robot y qué da puntos.

Si escribes en C o C++, lee primero [Controladores en C++](/docs/programming/cpp/) para compilar y ejecutar tus programas.
