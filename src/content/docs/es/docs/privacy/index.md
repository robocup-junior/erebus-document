Esta documentación es un sitio web estático. No tiene cuentas y no pide ningún dato personal.

## Analítica {#analytics}
Este sitio usa [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) para ver qué páginas se visitan y así poder mejorarlas. Cuenta las visitas sin cookies y sin identificar a cada visitante.

## Qué se guarda en tu navegador {#what-is-stored-in-your-browser}
El sitio guarda algunos ajustes en tu navegador, que no se envían a ningún sitio:

- Tu tema
- La pestaña de lenguaje seleccionada en los ejemplos de código

Este sitio no usa cookies.
