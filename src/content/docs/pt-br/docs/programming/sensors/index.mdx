Os sensores contam ao seu robô como é o mundo. Todos os sensores são usados da mesma forma:

1. Obtenha-o pelo nome com `robot.getDevice()`.
2. Ative-o com `enable(timeStep)`. Até lá, ele não fornece nenhum valor.
3. Leia-o dentro do laço principal. Os valores são atualizados após cada `robot.step()`.

Como sensores reais, eles têm ruído: a mesma leitura pode mudar um pouco de um passo para o outro. Os organizadores não mudam o ruído na competição, então deixe seu programa robusto a ele, por exemplo comparando várias leituras.
