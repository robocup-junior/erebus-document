Esta documentação é um site estático. Ele não tem contas e não pede nenhuma informação pessoal.

## Estatísticas de acesso {#analytics}
Este site usa o [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) para ver quais páginas são visitadas, para que possamos melhorá-las. Ele conta as visitas sem cookies e sem identificar visitantes individuais.

## O que fica guardado no seu navegador {#what-is-stored-in-your-browser}
O site guarda algumas configurações no seu navegador, que não são enviadas a lugar nenhum:

- O seu tema
- A aba de linguagem selecionada nos exemplos de código

Este site não usa cookies.
