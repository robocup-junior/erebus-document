## Contribuições para a plataforma Erebus {#contributions-to-the-erebus-platform}

Há várias formas de contribuir com a plataforma Erebus:
- Abra uma [issue no repositório](https://github.com/robocup-junior/erebus/issues): avise-nos se encontrar um bug na plataforma ou se houver uma funcionalidade que você acha que ela deveria ter.
- Faça um pull request: se você mesmo corrigir um bug, pode enviar a mudança em um pull request para que ela seja revisada e incorporada.
- Fale com a gente no [servidor do Discord](https://discord.com/invite/6FJxZxk): lá você encontra os desenvolvedores e o Comitê da RCJ Rescue. Compartilhe suas ideias com a gente!

### Envolvimento mais profundo {#deeper-involvement}
No momento, não estamos procurando ativamente novos desenvolvedores para a plataforma de simulação. Mesmo assim, estamos sempre em busca de novos talentos para manter a plataforma para as próximas gerações. Se você tem as habilidades e gostaria de fazer parte da equipe de desenvolvimento, entre em contato com a equipe de desenvolvimento da plataforma ou com o Comitê da RoboCupJunior Rescue pelo servidor do Discord.

## Contribuições para a documentação {#contributions-to-the-documentation}

- Abra uma issue no [repositório da documentação](https://github.com/robocup-junior/erebus-document/issues).
- Fale com a gente no [servidor do Discord](https://discord.com/invite/6FJxZxk): lá você encontra os desenvolvedores e o Comitê da RCJ Rescue. Compartilhe suas ideias com a gente!
- Torne-se um editor da documentação! Se você quiser ajudar a escrever a documentação, entre em contato com a equipe de desenvolvimento da plataforma no servidor do Discord.

A documentação é um site [Astro](https://astro.build/) que usa o tema [Starlight](https://starlight.astro.build/). As páginas são arquivos Markdown em `src/content/docs`, e toda página tem um link **Editar página** no rodapé. Veja o [README](https://github.com/robocup-junior/erebus-document#readme) do repositório da documentação para saber como rodá-la localmente.
