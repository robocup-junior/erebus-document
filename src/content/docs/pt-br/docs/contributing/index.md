## Contribuições para a plataforma Erebus  {#contributions-to-the-erebus-platform}

Se você quiser contribuir com a plataforma Erebus, no momento existem algumas formas de fazer isso.
- Abrir [issues no repositório](https://github.com/robocup-junior/erebus/issues): avise-nos se encontrar algum bug na plataforma ou uma funcionalidade que você acha que deveria ser incluída.
- Pull requests: se você conseguir corrigir o bug por conta própria, pode abrir um pull request com essa mudança para que ela possa ser aplicada.
- Fale com a gente pelo [servidor do Discord](https://discord.com/invite/6FJxZxk): você pode se comunicar conosco (desenvolvedores, comitê da RCJ Rescue) pelo servidor do Discord. Compartilhe suas ideias com a gente!

### Envolvimento mais profundo {#deeper-involvement}
No momento, não estamos procurando ativamente novos desenvolvedores para a plataforma de simulação. Mesmo assim, estamos sempre em busca de novos talentos para manter esta plataforma para as próximas gerações. Se você sente que tem as habilidades e gostaria de fazer parte da equipe de desenvolvimento desta plataforma, entre em contato com a equipe de desenvolvimento da plataforma ou com o comitê da RoboCupJunior Rescue pelo servidor do Discord.

## Contribuições para a documentação {#contributions-to-the-documentation}

- Abrir issues clicando em [Documentation issue](https://github.com/robocup-junior/erebus-document/issues) e criando uma issue no repositório do projeto.
- Fale com a gente pelo [servidor do Discord](https://discord.com/invite/6FJxZxk): você pode se comunicar conosco (desenvolvedores, comitê da RCJ Rescue) pelo servidor do Discord. Compartilhe suas ideias com a gente!
- Torne-se um editor ativo da documentação! Se você quiser participar ativamente da escrita da documentação, entre em contato com a equipe de desenvolvimento da plataforma no servidor do Discord.

A documentação é um site [Astro](https://astro.build/) que usa o tema [Starlight](https://starlight.astro.build/). As páginas são arquivos Markdown em `src/content/docs`, e toda página tem um link **Editar página** no rodapé. Veja o [README](https://github.com/robocup-junior/erebus-document#readme) do repositório da documentação para saber como rodá-la localmente.
