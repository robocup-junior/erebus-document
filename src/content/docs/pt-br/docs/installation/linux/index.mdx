import { Steps } from '@astrojs/starlight/components';
import DownloadErebus from '@/components/DownloadErebus.astro';

<Steps>

1. Abra o terminal e instale o pip e as bibliotecas necessárias:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   No Ubuntu 24.04, o pip se recusa a instalar bibliotecas no Python do sistema, com um erro `externally-managed-environment`. Adicione `--break-system-packages` ao segundo comando, ou instale as bibliotecas em um [ambiente virtual](https://docs.python.org/3/library/venv.html) e configure o Python dele nas preferências do Webots.

2. Baixe e instale o **Webots R2025a**:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. Baixe o <DownloadErebus /> e descompacte o arquivo.

</Steps>

## Execute o ambiente \{#run-the-environment\}

Abra o mundo pelo terminal, trocando o caminho pelo da sua pasta do Erebus:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

O Webots abre a janela de controle do Erebus no seu navegador. Na primeira vez, o Erebus instala algumas bibliotecas Python e prepara o modelo do robô, o que pode demorar um pouco. Ele está pronto quando a janela mostra **Ready** e o cronômetro da partida em 08:00:

![A janela de controle do Erebus, pronta para começar](../../../../docs/installation/linux/../control-window-ready.png)

Na primeira vez, o console do Webots também pode mostrar `ERROR: Skipped PROTO 'custom_robot'`. Você pode ignorar: o Erebus prepara o modelo do robô e recarrega o mundo sozinho.

Em seguida, leia o [Resumo das regras](/docs/rules/) para entender o jogo. Se algo der errado, veja [Solução de problemas](/docs/troubleshooting/).
