## Requisitos de software \{#software-requirements\}
O sistema de simulação é formado por três componentes, e você precisa instalar cada um deles. A instalação é fácil, mas baixar e instalar o Webots pode demorar um pouco. Os três componentes são:

1. Simulador de robôs Webots, versão **R2025a**: o ambiente de simulação. O Erebus v27 não é compatível com outras versões do Webots.
1. Erebus: os mundos e o Main Supervisor, que aplica as regras e calcula a pontuação. A versão mais recente é a **v<span data-erebus-version>{latestVersion}</span>**.
1. Python, versão **3.10 ou mais recente**: necessário para rodar o próprio Erebus e para escrever os controladores dos robôs. Você também pode escrever controladores em C/C++.

## Requisitos mínimos do sistema \{#minimum-system-requirements\}
* Linux: Ubuntu 22.04 LTS ou 24.04 LTS
* Windows: Windows 10 ou 11, 64 bits
* macOS: macOS 12 "Monterey", 13 "Ventura" ou 14 "Sonoma". Essas são as versões suportadas pelo Webots R2025a. Versões mais novas do macOS também podem funcionar: esta documentação foi testada no macOS 26.
* CPU: dual-core, 2 GHz
* RAM: 2 GB
* Placa de vídeo: NVIDIA ou AMD, com suporte a OpenGL 3.3 e 512 MB de memória

## Bibliotecas Python \{#python-libraries\}
O Erebus precisa das bibliotecas Python abaixo. A maioria delas é instalada automaticamente quando ele inicia, mas **o OpenCV não é**, então você precisa instalá-lo por conta própria. O guia de cada sistema operacional inclui essa etapa. O arquivo `requirements.txt` na pasta do Erebus lista as versões com que o Erebus foi testado.

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```

## Opcional: Wireshark \{#optional-wireshark\}
O Erebus pode monitorar a rede durante uma partida em busca de acessos não autorizados ao jogo, o que os organizadores usam nas competições. Para isso ele precisa do [Wireshark](https://www.wireshark.org/download.html). Você não precisa dele para treinar: sem ele, a janela de controle mostra um aviso de que o acesso à rede não está sendo monitorado, que você pode confirmar e ignorar.
