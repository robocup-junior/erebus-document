## Requisitos de software \{#software-requirements\}
O sistema de simulação é formado por três componentes, e você precisa instalar cada um deles. A instalação é fácil, mas baixar e instalar o Webots pode demorar um pouco. Os três componentes são:

1. Simulador de robôs Webots, versão **R2023b**: o ambiente de simulação. O Erebus v26 não é compatível com outras versões do Webots.
1. Erebus: os mundos e o Main Supervisor, que aplica as regras e calcula a pontuação. A versão mais recente é a **v26.1**.
1. Python, versão **3.9 ou mais recente**: necessário para rodar o próprio Erebus e para escrever os controladores dos robôs. Você também pode escrever controladores em C/C++.

## Requisitos mínimos do sistema \{#minimum-system-requirements\}
* Linux: Ubuntu 20.04 LTS ou 22.04 LTS
* Windows: Windows 10 ou 11, 64 bits
* macOS: macOS 11 "Big Sur" ou 12 "Monterey". Essas são as versões suportadas pelo Webots R2023b. Versões mais novas do macOS também podem funcionar: esta documentação foi testada no macOS 26.
* CPU: dual-core, 2 GHz
* RAM: 2 GB
* Placa de vídeo: NVIDIA ou AMD, com suporte a OpenGL e 512 MB de memória

## Bibliotecas Python \{#python-libraries\}
O Erebus precisa das bibliotecas Python abaixo. A maioria delas é instalada automaticamente quando ele inicia, mas **o OpenCV não é**, então você precisa instalá-lo por conta própria. O guia de cada sistema operacional inclui essa etapa.

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```
