---
title: Glossar
description: Die Begriffe, die in Erebus und in den Regeln verwendet werden.
---

| Begriff | Bedeutung |
|---|---|
| **Bereich** (Area) | Einer der vier Teile des Spielfelds, jeder mit einer eigenen Art von Wänden. Der World Editor nennt sie Räume (rooms). |
| **Bereichsmultiplikator** (Area multiplier, AM) | 1, 1,25, 1,5 oder 2, angewendet auf die Punkte jedes Bereichs |
| **Akku** (Battery) | Entlädt sich mit der Geschwindigkeit der Motoren. Ist er leer, endet das Spiel. |
| **Checkpoint** | Eine silberne Kachel. Nach einem fehlenden Fortschritt kehrt der Roboter zum zuletzt besuchten Checkpoint zurück. |
| **Kognitives Ziel** (Cognitive target) | Eine Wandmarkierung aus fünf konzentrischen Farben, deren Summe einen Gefahrguttyp ergibt. Hat 2026 die Gefahrgutschilder (Hazmat signs) ersetzt. |
| **Kontaktkachel** (Contact tile) | Eine cyanfarbene Kachel, auf der der Akku ausgetauscht wird, wenn der Roboter 5 Sekunden lang darauf stillsteht |
| **Steuerfenster** (Control window) | Die Webseite, auf der du Programme lädst und das Spiel startest. Wird auch Roboterfenster (robot window) genannt. |
| **Controller** | Dein Programm |
| **Eigener Roboter** (Custom robot) | Ein Roboter, der mit dem Robot Customizer entworfen und aus einer `.json`-Datei geladen wird |
| **Ausgangsbonus** (Exit bonus, EB) | +10 %, wenn du zur Startkachel zurückkehrst und `E` sendest |
| **Fälschung** (Fake) | Eine Markierung, die nicht gemeldet werden darf: dreidimensionale Smiley-Opfer und kognitive Ziele mit ungültiger Summe |
| **Schwebende Kachel** (Floating tile) | Eine Kachel, die man nicht erreicht, wenn man den mit dem Start verbundenen Wänden folgt. Markierungen dort sind mehr wert. |
| **Fehlender Fortschritt** (Lack of progress, LoP) | Wenn der Roboter feststeckt oder in ein Loch fällt. Er kehrt zum letzten Checkpoint zurück und verliert 5 Punkte. |
| **Lineare Kachel** (Linear tile) | Eine Kachel, die man erreicht, wenn man den mit dem Start verbundenen Wänden folgt |
| **Main Supervisor** | Der Teil von Erebus, der das Spiel verwaltet. Wird auch Supervisor oder Spielverwaltung (game manager) genannt. |
| **Kartenbonus** (Mapping bonus, MB) | Ein Multiplikator der Punktzahl von Korrektheit × 1,2 + 1 |
| **Kartenmatrix** (Map matrix) | Das Array, das die Karte darstellt |
| **Durchgang** (Passage) | Eine farbige Kachel, die zwei Bereiche verbindet |
| **Viertelkachel** (Quarter tile) | Ein Viertel einer Kachel, 6 cm breit, verwendet in den Bereichen 2 und 3 |
| **Server-Client-Setup** | Das Spiel läuft auf einem Computer und dein Programm auf einem anderen. Siehe Remote Controller. |
| **Smiley-Opfer** (Smiley victim) | Eine Wandmarkierung mit einem traurigen, neutralen oder fröhlichen Gesicht. Hat 2027 die Buchstabenopfer ersetzt. |
| **Sumpf** (Swamp) | Eine braune Kachel, auf der sich der Akku schneller entlädt |
| **TDP** | Technical Description Paper (technische Beschreibung) |
| **Kachel** (Tile) | Die Einheit des Spielfelds, 12 cm breit |
| **TI, TT, CN, TMI** | In der Wertung: Erkennung einer Markierung (token identification), Markierungstyp (token type), Erreichen eines Checkpoints (checkpoint negotiation) und Fehlerkennung einer Markierung (token misidentification) |
| **Wandmarkierung** (Wall token) | Alles, was an einer Wand erkannt werden muss: Smiley-Opfer und kognitive Ziele |
| **Welt** (World) | Eine Karte als `.wbt`-Datei |
