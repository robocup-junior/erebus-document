<Steps>

1. Installiere **Python 3.10 oder neuer** von der [offiziellen Website](https://www.python.org/downloads/macos/).

   Auch wenn du Python bereits über Homebrew, Anaconda oder ein ähnliches Tool hast, empfehlen wir, es auf diese Weise zu installieren. Sonst funktioniert die Simulation eventuell nicht richtig.

2. Öffne das Terminal und installiere die benötigten Bibliotheken:

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. Installiere **Webots R2025a** aus dem [offiziellen Repository](https://github.com/cyberbotics/webots/releases/download/R2025a/webots-R2025a.dmg).

4. Lade <DownloadErebus /> herunter und entpacke die Datei.

</Steps>

## Die Umgebung starten \{#run-the-environment\}

Doppelklicke auf die Weltdatei `game/worlds/world1.wbt`, um sie in Webots zu öffnen.

Webots öffnet das Erebus-Steuerfenster in deinem Webbrowser. Beim ersten Mal installiert Erebus einige Python-Bibliotheken und bereitet das Robotermodell vor, was eine Weile dauern kann. Es ist bereit, wenn das Fenster **Ready** und den Spieltimer 08:00 anzeigt:

![Das Erebus-Steuerfenster, startbereit](../../../../docs/installation/mac/../control-window-ready.png)

Beim ersten Mal kann die Webots-Konsole auch `ERROR: Skipped PROTO 'custom_robot'` anzeigen. Das kannst du ignorieren: Erebus bereitet das Robotermodell vor und lädt die Welt von selbst neu.

Lies als Nächstes die [Regeln im Überblick](/docs/rules/), um das Spiel zu verstehen. Wenn etwas schiefgeht, sieh unter [Fehlerbehebung](/docs/troubleshooting/) nach.
