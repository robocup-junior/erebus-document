<Steps>

1. Installiere **Python 3.9 oder neuer** von der [offiziellen Website](https://www.python.org/downloads/macos/).

   Auch wenn du Python bereits über Homebrew, Anaconda o. Ä. hast, empfehlen wir, es auf diese Weise zu installieren. Sonst funktioniert die Simulation eventuell nicht richtig.

2. Öffne das Terminal und installiere die benötigten Bibliotheken:

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. Installiere **Webots R2023b** aus dem [offiziellen Repository](https://github.com/cyberbotics/webots/releases/download/R2023b/webots-R2023b.dmg).

4. Lade <DownloadErebus /> herunter und entpacke die Datei.

</Steps>

## Die Umgebung starten \{#run-the-environment\}

Doppelklicke auf die Weltdatei `game/worlds/world1.wbt`, um sie in Webots zu öffnen.

Webots öffnet das Erebus-Steuerfenster in deinem Webbrowser. Beim ersten Mal installiert Erebus einige Python-Bibliotheken, was eine Weile dauern kann. Es ist bereit, wenn das Fenster den Spieltimer 08:00 anzeigt:

![Das Erebus-Steuerfenster, startbereit](../../../../docs/installation/mac/../control-window-ready.png)

Lies als Nächstes die [Regeln im Überblick](/docs/rules/), um das Spiel zu verstehen. Wenn etwas schiefgeht, sieh unter [Fehlerbehebung](/docs/troubleshooting/) nach.
