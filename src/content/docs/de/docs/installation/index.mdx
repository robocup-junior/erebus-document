## Software-Voraussetzungen \{#software-requirements\}
Das Simulationssystem besteht aus drei Komponenten, die du alle installieren musst. Die Installation ist einfach, aber das Herunterladen und Installieren von Webots kann eine Weile dauern. Die drei Komponenten sind:

1. Der Robotersimulator Webots, Version **R2023b**: die Simulationsumgebung. Erebus v26 unterstützt keine anderen Versionen von Webots.
1. Erebus: die Welten und der Main Supervisor, der die Regeln anwendet und die Punktzahl berechnet. Die neueste Version ist **v26.1**.
1. Python, Version **3.9 oder neuer**: nötig, um Erebus selbst auszuführen und Controller für die Roboter zu schreiben. Du kannst Controller auch in C/C++ schreiben.

## Minimale Systemvoraussetzungen \{#minimum-system-requirements\}
* Linux: Ubuntu 20.04 LTS oder 22.04 LTS
* Windows: Windows 10 oder 11, 64 Bit
* macOS: macOS 11 „Big Sur“ oder 12 „Monterey“. Das sind die Versionen, die Webots R2023b unterstützt. Neuere Versionen von macOS funktionieren eventuell auch: Diese Dokumentation wurde unter macOS 26 getestet.
* CPU: Dual-Core, 2 GHz
* RAM: 2 GB
* Grafik: NVIDIA- oder AMD-Grafikkarte mit OpenGL-Unterstützung und 512 MB Speicher

## Python-Bibliotheken \{#python-libraries\}
Erebus braucht die folgenden Python-Bibliotheken. Die meisten werden beim Start automatisch installiert, aber **OpenCV nicht**, also musst du es selbst installieren. Die Anleitung für jedes Betriebssystem enthält diesen Schritt.

```bash
python3 -m pip install numpy termcolor requests overrides pillow opencv-python
```
