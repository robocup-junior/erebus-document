<Steps>

1. Öffne das Terminal und installiere pip und die benötigten Bibliotheken:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   Unter Ubuntu 24.04 verweigert pip mit dem Fehler `externally-managed-environment`, Bibliotheken in das Python des Systems zu installieren. Ergänze den zweiten Befehl um `--break-system-packages`, oder installiere die Bibliotheken in einer [virtuellen Umgebung](https://docs.python.org/3/library/venv.html) und stelle deren Python in den Webots-Einstellungen ein.

2. Lade **Webots R2025a** herunter und installiere es:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. Lade <DownloadErebus /> herunter und entpacke die Datei.

</Steps>

## Die Umgebung starten \{#run-the-environment\}

Öffne die Welt im Terminal und passe dabei den Pfad zu deinem Erebus-Ordner an:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots öffnet das Erebus-Steuerfenster in deinem Webbrowser. Beim ersten Mal installiert Erebus einige Python-Bibliotheken und bereitet das Robotermodell vor, was eine Weile dauern kann. Es ist bereit, wenn das Fenster **Ready** und den Spieltimer 08:00 anzeigt:

![Das Erebus-Steuerfenster, startbereit](../../../../docs/installation/linux/../control-window-ready.png)

Beim ersten Mal kann die Webots-Konsole auch `ERROR: Skipped PROTO 'custom_robot'` anzeigen. Das kannst du ignorieren: Erebus bereitet das Robotermodell vor und lädt die Welt von selbst neu.

Lies als Nächstes die [Regeln im Überblick](/docs/rules/), um das Spiel zu verstehen. Wenn etwas schiefgeht, sieh unter [Fehlerbehebung](/docs/troubleshooting/) nach.
