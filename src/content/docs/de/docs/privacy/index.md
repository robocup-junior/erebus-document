Diese Dokumentation ist eine statische Website. Sie hat keine Benutzerkonten und fragt keine persönlichen Daten ab.

## Analyse {#analytics}
Diese Website nutzt [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/), um zu sehen, welche Seiten besucht werden, damit wir sie verbessern können. Besuche werden ohne Cookies gezählt, und einzelne Besucher werden nicht identifiziert.

## Was in deinem Browser gespeichert wird {#what-is-stored-in-your-browser}
Die Website speichert einige Einstellungen in deinem Browser, die nirgendwohin gesendet werden:

- Dein Farbschema
- Der ausgewählte Sprach-Tab der Codebeispiele

Diese Website verwendet keine Cookies.
