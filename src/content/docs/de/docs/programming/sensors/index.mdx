Sensoren informieren deinen Roboter über die Welt. Jeder Sensor wird auf die gleiche Weise verwendet:

1. Hol ihn über seinen Namen mit `robot.getDevice()`.
2. Aktiviere ihn mit `enable(timeStep)`. Bis dahin liefert er keine Werte.
3. Lies ihn in der Hauptschleife aus. Die Werte werden nach jedem `robot.step()` aktualisiert.

Wie echte Sensoren haben sie Rauschen: Derselbe Messwert kann sich von einem Schritt zum nächsten leicht ändern. Die Organisatoren ändern das Rauschen für den Wettbewerb nicht. Mach dein Programm also robust dagegen, zum Beispiel indem du mehrere Messwerte vergleichst.
