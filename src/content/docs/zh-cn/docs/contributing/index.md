## 为 Erebus 平台做贡献  {#contributions-to-the-erebus-platform}

如果你想为 Erebus 平台做贡献，目前有以下几种方式：
- 在[仓库中提交 issue](https://github.com/robocup-junior/erebus/issues)：如果你发现了平台的任何错误，或者有你认为必须加入的功能，请告诉我们。
- Pull request：如果你自己修复了错误，可以为这个修改提交一个 pull request，它有可能会被合并。
- 在 [Discord 服务器](https://discord.com/invite/6FJxZxk)上和我们交流：你可以通过 Discord 服务器联系我们（开发者、RCJ Rescue 委员会）。欢迎和我们分享你的想法！

### 更深入的参与 {#deeper-involvement}
我们目前没有积极招募仿真平台的新开发者。不过，我们一直在寻找新的人才，为下一代维护好这个平台。如果你确信自己具备相应的技能，并且希望加入这个平台的开发团队，请通过 Discord 服务器联系平台开发团队或 RoboCupJunior Rescue 委员会。

## 为文档做贡献 {#contributions-to-the-documentation}

- 点击[文档 issue](https://github.com/robocup-junior/erebus-document/issues)，在项目仓库中创建 issue。
- 在 [Discord 服务器](https://discord.com/invite/6FJxZxk)上和我们交流：你可以通过 Discord 服务器联系我们（开发者、RCJ Rescue 委员会）。欢迎和我们分享你的想法！
- 成为一名积极的文档编辑者！如果你想积极参与文档的编写，请在 Discord 服务器上联系平台开发团队。

本文档是一个使用 [Starlight](https://starlight.astro.build/) 主题的 [Astro](https://astro.build/) 网站。页面是 `src/content/docs` 中的 Markdown 文件，每个页面底部都有一个 **Edit page**（编辑页面）链接。关于如何在本地运行，请参阅文档仓库的 [README](https://github.com/robocup-junior/erebus-document#readme)。
