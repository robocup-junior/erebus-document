本文档是一个静态网站。它没有账户系统，也不会要求你提供任何个人信息。

## 访问统计 {#analytics}
本网站使用 [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) 来了解哪些页面被访问，以便我们改进这些页面。它在统计访问量时不使用 Cookie，也不会识别单个访问者。

## 浏览器中保存的内容 {#what-is-stored-in-your-browser}
本网站会在你的浏览器中保存几项设置，这些设置不会被发送到任何地方：

- 你选择的主题
- 代码示例中所选的语言标签页

本网站不使用 Cookie。
