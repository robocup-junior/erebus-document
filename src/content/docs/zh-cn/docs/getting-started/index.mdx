在本页中，你会在机器人上运行一个完整的程序，并学会使用 Erebus 控制窗口。你需要先[安装 Erebus](/docs/installation/)并准备好[你的机器人](/docs/robot/)。

## Erebus 文件夹 \{#the-erebus-folder\}
你下载的发布版中主要有这些文件夹：

| 文件夹 | 内容 |
|---|---|
| `game/worlds` | 各个世界（`.wbt` 文件）。打开其中一个即可开始。 |
| `game/logs` | 每场比赛结束时写入的比赛日志 |
| `match-results` | 每场比赛一个文件夹，包含回放和地图结果 |
| `player_controllers` | 示例控制器 |

## 控制窗口 \{#the-control-window\}
1. 在 Webots 中打开 `game/worlds/world1.wbt`。
1. Webots 会在网页浏览器中打开 Erebus 控制窗口（Main Supervisor 的机器人窗口）。你在这里加载程序并运行比赛。

![Erebus 控制窗口](../../../docs/getting-started/control_window.png)

从上到下依次是：

| 部分 | 用途 |
|---|---|
| 世界和状态 | 世界的名称，以及比赛的状态：Ready、Running、Paused 或 Finished |
| **Robot setup** | 加载你的程序和机器人，并连接远程控制器。见下文。 |
| **Advanced setup** | 各种选项，见下文 |
| **Worlds** | 切换到另一个世界 |
| 分数 | 当前分数 |
| **Robot battery** | 机器人的电池电量。低于 20% 时显示“Low battery”。参见[电池](/docs/programming/battery/)。 |
| **Simulation remaining** | 剩余的比赛时间。**Real-world allowance** 表示剩余的真实时间比比赛时间多出多少。任意一个耗尽，比赛就结束。 |
| 比赛控制 | 运行、暂停、重新定位、重置、放弃和保存地图。见下文。 |
| **Match events** | 比赛记录，最新的在最前面。**Export CSV** 可以把它保存为文件。 |

右上角的按钮会把同一个窗口作为单独的、更小的浏览器窗口打开。

:::note
如果没有安装 [Wireshark](/docs/installation/#optional-wireshark)，窗口还会显示网络访问未被监控的警告，并要求你确认。这种监控是给比赛组织者用的，所以你可以确认警告后照常练习。
:::

### Robot setup \{#robot-setup\}
按 **Robot setup** 来加载你的程序和机器人。

![已加载程序和机器人的 Robot setup 面板](../../../docs/getting-started/robot-setup.png)

| 部分 | 用途 |
|---|---|
| **Controller** | **Load file** 加载机器人的程序。Python 文件可以直接加载。C 和 C++ 程序必须先编译。 |
| **Robot JSON** | **Load file** 加载你的机器人，即用[机器人定制器](/docs/robot/customizer/)制作的 `.json` 文件 |
| **Keep files after Reset** | 重置比赛时保持程序和机器人的加载状态。默认开启。 |
| **Reload before Run** | 每次运行比赛时，都从 **Original controller file** 重新加载程序，以使用你最新的修改。请填写运行 Webots 的计算机上该文件的路径。 |
| **Remote mode** | 让在 Webots 外部运行的程序控制机器人。参见[远程控制器](/docs/competition/remote-controller/)。**Keep on Reset** 会在重置比赛时保持开启。 |
| **Docker project path** | 含有 `Dockerfile` 的文件夹，用 **Run Docker** 在容器中运行你的控制器。参见 [erebus-dockerfiles](https://github.com/robocup-junior/erebus-dockerfiles) 仓库。这是可选的。 |

### 比赛控制 \{#match-controls\}

![比赛控制按钮](../../../docs/getting-started/match-controls.png)

| 按钮 | 用途 |
|---|---|
| **Run match** | 开始比赛。机器人出现在世界中，你的程序开始运行。 |
| **Pause** | 暂时停止机器人。按 **Run match** 继续。 |
| **Relocate** | 宣布缺乏进展：机器人回到最后到达的检查点，你失去 5 分 |
| **Reset** | 重置比赛和世界 |
| **Give up** | 结束比赛 |
| **Save map** | 保存机器人提交的地图的结果并打开它。参见[提交地图](/docs/programming/map-bonus/)。 |

## 运行程序 \{#run-a-program\}
<a href={mazeUrl} download="maze.py">下载 maze.py</a>，这是一个让机器人在迷宫中行驶的完整程序，也就是你将在[迷宫导航](/docs/programming/navigate-the-maze/)中亲自编写的程序。

1. 打开 `game/worlds/world1.wbt`。
1. 如果还没有加载机器人，按 **Robot setup**，用 **Robot JSON** 下的 **Load file** 加载你的机器人。
1. 用 **Controller** 下的 **Load file** 加载 `maze.py`。文件加载后会显示它的名称。
1. 按 **Run match**。机器人出现在世界中并开始移动。
1. 要暂时停止机器人，按 **Pause**。
1. 如果机器人卡住了，按 **Relocate** 触发缺乏进展。
1. 按 **Reset** 重置比赛。你的程序和机器人仍保持加载，所以可以再次运行。

这个程序需要 OpenCV，你已经和其他 [Python 库](/docs/installation/#python-libraries)一起安装了它。程序的消息和错误会显示在 Webots 控制台中。

比赛进行时，比赛事件会显示在窗口底部。它能准确告诉你为什么得分或扣分，是检查程序的最佳工具。

![比赛中的控制窗口，以及比赛事件](../../../docs/getting-started/control_window_running.png)

`maze.py` 全速行驶且从不更换电池，所以在 `world1.wbt` 中，比赛会在不到两分钟后以 `Battery depleted` 结束。你将在[电池](/docs/programming/battery/)中学习如何管理电池。

比赛结束时，同样的信息会保存在 `game/logs` 文件夹中。比赛还会作为可交互的 3D 回放保存在 `match-results` 文件夹中：在浏览器中打开 `recording/replay.html` 即可再次观看。

## 使用其他世界 \{#using-other-worlds\}
按 **Worlds** 切换到另一个世界。按名称搜索世界，选中它，然后按 **Load world**。你也可以加入用[世界编辑器](/docs/tools/world-editor/)制作的自己的世界。

![控制窗口的 Worlds 面板](../../../docs/getting-started/worlds.png)

Erebus v27 自带的世界有：

| 世界 | 用途 |
|---|---|
| `2027_d1r1.wbt`、`2027_d1r2.wbt`、`2027_d2r1.wbt`、`2027_d2r2.wbt` | 2027 年规则的示例世界，带有接触地块和假受害者 |
| `world1.wbt`、`world2.wbt` | 示例世界。`world2.wbt` 包含区域 4。 |
| `world3.wbt`、`world4.wbt` | 更大的示例世界，还包含**假受害者** |
| `mapping_example_1.wbt` 到 `mapping_example_3.wbt` | 用来测试建图的世界。参见[地图规则](/docs/rules/mapping/)。 |
| `mapping_example_1_cyan_tiles.wbt` | 加了两个接触地块的 `mapping_example_1.wbt` |
| `NewPassages.wbt` | 区域之间通道的示例 |

## Advanced setup \{#advanced-setup\}
![控制窗口的 Advanced setup 面板](../../../docs/getting-started/settings.png)

| 设置 | 用途 |
|---|---|
| Show head-up display | 在 Webots 窗口中显示分数、时间和最新事件 |
| Automatic camera | 让视角跟随机器人 |
| HTML replay recording | 把每场比赛作为可交互的 3D 回放保存在 `match-results` 文件夹中 |
| Automatic map result | 机器人一提交地图，就保存并打开地图的结果 |
| Disable automatic LoP | 关闭 20 秒后的自动缺乏进展。仅用于调试。 |
| Enable debugging | 在 Webots 控制台中输出额外信息，例如墙面标识的报告为什么被拒绝 |

窗口底部的 **References** 可以打开更新日志、本文档以及制作世界和机器人的工具。要用 2027 年规则制作世界，请使用[世界编辑器](https://world.erebus.rcj.cloud/)。

## 手动把机器人移到想要的位置 \{#manually-move-the-robot-where-you-want-it-to-go\}
在仿真窗口中点击机器人时，会出现红、绿、蓝三个箭头。用鼠标拖动这些箭头，就可以把机器人移到任意位置。注意，程序开始之前不会显示机器人。
![在 Webots 中选中的机器人，以及用于移动它的箭头](../../../docs/getting-started/manual.png)
