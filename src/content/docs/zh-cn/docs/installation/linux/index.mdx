<Steps>

1. 打开终端，安装 pip 和所需的库：

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   在 Ubuntu 24.04 上，pip 会以 `externally-managed-environment` 错误拒绝把库安装到系统的 Python 中。请在第二条命令后加上 `--break-system-packages`，或者把库安装到[虚拟环境](https://docs.python.org/3/library/venv.html)中，并在 Webots 首选项里设置它的 Python。

2. 下载并安装 **Webots R2025a**：

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. 下载 <DownloadErebus />，然后解压。

</Steps>

## 运行仿真环境 \{#run-the-environment\}

在终端中打开世界文件，把路径改成你的 Erebus 文件夹：

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots 会在你的网页浏览器中打开 Erebus 控制窗口。第一次运行时，Erebus 会安装一些 Python 库并准备机器人模型，这可能需要一段时间。当窗口显示 **Ready** 和 08:00 的比赛计时器时，就准备好了：

![准备开始的 Erebus 控制窗口](../../../../docs/installation/linux/../control-window-ready.png)

第一次运行时，Webots 控制台还可能显示 `ERROR: Skipped PROTO 'custom_robot'`。可以忽略它：Erebus 会准备好机器人模型，并自动重新加载世界。

接下来，阅读[规则概要](/docs/rules/)来了解比赛。如果遇到问题，请查看[故障排除](/docs/troubleshooting/)。
