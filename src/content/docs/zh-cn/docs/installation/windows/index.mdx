import { Steps } from '@astrojs/starlight/components';
import DownloadErebus from '@/components/DownloadErebus.astro';

<Steps>

1. 从[官方网站](https://www.python.org/downloads/windows/)安装 64 位的 **Python 3.9 或更高版本**。安装时，请确保把 Python 添加到 PATH 中：

   ![Python 安装程序中的 Add Python to PATH 选项](../../../../docs/installation/windows/python-path.png)

2. 打开 PowerShell，安装所需的库：

   ```powershell
   python -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. 从[官方仓库](https://github.com/cyberbotics/webots/releases/download/R2023b/webots-R2023b_setup.exe)安装 **Webots R2023b**。

4. 下载 <DownloadErebus />，然后解压。

</Steps>

## 运行环境 \{#run-the-environment\}

双击世界文件 `game/worlds/world1.wbt`，在 Webots 中打开它。

Webots 会在你的网页浏览器中打开 Erebus 控制窗口。第一次运行时，Erebus 会安装一些 Python 库，这可能需要一段时间。当窗口显示 08:00 的比赛计时器时，就准备好了：

![准备开始的 Erebus 控制窗口](../../../../docs/installation/windows/../control-window-ready.png)

接下来，阅读[规则概要](/docs/rules/)来了解比赛。如果遇到问题，请查看[故障排除](/docs/troubleshooting/)。
