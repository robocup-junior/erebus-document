<Steps>

1. 从[官方网站](https://www.python.org/downloads/macos/)安装 **Python 3.10 或更高版本**。

   即使你已经通过 Homebrew、Anaconda 或类似工具安装了 Python，我们也建议用这种方式安装。否则，仿真可能无法正常运行。

2. 打开终端，安装所需的库：

   ```bash
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

3. 从[官方仓库](https://github.com/cyberbotics/webots/releases/download/R2025a/webots-R2025a.dmg)安装 **Webots R2025a**。

4. 下载 <DownloadErebus />，然后解压。

</Steps>

## 运行仿真环境 \{#run-the-environment\}

双击世界文件 `game/worlds/world1.wbt`，在 Webots 中打开它。

Webots 会在你的网页浏览器中打开 Erebus 控制窗口。第一次运行时，Erebus 会安装一些 Python 库并准备机器人模型，这可能需要一段时间。当窗口显示 **Ready** 和 08:00 的比赛计时器时，就准备好了：

![准备开始的 Erebus 控制窗口](../../../../docs/installation/mac/../control-window-ready.png)

第一次运行时，Webots 控制台还可能显示 `ERROR: Skipped PROTO 'custom_robot'`。可以忽略它：Erebus 会准备好机器人模型，并自动重新加载世界。

接下来，阅读[规则概要](/docs/rules/)来了解比赛。如果遇到问题，请查看[故障排除](/docs/troubleshooting/)。
