---
title: 术语表
description: Erebus 和规则中使用的术语。
---

| 术语 | 含义 |
|---|---|
| **区域**（Area） | 场地的四个部分之一，每个区域都有自己的墙壁类型。World Editor 中称为房间（room）。 |
| **区域乘数**（Area multiplier，AM） | 1、1.25、1.5 或 2，用于乘以每个区域的得分 |
| **电池**（Battery） | 按电机的速度消耗。电池耗尽时比赛结束。 |
| **检查点**（Checkpoint） | 银色的地块。发生缺乏进展后，机器人会回到它最后经过的检查点。 |
| **认知目标**（Cognitive target） | 由五个同心颜色圆环组成的墙面标识，各环数值之和对应一种危险品类型。2026 年起取代了危险品标志。 |
| **接触地块**（Contact tile） | 青色地块，机器人在上面静止 5 秒就会更换电池 |
| **控制窗口**（Control window） | 用来加载程序并运行比赛的网页。也称为机器人窗口（robot window）。 |
| **控制器**（Controller） | 你的程序 |
| **自定义机器人**（Custom robot） | 用 Robot Customizer 设计、从 `.json` 文件加载的机器人 |
| **离场奖励**（Exit bonus，EB） | 回到起始地块并发送 `E` 可获得 +10% |
| **假标识**（Fake） | 不能报告的标识：立体的笑脸受害者，以及数值之和无效的认知目标 |
| **浮动地块**（Floating tile） | 沿着与起点相连的墙壁走无法到达的地块。这里的标识分值更高。 |
| **缺乏进展**（Lack of progress，LoP） | 机器人被卡住或掉进坑洞时发生。机器人会回到最后一个检查点，并扣 5 分。 |
| **线性地块**（Linear tile） | 沿着与起点相连的墙壁走可以到达的地块 |
| **Main Supervisor** | Erebus 中管理比赛的部分。也称为监督程序或比赛管理器（game manager）。 |
| **地图奖励**（Mapping bonus，MB） | 得分乘数，等于正确率 × 1.2 + 1 |
| **地图矩阵**（Map matrix） | 表示地图的数组 |
| **通道**（Passage） | 连接两个区域的彩色地块 |
| **四分之一地块**（Quarter tile） | 地块的四分之一，宽 6 cm，用于区域 2 和 3 |
| **服务器-客户端模式**（Server-client setup） | 比赛在一台电脑上运行，你的程序在另一台电脑上运行。请参阅 Remote Controller。 |
| **笑脸受害者**（Smiley victim） | 带有难过、平静或开心表情的墙面标识。2027 年取代了字母受害者。 |
| **沼泽**（Swamp） | 会让电池消耗得更快的棕色地块 |
| **TDP** | 技术描述文档（Technical Description Paper） |
| **地块**（Tile） | 场地的基本单位，宽 12 cm |
| **TI、TT、CN、TMI** | 计分中的标识识别、标识类型、通过检查点和标识误判 |
| **墙面标识**（Wall token） | 墙上所有需要识别的东西：笑脸受害者和认知目标 |
| **世界**（World） | 一张地图，以 `.wbt` 文件的形式存在 |
