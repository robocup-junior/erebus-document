Erebus 是一个机器人仿真比赛环境。你需要设计一个机器人，并为它编写程序，让它自主探索迷宫，找到并识别墙面标识，避开障碍物和陷阱，保持电池电量，并绘制出环境的地图。

本文档介绍的是 **Erebus v27**，对应 **RoboCupJunior Rescue Simulation 2027** 规则。其他受支持的版本请参阅[版本](/docs/reference/versions/)。

## 学习路线 {#the-learning-path}
请按顺序完成各个步骤。每一步都建立在前一步的基础上。

| 步骤 | 页面 | 你将会…… |
|---|---|---|
| **开始** | [什么是 Erebus？](/docs/introduction/)、[安装](/docs/installation/) | 了解你要做什么，并安装好所有软件 |
| **1. 比赛** | [规则概要](/docs/rules/) | 了解任务、场地和计分方式 |
| **2. 你的机器人** | [获取机器人](/docs/robot/)、[搭建机器人](/docs/robot/build/) | 在 Erebus 中加载入门机器人 |
| **3. 首次运行** | [首次运行](/docs/getting-started/) | 观看你的机器人探索，并熟悉控制窗口 |
| **4. 编程基础** | [第一个程序](/docs/programming/first-program/)、[移动](/docs/programming/movement/)、[传感器](/docs/programming/sensors/) | 让你的机器人移动和感知 |
| **5. 进行比赛** | [迷宫导航](/docs/programming/navigate-the-maze/)、[通信](/docs/programming/communication/)、[墙面标识](/docs/programming/wall-tokens/)、[电池](/docs/programming/battery/)、[探索与建图](/docs/programming/exploring/)、[地图规则](/docs/rules/mapping/)、[提交地图](/docs/programming/map-bonus/) | 用各种方式得分 |
| **6. 参加比赛** | [赛前准备](/docs/competition/)、[Remote Controller](/docs/competition/remote-controller/) | 为比赛做好准备 |

所有示例都使用[入门机器人](/docs/robot/)，所以运行示例之前请先加载它。
