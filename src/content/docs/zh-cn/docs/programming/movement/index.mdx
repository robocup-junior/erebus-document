机器人有两个车轮，每个车轮都有自己的电机：在[入门机器人](/docs/robot/)上分别是 `left wheel motor` 和 `right wheel motor`。你通过设置每个车轮的速度来驾驶它：

| 左轮 | 右轮 | 机器人会…… |
|---|---|---|
| 向前 | 向前 | 向前行驶 |
| 向后 | 向后 | 向后行驶 |
| 向后 | 向前 | 原地向左转 |
| 向前 | 向后 | 原地向右转 |
| 快 | 慢 | 向右转弯 |

速度的单位是**弧度每秒**，最大为 6.28（每秒车轮转一圈）。速度为负值时，车轮向后转。

## 行驶 \{#driving\}

1. 按名字获取每个电机。
2. 把它的位置设为无穷大，让它可以无限制地转动。
3. 设置它的速度。

电机会保持你最后设置的速度，所以在程序做其他事情时，机器人会继续移动。下面的程序让机器人向前行驶、向后行驶、原地向左转，每个动作持续一秒：

## 测量车轮转过了多少 \{#measuring-how-far-a-wheel-turned\}

每个电机都有一个位置传感器，也叫编码器，它以弧度为单位记录车轮转过了多少。它可以用来行驶固定的距离。车轮向后转时，计数会减小。

按时间控制移动很简单，但结果会随速度而变化。编码器测量的是移动本身，所以更可靠。要想精确转向，[陀螺仪](/docs/programming/sensors/imu/)效果更好。
