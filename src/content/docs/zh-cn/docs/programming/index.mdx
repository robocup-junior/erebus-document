title: 为机器人编程

---

程序，也叫**控制器**（controller），是在一个循环中运行的：读取传感器，做出决定，设置电机，然后让仿真前进一步。机器人做的每一件事都来自这个循环。

这里的所有示例都在[入门机器人](/docs/robot/)上运行。运行示例之前先加载入门机器人，示例就能直接使用。每个示例都有 Python 和 C/C++ 两个版本：在标签页中选择你的语言，整个网站都会按照你的选择显示。

## 学习路线 \{#the-path\}

| 步骤 | 你将学会…… |
|---|---|
| 1. [第一个程序](/docs/programming/first-program/) | 编写、加载并运行程序 |
| 2. [移动](/docs/programming/movement/) | 行驶和转向 |
| 3. [传感器](/docs/programming/sensors/) | 找到墙壁、坑洞、标识和自己的位置 |
| 4. [迷宫导航](/docs/programming/navigate-the-maze/) | 把这些组合成一个完整的程序 |
| 5. [通信](/docs/programming/communication/) | 报告标识并得分 |
| 6. [墙面标识](/docs/programming/wall-tokens/) | 区分受害者、目标和假标识 |
| 7. [探索与建图](/docs/programming/exploring/) | 有条理地探索并记住迷宫 |
| 8. [地图规则](/docs/rules/mapping/)和[提交地图](/docs/programming/map-bonus/) | 获得地图奖励 |

每一步都建立在前面几步的基础上。如果你还没读过[规则概要](/docs/rules/)，请先读一读：它解释了你的机器人需要做什么，以及怎样得分。

如果你使用 C 或 C++，请先阅读 [C++ 控制器](/docs/programming/cpp/)，了解如何编译和运行你的程序。
