激光雷达（LIDAR）测量机器人四周的距离，单位为**米**，就像同时使用许多个距离传感器一样。在入门机器人上，它的名字是 `lidar`，位于机器人顶部。

它会测量机器人周围的 512 个点，共有 4 层，一层叠在另一层上面，最远可达 1 m。没有碰到任何物体的点读数为 `inf`。

## 读取距离 \{#reading-distances\}

`getLayerRangeImage(0)` 给出某一层的 512 个距离。第一个点在机器人正前方，之后按**顺时针**方向排列：四分之一处在右侧，一半处在后方，四分之三处在左侧。

![一层激光雷达的点在机器人周围的位置：0 在前方，128 在右侧，256 在后方，384 在左侧](../../../../../docs/programming/sensors/lidar/lidar-order.svg)

## 点云 \{#point-cloud\}

激光雷达还可以把每个点表示为相对于激光雷达的位置，这对于绘制机器人所见环境的地图很有用。计算点云需要额外的时间，所以只有在用到时才启用它。

:::caution[放置激光雷达]
在你自己的机器人上，请把激光雷达放在顶部，并使用与[入门机器人](/docs/robot/build/)相同的旋转角度，让它保持水平。如果放在车身内部或者倾斜放置，它会测到机器人自己。
:::
