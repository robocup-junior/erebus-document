颜色传感器朝向地面，所以它能告诉机器人哪里有坑洞、沼泽和通道。它其实是一个只有一个像素、朝下的摄像头。在入门机器人上，它的名字是 `color`，位于机器人前部，这样在车轮到达坑洞之前就能看到它。

<CodeTabs file="read" />

## 地面颜色 \{#floor-colours\}

这些数值是用入门机器人在 `world2.wbt` 上测得的：

| 地面 | 红 | 绿 | 蓝 |
|---|---:|---:|---:|
| 普通地面 | 252 | 252 | 252 |
| 沼泽 | 245 | 222 | 142 |
| 区域 1 和 2 之间的通道（蓝色） | 91 | 91 | 255 |
| 区域 2 和 3 之间的通道（紫色） | 193 | 91 | 251 |
| 区域 1 和 4 之间的通道（绿色） | 48 | 255 | 48 |
| 区域 3 和 4 之间的通道（红色） | 255 | 91 | 91 |

:::caution
数值会随世界而变化：在 `world1.wbt` 中，普通地面的读数约为 240。请使用范围而不是精确值，并用 Erebus 的 `player_controllers` 文件夹中的 `calibrateColourSensor.py` 来检查它们。
:::

坑洞有黑色的边缘，所以在坑洞前面，地面会先变暗。对这个传感器来说，检查点看起来和普通地面几乎一样，所以请在你的世界中找一个检查点来校准。
