颜色传感器朝向地面，所以它能告诉机器人哪里有坑洞、沼泽、接触地块和通道。它其实是一个只有一个像素、朝下的摄像头。在入门机器人上，它的名字是 `color`，位于机器人前部，这样在车轮到达坑洞之前就能看到它。

<CodeTabs file="read" />

## 地面颜色 \{#floor-colours\}

这些数值是用入门机器人在 `world2.wbt` 和 `mapping_example_1_cyan_tiles.wbt` 上测得的：

| 地面 | 红 | 绿 | 蓝 |
|---|---:|---:|---:|
| 普通地面 | 242 | 242 | 242 |
| 检查点 | 254 | 254 | 254 |
| 沼泽 | 225 | 193 | 115 |
| 接触地块（青色） | 0 | 242 | 242 |
| 坑洞（黑色边缘） | 34 | 34 | 34 |
| 区域 1 和 2 之间的通道（蓝色） | 72 | 72 | 254 |
| 区域 2 和 3 之间的通道（紫色） | 161 | 72 | 238 |
| 区域 1 和 4 之间的通道（绿色） | 38 | 253 | 38 |
| 区域 3 和 4 之间的通道（红色） | 254 | 72 | 72 |

:::caution
这些值可能会随世界和图形设置而变化。请使用范围而不是精确值，并用 Erebus 的 `player_controllers` 文件夹中的 `calibrateColourSensor.py` 检查它们。
:::

坑洞有黑色边缘，所以在坑洞前地面会变暗。检查点只比普通地面亮一点点，所以在依赖它之前，请先在你的世界里的检查点上校准。
