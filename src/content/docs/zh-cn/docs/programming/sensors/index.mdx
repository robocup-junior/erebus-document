传感器让你的机器人了解周围的世界。所有传感器的用法都一样：

1. 用 `robot.getDevice()` 按名字获取它。
2. 用 `enable(timeStep)` 启用它。在启用之前，它不会给出任何数值。
3. 在主循环中读取它。每次 `robot.step()` 之后，数值都会更新。

和真实的传感器一样，它们也有噪声：同一个读数在相邻两步之间可能会略有变化。组织者在比赛中不会改变噪声，所以要让你的程序能够应对噪声，例如比较多个读数。
