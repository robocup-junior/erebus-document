摄像头会给出它前方景物的图像。你需要用它来寻找和识别[墙面标识](/docs/programming/wall-tokens/)。入门机器人有一个摄像头，名字是 `camera`，分辨率为 64 × 40 像素。

## 读取像素 \{#reading-pixels\}

图像是由像素组成的网格。每个像素都有红、绿、蓝三个值，范围是 0 到 255，其中 (0, 0, 0) 是黑色，(255, 255, 255) 是白色。

## 分辨率 \{#resolution\}

分辨率越高，能在越远的地方看到标识，但成本更高，处理时间也更长。你可以在 [Robot Customizer](/docs/robot/customizer/#components) 中为每个摄像头选择分辨率。
