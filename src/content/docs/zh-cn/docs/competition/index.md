本页是基于 2027 年规则的国际赛指南。地方赛和地区赛可能有所不同，请向你的组织者确认。任何时候都以官方[规则](/docs/rules/)为准。

## 时间安排 {#timeline}

| 时间 | 事项 |
|---|---|
| 全年 | 关注[活动页面](/docs/events/upcoming-events/)和[论坛](https://junior.forum.robocup.org/)，规则澄清会发布在那里 |
| 至少提前 4 周 | 组织者发布填写网页表单的说明，用于准备面试 |
| 比赛第一天前 3 周 | 文档材料的提交截止日期 |
| 布置日 | 尽早到达会场，进行注册、面试和参加队伍会议 |
| 每一轮 | 世界会在比赛开始前才公布。每一轮的截止时间过后，程序就不能再修改。 |
| 计分轮结束后 | 技术挑战（Technical Challenge） |

## 需要提交的文档材料 {#documents-to-submit}
模板和评分标准在 [RCJ Rescue 社区网站](https://rescue.rcj.cloud/)上。

- [ ] **技术描述文档（Technical Description Paper，TDP）**：请严格按照模板编写，否则该文档的得分为 0。
- [ ] **海报（Poster）**：需要提交电子文件，并在会场展示实体海报，尺寸不超过 A1。
- [ ] 展示你的项目的**视频（Video）**。
- [ ] **服务器-客户端视频：** 一段短视频，展示你如何在服务器-客户端模式下，在示例地图上运行控制器。
- [ ] **源代码**以及用于面试的**网页表单**。

## 比赛设置 {#competition-setup}
比赛以服务器-客户端模式进行：组织者运行比赛服务器并提供一个 RJ-45 网口，你的程序在你的电脑上运行。请参阅 [Remote Controller](/docs/competition/remote-controller/)。

请带上：

- [ ] 一台电脑，装好你的程序和它需要的所有库，以及 Webots R2025a
- [ ] 一根以太网线，如果你的电脑需要，还要带上转接器
- [ ] 如果你有自定义机器人，带上机器人的 `.json` 文件
- [ ] 实体海报

## OpenGL 设置 {#opengl-settings}
除非组织者另行公布，否则会使用以下设置。它们会影响摄像头看到的画面，所以请用这些设置进行测试。你可以在 Webots 首选项（Preferences）的 OpenGL 标签页中找到它们。

| 设置 | 值 |
|---|---|
| Ambient Occlusion | Low |
| Texture Quality | Low |
| Max Texture Filtering | 4 |
| Shadows | Disabled |
| Anti-aliasing | Disabled |

## 测试你的机器人 {#testing-your-robot}
- [ ] 在所有自带的世界中运行，特别是四个 `2027_` 世界，它们带有接触地块和假标识。
- [ ] 用 [World Editor](/docs/tools/world-editor/) 制作你自己的地图，并包含全部四个区域。
- [ ] 检查整场比赛：能否运行到最后、及时更换电池、提交地图并返回起点？
- [ ] 测试发生缺乏进展之后会怎样。
- [ ] 在你将要带去的电脑上，用上面的 OpenGL 设置进行测试。

## 比赛期间 {#during-the-competition}
- 除非裁判另有指示，只有队长和副队长可以进入比赛区域。
- 由裁判操作仿真。比赛开始后，你不能触碰比赛设备。
- 比赛期间，指导老师不能提供帮助。
- 准备好解释你们的工作：每位队员都应该承担一项技术工作，并了解它是如何运作的。

## 最终得分 {#final-score}
国际赛的最终得分由以下部分组成：

| 部分 | 权重 | 内容 |
|---|---|---|
| 场地得分 | 0.6 | 标准化场地得分的平均值。最差的一轮或几轮不计入。 |
| 评分标准 | 0.2 | TDP（0.6）、视频（0.2）、海报（0.2） |
| 技术挑战 | 0.2 | 在比赛现场公布的小任务，需要在有限时间内重新为机器人编程来完成 |

得分相同时，以标准化场地得分的平均值决定名次。SuperTeam Challenge（超级团队挑战）是一项独立的活动，有单独的奖项。
