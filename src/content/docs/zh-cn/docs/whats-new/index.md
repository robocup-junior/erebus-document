title: v27 新功能
description: Erebus v27 和 2027 年规则中影响你的机器人的变化。
---

Erebus v27 实现了 2027 年规则。如果你是从 v26 过来的，下面是会影响你的机器人的变化。

| 主题 | 2026 年及以前 | 2027 年起 |
|---|---|---|
| 电池 | - | 新增：机器人有一块[电池](/docs/rules/#the-battery)，按电机的速度消耗。电池耗尽时比赛结束。 |
| 接触地块 | - | 新增：青色的[接触地块](/docs/rules/#contact-tiles)。在上面静止 5 秒即可更换电池。在地图中记为 `k`。 |
| 沼泽 | 比赛时间流逝更快：第一次进入为 x5，最多 x10 | 电池消耗更快。比赛时间不受影响。 |
| 受害者 | 符号 Φ、Ψ、Ω | [笑脸](/docs/rules/#smiley-victims)：难过（受伤）、平静（稳定）和开心（未受伤）。报告时仍使用 `H`、`S`、`U`。 |
| 假受害者 | 立体的符号 | 立体的笑脸 |
| 比赛信息 | `G` 的回复为 16 字节 | `G` 的回复为 20 字节，最后是电池电量。参见[比赛信息](/docs/programming/communication/#game-information)。 |
| 报告距离 | Erebus v26 接受距离标识 9 cm 以内的报告 | 按规则为半个地块（6 cm） |
| 区域 | 四个区域，区域 4 可选 | 最多四个区域：区域 1 一定存在，组织者可以省略区域 2 到 4 |
| Webots | R2023b | **R2025a** |
| Python | 3.9 或更高版本 | 3.10 或更高版本 |

[第一次运行](/docs/getting-started/)介绍了 Erebus v27 控制窗口的用法。

## 更新你的程序 {#updating-your-program}

1. 把 `G` 的回复按 20 字节读取。只接受 16 字节的程序将收不到比赛信息。
1. 关注电池电量，规划路线，让机器人在电池耗尽之前到达接触地块。参见[电池](/docs/programming/battery/)。
1. 把接触地块以 `k` 加入地图。
1. 把受害者识别更新为笑脸。报告的字母不变。
1. 在更近的地方报告标识：机器人的中心和你发送的位置都必须在离标识半个地块以内。
1. 沼泽现在消耗的是电池而不是时间，请在电池计划中考虑它们。
1. 安装 Webots R2025a 和 Python 3.10 或更高版本，并检查你的程序是否仍能运行。参见[安装](/docs/installation/)。
