title: v26 新功能

---

Erebus v26 实现了 2026 年规则。如果你是从较早的版本升级过来的，下面是会影响你的机器人的变化。

| 主题 | 2025 年及以前 | 2026 年起 |
|---|---|---|
| 字母受害者（Letter victims） | 字母 H、S、U | 符号 Φ（受伤）、Ψ（稳定）、Ω（未受伤）。报告时仍然使用 `H`、`S`、`U`。 |
| 危险品标志（Hazmat signs） | 四种危险品标签 | 被[认知目标](/docs/rules/#cognitive-targets)（Cognitive targets）取代：由同心彩色圆环组成，各环数值之和就是类型。报告时仍然使用 `F`、`P`、`C`、`O`。 |
| 假标识 | - | 新增：带有立体字母的[假受害者](/docs/rules/#fake-victims)（Fake victims），以及数值之和不在 0 到 3 之间的认知目标。不要报告它们，也不要把它们画进地图。 |
| 沼泽（Swamps） | 时间消耗加快 5 倍 | 第一次进入沼泽时为 x5，每次重新进入同一片沼泽再加 1，最高 x10。 |
| 地图上的障碍物 | 不记入地图 | 有障碍物的地块在地图中记为 `x`。 |
| 地图奖励（Mapping bonus） | 最高 x2 | 乘数现在为正确率 × 1.2 + 1。 |
| 传感器噪声 | - | GPS 有噪声。组织者在比赛中不会改变噪声水平。 |
| 比赛执行方式 | 每次活动另行公布 | 服务器-客户端模式：你的控制器在你自己的电脑上运行，通过以太网连接到比赛服务器。请参阅 [Remote Controller](/docs/competition/remote-controller/)。 |
| 文档材料 | TDP、海报、视频 | 另外还需要一段短视频，展示你如何在服务器-客户端模式下运行控制器。 |
| 缺席的比赛 | -50 分 | 0 分。 |

Webots 版本没有变化：Erebus v26 仍然在 Webots **R2023b** 上运行。

v26.0.0 之后发布的两个版本没有改变规则。v26.0.1 增加了带有假受害者的示例世界，以及一个把现有世界中的受害者变成假受害者的脚本；v26.1 修正了区域 4 中障碍物的标记方式。

## 更新你的程序 {#updating-your-program}

1. 把受害者识别更新为新的符号。你报告的字母不变。
2. 把危险品标志识别替换为[读取认知目标](/docs/programming/wall-tokens/#reading-a-cognitive-target)。
3. 确保你的程序不报告假目标，并且不把它们画进地图。
4. 把障碍物以 `x` 的形式加入你的地图。
5. 规划路线时要考虑新的沼泽规则：机器人每次进入同一片沼泽，都会花费更多时间。
6. 练习[服务器-客户端模式](/docs/competition/remote-controller/)。
