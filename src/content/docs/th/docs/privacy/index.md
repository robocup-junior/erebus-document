เอกสารนี้เป็นเว็บไซต์แบบสแตติก ไม่มีบัญชีผู้ใช้ และไม่ขอข้อมูลส่วนบุคคลใด ๆ

## การวิเคราะห์การใช้งาน {#analytics}
เว็บไซต์นี้ใช้ [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) เพื่อดูว่ามีการเข้าชมหน้าใดบ้าง เพื่อให้เราปรับปรุงหน้าเหล่านั้นได้ ระบบนับจำนวนการเข้าชมโดยไม่ใช้คุกกี้ และไม่ระบุตัวตนของผู้เข้าชมแต่ละคน

## สิ่งที่จัดเก็บไว้ในเบราว์เซอร์ของคุณ {#what-is-stored-in-your-browser}
เว็บไซต์จัดเก็บการตั้งค่าบางอย่างไว้ในเบราว์เซอร์ของคุณ โดยไม่ส่งไปที่ใด:

- ธีมของคุณ
- แท็บภาษาที่เลือกไว้ของตัวอย่างโค้ด

เว็บไซต์นี้ไม่ใช้คุกกี้
