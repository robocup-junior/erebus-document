ใน Erebus **คุณเป็นผู้ออกแบบหุ่นยนต์ของคุณ**: คุณเลือกเซนเซอร์และตำแหน่งที่ติดตั้ง ภายในงบประมาณ ทุกโปรแกรมต้องมีหุ่นยนต์ ดังนั้นขั้นแรกคือการรับหุ่นยนต์และโหลดเข้า Erebus

![หุ่นยนต์ e-puck ของจริง](../../../docs/robot/real_robot.thumbnail.jpg)

หุ่นยนต์นี้มีพื้นฐานมาจาก [e-puck](https://cyberbotics.com/doc/guide/epuck?version=R2023b) ซึ่งเป็นหุ่นยนต์เพื่อการศึกษาขนาดเล็ก รูปทรงกลม มีสองล้อ คุณเพิ่มเซนเซอร์ให้มันได้ด้วย [Robot Customizer](https://robot.erebus.rcj.cloud/) และบันทึกแบบเป็นไฟล์ `.json` ที่ Erebus โหลดได้

## หุ่นยนต์เริ่มต้น {#the-starter-robot}
เอกสารนี้ใช้หุ่นยนต์ตัวเดียวกันทุกที่ คือ**หุ่นยนต์เริ่มต้น (starter robot)** เพื่อให้ทุกตัวอย่างทำงานได้ทันที หุ่นยนต์นี้มีเซนเซอร์ทุกตัวที่บทเรียนต้องใช้:

| องค์ประกอบ | ชื่อในโปรแกรมของคุณ | ใช้ทำอะไร |
|---|---|---|
| ล้อสองล้อ | `left wheel motor`, `right wheel motor` | เคลื่อนที่ |
| เอนโค้ดเดอร์ล้อ | `left wheel sensor`, `right wheel sensor` | วัดว่าล้อหมุนไปเท่าใด |
| เซนเซอร์วัดระยะสามตัว | `leftDist`, `frontDist`, `rightDist` | หาผนังทางซ้าย ด้านหน้า และทางขวา |
| กล้อง 64 × 40 พิกเซล | `camera` | ค้นหาสัญลักษณ์บนผนัง |
| เซนเซอร์สี | `color` | ดูพื้น: หลุม หนองน้ำ และทางผ่าน |
| GPS | `gps` | รู้ตำแหน่งของตัวเอง เพื่อรายงานสัญลักษณ์ |
| ไจโร | `gyro` | วัดว่าเลี้ยวไปเท่าใด |
| มาตรความเร่ง | `accelerometer` | วัดความเร่ง |
| Lidar | `lidar` | วัดระยะรอบตัว |
| ตัวส่งและตัวรับ | `emitter`, `receiver` | สื่อสารกับเกม หุ่นยนต์ทุกตัวมีอุปกรณ์นี้ |

หุ่นยนต์นี้ใช้งบประมาณ 2400 จาก 3000

## เลือกเส้นทางของคุณ {#choose-your-path}

**แนะนำ: ประกอบด้วยตัวเอง** ใช้เวลาประมาณ 15 นาที และคุณจะเข้าใจทุกส่วนของหุ่นยนต์ ทำตาม[ประกอบหุ่นยนต์ของคุณ](/docs/robot/build/)

**หากรีบ:** ดาวน์โหลดหุ่นยนต์ที่เสร็จแล้วและเรียนบทเรียนต่อ คุณกลับมาประกอบภายหลังได้เสมอ

<a href="/downloads/starter-robot.json" download>ดาวน์โหลด starter-robot.json</a>

## โหลดเข้า Erebus {#load-it-in-erebus}
1. เปิดโลก เช่น `game/worlds/world1.wbt`
2. ในหน้าต่างควบคุม กด**ปุ่ม LOAD ด้านขวา** ที่มีไอคอนหุ่นยนต์ แล้วเลือกไฟล์ `.json` ของคุณ
3. ตรวจสอบคอนโซลของ Webots Erebus จะแสดงรายการองค์ประกอบแต่ละชิ้นพร้อมราคา และจบด้วย `Your custom robot has been successfully generated!`

:::note
Erebus v26.1 ยังพิมพ์ `PROTO parameter 'camera_width' has no matching IS field` เป็นสีแดงด้วย คุณละเลยข้อความนี้ได้: กล้องของคุณยังคงมีความละเอียดตามที่คุณเลือก
:::

หุ่นยนต์จะยังโหลดอยู่จนกว่าคุณจะโหลดตัวอื่นหรือรีเซ็ตเกม ขั้นต่อไป [รันโปรแกรมแรกของคุณ](/docs/getting-started/)

## การออกแบบหุ่นยนต์ของคุณเอง {#designing-your-own}
เมื่อคุณรู้พื้นฐานแล้ว ลองปรับเปลี่ยนหุ่นยนต์เริ่มต้นหรือออกแบบตัวใหม่: เพิ่มกล้องที่ความละเอียดสูงขึ้น เพิ่มเซนเซอร์วัดระยะ หรือติดเซนเซอร์ในตำแหน่งอื่น [ข้อมูลอ้างอิง Robot Customizer](/docs/robot/customizer/) แสดงองค์ประกอบทั้งหมด พร้อมราคาและข้อจำกัด

หากคุณเปลี่ยนชื่อขององค์ประกอบ ให้เปลี่ยนในโปรแกรมของคุณด้วย
