description: การเปลี่ยนแปลงใน Erebus v26 และกติกาปี 2026 ที่มีผลต่อหุ่นยนต์ของคุณ
---

Erebus v26 ใช้กติกาปี 2026 หากคุณย้ายมาจากเวอร์ชันก่อนหน้า การเปลี่ยนแปลงที่มีผลต่อหุ่นยนต์ของคุณมีดังนี้

| หัวข้อ | จนถึงปี 2025 | ตั้งแต่ปี 2026 |
|---|---|---|
| ผู้ประสบภัยแบบตัวอักษร (Letter victims) | ตัวอักษร H, S, U | สัญลักษณ์ Φ (บาดเจ็บ), Ψ (อาการคงที่), Ω (ไม่บาดเจ็บ) ยังคงรายงานเป็น `H`, `S`, `U` |
| ป้ายวัตถุอันตราย (Hazmat signs) | ป้ายวัตถุอันตรายสี่แบบ | ถูกแทนที่ด้วย[เป้าหมายเชิงรับรู้ (cognitive targets)](/docs/rules/#cognitive-targets): วงแหวนสีซ้อนกันที่ผลรวมของค่าบอกชนิด ยังคงรายงานเป็น `F`, `P`, `C`, `O` |
| สัญลักษณ์ปลอม (Fake tokens) | - | ใหม่: [ผู้ประสบภัยปลอม (fake victims)](/docs/rules/#fake-victims) ที่เป็นตัวอักษรสามมิติ และเป้าหมายเชิงรับรู้ที่ผลรวมไม่อยู่ระหว่าง 0 ถึง 3 ห้ามรายงานหรือใส่ในแผนที่ |
| หนองน้ำ (Swamps) | เวลาเดินเร็วขึ้น 5 เท่า | การเข้าหนองน้ำครั้งแรกเป็น x5 และการเข้าหนองน้ำเดิมแต่ละครั้งหลังจากนั้นจะเพิ่มขึ้นอีก 1 สูงสุด x10 |
| สิ่งกีดขวางบนแผนที่ | ไม่ต้องใส่ในแผนที่ | ช่องที่มีสิ่งกีดขวางจะใส่ในแผนที่เป็น `x` |
| โบนัสแผนที่ | สูงสุด x2 | ตอนนี้ตัวคูณคือ ความถูกต้อง × 1.2 + 1 |
| สัญญาณรบกวนของเซนเซอร์ | - | GPS มีสัญญาณรบกวน ผู้จัดจะไม่เปลี่ยนระดับสัญญาณรบกวนในการแข่งขัน |
| การรันเกม | ประกาศแยกในแต่ละงาน | การตั้งค่าแบบเซิร์ฟเวอร์-ไคลเอนต์: คอนโทรลเลอร์ของคุณรันบนคอมพิวเตอร์ของคุณเอง และเชื่อมต่อกับเซิร์ฟเวอร์เกมผ่าน Ethernet ดู [Remote Controller](/docs/competition/remote-controller/) |
| เอกสาร | TDP, โปสเตอร์, วิดีโอ | เพิ่มวิดีโอสั้น ๆ ที่แสดงวิธีรันคอนโทรลเลอร์ด้วยการตั้งค่าแบบเซิร์ฟเวอร์-ไคลเอนต์ |
| เกมที่พลาด | -50 คะแนน | 0 คะแนน |

เวอร์ชันของ Webots ไม่ได้เปลี่ยน: Erebus v26 ยังคงรันบน Webots **R2023b**

สองเวอร์ชันที่ออกหลัง v26.0.0 ไม่ได้เปลี่ยนกติกา v26.0.1 เพิ่มโลกตัวอย่างที่มีผู้ประสบภัยปลอม และสคริปต์ที่เปลี่ยนผู้ประสบภัยในโลกที่มีอยู่ให้เป็นของปลอม ส่วน v26.1 แก้ไขวิธีทำเครื่องหมายสิ่งกีดขวางในพื้นที่ 4

## การอัปเดตโปรแกรมของคุณ {#updating-your-program}

1. อัปเดตการตรวจจับผู้ประสบภัยให้รองรับสัญลักษณ์ใหม่ ตัวอักษรที่คุณรายงานไม่เปลี่ยน
2. แทนที่การตรวจจับวัตถุอันตรายด้วย[การอ่านเป้าหมายเชิงรับรู้](/docs/programming/wall-tokens/#reading-a-cognitive-target)
3. ตรวจสอบให้แน่ใจว่าโปรแกรมของคุณไม่รายงานของปลอม และไม่ใส่ของปลอมในแผนที่
4. เพิ่มสิ่งกีดขวางลงในแผนที่ของคุณเป็น `x`
5. วางแผนเส้นทางโดยคำนึงถึงหนองน้ำแบบใหม่: ทุกครั้งที่หุ่นยนต์เข้าหนองน้ำเดิม จะเสียเวลามากขึ้น
6. ฝึกใช้[การตั้งค่าแบบเซิร์ฟเวอร์-ไคลเอนต์](/docs/competition/remote-controller/)
