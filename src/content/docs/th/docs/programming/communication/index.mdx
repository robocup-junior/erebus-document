โปรแกรมของคุณสื่อสารกับเกมผ่านอุปกรณ์สองชิ้นที่หุ่นยนต์ทุกตัวมี:

- **ตัวส่ง (emitter)** ส่งข้อความไปยังเกม ไม่จำเป็นต้องเปิดใช้งาน
- **ตัวรับ (receiver)** รับข้อความจากเกม ให้เปิดใช้งานเหมือนเซนเซอร์

แต่ละหัวข้อด้านล่างเป็นโปรแกรมที่สมบูรณ์สำหรับ[หุ่นยนต์เริ่มต้น](/docs/robot/) ข้อความทั้งหมดอยู่ใน[ข้อมูลอ้างอิงข้อความ](/docs/reference/messages/)

## การทำคะแนนจากสัญลักษณ์บนผนัง \{#scoring-wall-tokens\}

ในการทำคะแนนจากผู้ประสบภัยแบบหน้ายิ้ม (letter victim) หรือเป้าหมายเชิงรับรู้ (cognitive target) หุ่นยนต์ต้อง:

1. **หยุดนิ่งนานกว่า 1 วินาที** ใกล้กับสัญลักษณ์ Erebus จะไม่รับการรายงานหากหุ่นยนต์เคลื่อนที่ภายใน 1 วินาทีที่ผ่านมา
2. **ส่งตำแหน่งและชนิด**ของสัญลักษณ์: X และ Z เป็น**เซนติเมตร** และชนิดเป็นตัวอักษรหนึ่งตัว

| สัญลักษณ์บนผนัง | ชนิด |
|---|---|
| ผู้ประสบภัยแบบหน้ายิ้ม หน้าเศร้า (บาดเจ็บ) | `H` |
| ผู้ประสบภัยแบบหน้ายิ้ม หน้าเฉย ๆ (คงที่) | `S` |
| ผู้ประสบภัยแบบหน้ายิ้ม หน้ายิ้ม (ไม่บาดเจ็บ) | `U` |
| เป้าหมายเชิงรับรู้ ผลรวม 0 (ก๊าซไวไฟ) | `F` |
| เป้าหมายเชิงรับรู้ ผลรวม 1 (สารพิษ) | `P` |
| เป้าหมายเชิงรับรู้ ผลรวม 2 (สารกัดกร่อน) | `C` |
| เป้าหมายเชิงรับรู้ ผลรวม 3 (สารเปอร์ออกไซด์อินทรีย์) | `O` |

ชนิดเป็นตัวอักษร แม้ว่าผู้ประสบภัยจะแสดงเป็นใบหน้า GPS ให้ค่าเป็นเมตร จึงต้องคูณด้วย 100

<CodeTabs file="report" />

หุ่นยนต์ต้องอยู่ฝั่งเดียวกับสัญลักษณ์บนผนัง และทั้งจุดศูนย์กลางของหุ่นยนต์และตำแหน่งที่ส่งต้องอยู่ห่างจากสัญลักษณ์ไม่เกินครึ่งช่อง (6 ซม.)

รันโปรแกรมนี้ที่จุดเริ่มต้นของ `world1.wbt` ตรงนั้นไม่มีสัญลักษณ์ ดังนั้นเหตุการณ์ของการแข่งขันในหน้าต่างควบคุมจะแสดง `Misidentification of Victim -5` การรายงานผิด รวมถึงการรายงานของปลอม จะเสีย 5 คะแนน และสัญลักษณ์แต่ละอันได้คะแนนเพียงครั้งเดียว

![เหตุการณ์ของการแข่งขันหลังการรายงานผิด](../../../../docs/programming/communication/history.png)

## การไม่มีความคืบหน้า \{#lack-of-progress\}

เมื่อหุ่นยนต์ติดอยู่ การไม่มีความคืบหน้า (lack of progress) จะย้ายหุ่นยนต์กลับไปยังจุดตรวจล่าสุดและเสีย 5 คะแนน ซึ่งจะเกิดขึ้นโดยอัตโนมัติเมื่อหุ่นยนต์ไม่เคลื่อนที่ 20 วินาที และโปรแกรมของคุณก็เรียกเองได้โดยส่ง `L` ทุกครั้งที่เกิดขึ้น เกมจะส่ง `L` ให้หุ่นยนต์ เพื่อให้โปรแกรมของคุณรู้ว่าตำแหน่งเปลี่ยนไปแล้ว

<CodeTabs file="lop" />

ตัวรับอาจได้รับข้อความหลายแบบ จึงควรตรวจสอบความยาวของแต่ละข้อความก่อนอ่าน เหมือนในตัวอย่าง

## ข้อมูลของเกม \{#game-information\}

ส่ง `G` เพื่อขอคะแนน เวลาที่เหลือ และระดับแบตเตอรี่ เกมจะตอบกลับด้วยข้อความขนาด 20 ไบต์ ได้แก่ ตัวอักษร `G` คะแนน เวลาของเกมและเวลาจริงที่เหลือเป็นวินาที และระดับแบตเตอรี่เป็นเปอร์เซ็นต์

<CodeTabs file="gameinfo" />

เกมจะจบเมื่อเวลาใดเวลาหนึ่งหมด หรือเมื่อแบตเตอรี่หมด ใช้ค่าเหล่านี้เพื่อรู้ว่าเมื่อไรควรกลับไปจุดเริ่มต้น และเมื่อไรควร[เปลี่ยนแบตเตอรี่](/docs/programming/battery/)

## การจบเกม \{#ending-the-game\}

ส่ง `E` เพื่อจบเกม หากหุ่นยนต์อยู่บนช่องเริ่มต้นและได้ระบุสัญลักษณ์บนผนังไปแล้วอย่างน้อยหนึ่งอัน จะได้รับโบนัสออกจากสนาม (exit bonus) 10%

<CodeTabs file="exit" />

:::caution
เกมจะจบ ณ ตำแหน่งที่หุ่นยนต์อยู่เมื่อส่ง `E` และหุ่นยนต์จะไปต่อไม่ได้ ก่อนส่ง ตรวจสอบให้แน่ใจว่าหุ่นยนต์กลับมายังช่องเริ่มต้นแล้ว และ[ส่งแผนที่](/docs/programming/map-bonus/)แล้ว
:::

ขั้นต่อไป เรียนรู้การแยกแยะสัญลักษณ์ใน[สัญลักษณ์บนผนัง](/docs/programming/wall-tokens/)
