เซนเซอร์ตำแหน่ง หรือ **GPS** ให้ตำแหน่งของหุ่นยนต์เป็น**เมตร** บนหุ่นยนต์เริ่มต้นมีชื่อว่า `gps` คุณต้องใช้เซนเซอร์นี้เพื่อ[รายงานสัญลักษณ์บนผนัง](/docs/programming/communication/#scoring-wall-tokens) และยังช่วยได้มากในการ[สำรวจอย่างเป็นระบบ](/docs/programming/exploring/)

`getValues()` คืนค่า `[x, y, z]` โดย **X และ Z เป็นแนวนอน** ส่วน Y เป็นแนวตั้ง ดังนั้นให้ใช้ X และ Z เป็นตำแหน่งในเขาวงกต:

![แกน X และ Z ของระนาบแนวนอน โดยมี Y เป็นแนวตั้ง](../../../../../docs/programming/sensors/location-sensor/coordinate_systems_right_handed.png)

GPS มีสัญญาณรบกวน (noise) ไม่กี่มิลลิเมตร ค่าจึงเปลี่ยนเล็กน้อยแม้หุ่นยนต์จะหยุดนิ่ง อย่าเปรียบเทียบตำแหน่งว่าเท่ากันพอดี
