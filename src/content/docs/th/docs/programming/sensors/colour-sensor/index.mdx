เซนเซอร์สีมองไปที่พื้น จึงบอกหุ่นยนต์ได้ว่ามีหลุม หนองน้ำ และทางผ่านหรือไม่ เซนเซอร์นี้คือกล้องขนาดหนึ่งพิกเซลที่หันลงด้านล่าง บนหุ่นยนต์เริ่มต้นมีชื่อว่า `color` และอยู่ด้านหน้าของหุ่นยนต์ เพื่อให้เห็นหลุมก่อนที่ล้อจะไปถึง

## สีของพื้น \{#floor-colours\}

ค่าเหล่านี้วัดด้วยหุ่นยนต์เริ่มต้นบน `world2.wbt`:

| พื้น | แดง | เขียว | น้ำเงิน |
|---|---:|---:|---:|
| ปกติ | 252 | 252 | 252 |
| หนองน้ำ | 245 | 222 | 142 |
| ทางผ่านระหว่างพื้นที่ 1 และ 2 (สีน้ำเงิน) | 91 | 91 | 255 |
| ทางผ่านระหว่างพื้นที่ 2 และ 3 (สีม่วง) | 193 | 91 | 251 |
| ทางผ่านระหว่างพื้นที่ 1 และ 4 (สีเขียว) | 48 | 255 | 48 |
| ทางผ่านระหว่างพื้นที่ 3 และ 4 (สีแดง) | 255 | 91 | 91 |

:::caution
ค่าจะเปลี่ยนไปตามโลก: พื้นปกติอ่านได้ประมาณ 240 ใน `world1.wbt` ให้ใช้ช่วงของค่าแทนค่าที่แน่นอน และตรวจสอบด้วย `calibrateColourSensor.py` ในโฟลเดอร์ `player_controllers` ของ Erebus
:::

หลุมมีขอบสีดำ พื้นจึงมืดลงก่อนถึงหลุมเล็กน้อย สำหรับเซนเซอร์นี้ จุดตรวจ (checkpoint) ดูแทบไม่ต่างจากพื้นปกติ ดังนั้นให้ปรับเทียบบนจุดตรวจในโลกของคุณ
