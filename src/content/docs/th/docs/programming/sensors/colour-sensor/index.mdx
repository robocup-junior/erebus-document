เซนเซอร์สีมองไปที่พื้น จึงบอกหุ่นยนต์ได้ว่ามีหลุม หนองน้ำ ช่องสัมผัส และทางผ่านหรือไม่ เซนเซอร์นี้คือกล้องขนาดหนึ่งพิกเซลที่หันลงด้านล่าง บนหุ่นยนต์เริ่มต้นมีชื่อว่า `color` และอยู่ด้านหน้าของหุ่นยนต์ เพื่อให้เห็นหลุมก่อนที่ล้อจะไปถึง

<CodeTabs file="read" />

## สีของพื้น \{#floor-colours\}

ค่าเหล่านี้วัดด้วยหุ่นยนต์เริ่มต้นบน `world2.wbt` และ `mapping_example_1_cyan_tiles.wbt`:

| พื้น | แดง | เขียว | น้ำเงิน |
|---|---:|---:|---:|
| ปกติ | 242 | 242 | 242 |
| จุดตรวจ | 254 | 254 | 254 |
| หนองน้ำ | 225 | 193 | 115 |
| ช่องสัมผัส (สีฟ้าอมเขียว) | 0 | 242 | 242 |
| หลุม (ขอบสีดำ) | 34 | 34 | 34 |
| ทางผ่านระหว่างพื้นที่ 1 และ 2 (สีน้ำเงิน) | 72 | 72 | 254 |
| ทางผ่านระหว่างพื้นที่ 2 และ 3 (สีม่วง) | 161 | 72 | 238 |
| ทางผ่านระหว่างพื้นที่ 1 และ 4 (สีเขียว) | 38 | 253 | 38 |
| ทางผ่านระหว่างพื้นที่ 3 และ 4 (สีแดง) | 254 | 72 | 72 |

:::caution
ค่าอาจเปลี่ยนไปตามโลกและการตั้งค่ากราฟิก ให้ใช้ช่วงค่าแทนค่าที่แน่นอน และตรวจสอบด้วย `calibrateColourSensor.py` ในโฟลเดอร์ `player_controllers` ของ Erebus
:::

หลุมมีขอบสีดำ พื้นจึงมืดลงก่อนถึงหลุม จุดตรวจสว่างกว่าพื้นปกติเพียงเล็กน้อย จึงควรปรับเทียบบนจุดตรวจในโลกของคุณก่อนจะพึ่งค่านี้
