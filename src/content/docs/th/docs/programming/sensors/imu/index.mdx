## ไจโรสโคป \{#gyroscope\}

ไจโรสโคปคืนค่าความเร็วในการหมุนของหุ่นยนต์รอบแต่ละแกน เป็น**เรเดียนต่อวินาที** บนหุ่นยนต์เริ่มต้นมีชื่อว่า `gyro`

`getValues()` คืนค่า `[x, y, z]` โดย**แกน Y เป็นแนวตั้ง** ดังนั้น `getValues()[1]` คือความเร็วในการเลี้ยวของหุ่นยนต์ ค่าจะเป็นบวกเมื่อเลี้ยวซ้าย

:::caution
ข้อมูลนี้ใช้กับไจโรของหุ่นยนต์เริ่มต้น แกนจะหมุนตามการหมุนของไจโร ดังนั้นหากคุณหมุนไจโรในหุ่นยนต์ของคุณเอง ให้ตรวจสอบว่าค่าใดเปลี่ยนเมื่อหุ่นยนต์เลี้ยว
:::

## ตัวอย่าง: เลี้ยว 90 องศา \{#example-turning-90-degrees\}

รวมค่าความเร็วในการหมุนคูณด้วยไทม์สเต็ป (time step) เพื่อหามุมที่เลี้ยวไป วิธีนี้น่าเชื่อถือกว่าการควบคุมการเลี้ยวด้วยเวลา เพราะไม่ขึ้นกับความเร็ว

<CodeTabs file="turn" />

ในการทดสอบบนหุ่นยนต์เริ่มต้น มุมที่คำนวณด้วยวิธีนี้ตรงกับการหมุนจริงโดยคลาดเคลื่อนไม่เกิน 0.01 เรเดียน ความคลาดเคลื่อนเล็ก ๆ จะสะสมขึ้นตลอดเกม ดังนั้นให้แก้ไขทิศทางเมื่อทำได้ เช่น โดยจัดแนวให้ตรงกับผนัง

## มาตรความเร่ง \{#accelerometer\}

มาตรความเร่งคืนค่าความเร่งตามแต่ละแกนเป็น m/s² บนหุ่นยนต์เริ่มต้นมีชื่อว่า `accelerometer` เมื่ออยู่นิ่ง `getValues()[1]` จะอ่านได้ประมาณ 9.8 ซึ่งคือแรงโน้มถ่วง

## หน่วยวัดแรงเฉื่อย \{#inertial-unit\}

หุ่นยนต์เริ่มต้นไม่มีหน่วยวัดแรงเฉื่อย (inertial unit) คุณเพิ่มได้ด้วย [Robot Customizer](/docs/robot/customizer/) โดยมีชื่อเริ่มต้นว่า `inertial_unit` หน่วยนี้ให้ทิศทางการวางตัวโดยตรงด้วย `getRollPitchYaw()` แทนที่จะต้องรวมค่าความเร็วในการหมุนเอง ดู[เอกสารอ้างอิงของ Webots](https://cyberbotics.com/doc/reference/inertialunit?version=R2023b)
