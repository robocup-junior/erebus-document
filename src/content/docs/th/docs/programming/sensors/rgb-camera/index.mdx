กล้องให้ภาพของสิ่งที่อยู่ด้านหน้า คุณต้องใช้กล้องเพื่อค้นหาและอ่าน[สัญลักษณ์บนผนัง](/docs/programming/wall-tokens/) หุ่นยนต์เริ่มต้นมีกล้องหนึ่งตัวชื่อ `camera` ขนาด 64 × 40 พิกเซล

## การอ่านพิกเซล \{#reading-pixels\}

ภาพคือตารางของพิกเซล แต่ละพิกเซลมีค่าสีแดง เขียว และน้ำเงิน ตั้งแต่ 0 ถึง 255 โดย (0, 0, 0) คือสีดำ และ (255, 255, 255) คือสีขาว

## การใช้ OpenCV \{#using-opencv\}

[OpenCV](https://opencv.org/) เป็นไลบรารีสำหรับประมวลผลภาพ เช่น ค้นหารูปทรง เปรียบเทียบสี และอื่น ๆ อีกมาก ภาพของ Webots มี 4 ค่าต่อพิกเซล เรียงลำดับแบบ BGRA ซึ่ง OpenCV ใช้ได้โดยตรง โปรแกรมนี้แสดงภาพและส่วนที่สว่างของภาพในสองหน้าต่าง:

<CodeTabs file="opencv" />

ทางซ้ายคือภาพจากกล้องของหุ่นยนต์เริ่มต้นที่อยู่หน้าผู้ประสบภัยแบบตัวอักษร ทางขวาคือส่วนที่สว่างของภาพนั้น ตามที่โปรแกรมนี้หาได้

![ภาพจากกล้องของผู้ประสบภัยแบบตัวอักษร และส่วนที่สว่างแสดงเป็นสีขาว](../../../../../docs/programming/sensors/rgb-camera/camera-and-bright.png)

:::note
สำหรับ Python, OpenCV จะถูกติดตั้งพร้อมกับ[ไลบรารี Python](/docs/installation/#python-libraries) อื่น ๆ สำหรับ C++ คุณต้องติดตั้ง OpenCV และ[เพิ่มเข้าไปตอนคอมไพล์](/docs/programming/cpp/#compiling) ตัวอย่าง C++ ทดสอบกับ OpenCV 4
:::

หน้าต่างแบบนี้มีไว้สำหรับทดสอบที่บ้าน ให้ปิดไว้เมื่อแข่งขัน

## ความละเอียด \{#resolution\}

ความละเอียดที่สูงขึ้นจะเห็นสัญลักษณ์ได้จากระยะไกลขึ้น แต่ใช้งบประมาณมากกว่าและใช้เวลาประมวลผลนานกว่า คุณเลือกความละเอียดของกล้องแต่ละตัวได้ใน [Robot Customizer](/docs/robot/customizer/#components)
