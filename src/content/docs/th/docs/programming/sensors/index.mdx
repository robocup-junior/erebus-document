---
title: เซนเซอร์
description: เซนเซอร์ทำงานอย่างไร และควรใช้ตัวใดสำหรับงานใด
---

import { CardGrid, LinkCard } from '@astrojs/starlight/components';

เซนเซอร์บอกหุ่นยนต์ของคุณเกี่ยวกับโลกรอบตัว เซนเซอร์ทุกตัวใช้งานแบบเดียวกัน:

1. รับเซนเซอร์ด้วยชื่อของมันผ่าน `robot.getDevice()`
2. เปิดใช้งานด้วย `enable(timeStep)` ก่อนหน้านั้นเซนเซอร์จะไม่ให้ค่าใด ๆ
3. อ่านค่าภายในลูปหลัก ค่าจะอัปเดตหลังจาก `robot.step()` แต่ละครั้ง

เซนเซอร์เหล่านี้มีสัญญาณรบกวน (noise) เหมือนเซนเซอร์จริง: ค่าที่อ่านได้อาจเปลี่ยนเล็กน้อยจากสเต็ปหนึ่งไปอีกสเต็ปหนึ่ง ผู้จัดการแข่งขันไม่เปลี่ยนระดับสัญญาณรบกวนในการแข่งขัน ดังนั้นให้เขียนโปรแกรมให้ทนทานต่อสัญญาณรบกวน เช่น โดยเปรียบเทียบค่าที่อ่านได้หลายครั้ง

หน้าด้านล่างนี้ใช้เซนเซอร์ของ[หุ่นยนต์เริ่มต้น](/docs/robot/)
