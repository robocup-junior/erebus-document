lidar วัดระยะเป็น**เมตร** รอบตัวหุ่นยนต์ เหมือนมีเซนเซอร์วัดระยะหลายตัวพร้อมกัน บนหุ่นยนต์เริ่มต้นมีชื่อว่า `lidar` และติดตั้งอยู่ด้านบนของหุ่นยนต์

lidar วัดได้ 512 จุดรอบตัวหุ่นยนต์ ใน 4 ชั้นที่ซ้อนกันในแนวตั้ง ได้ไกลสุด 1 เมตร จุดที่ไม่กระทบสิ่งใดจะอ่านได้ค่า `inf`

## การอ่านค่าระยะ \{#reading-distances\}

`getLayerRangeImage(0)` ให้ค่าระยะ 512 ค่าของชั้นหนึ่ง ค่าแรกอยู่ด้านหน้าหุ่นยนต์ และเรียงไปตาม**เข็มนาฬิกา**: ที่หนึ่งในสี่อยู่ทางขวา ที่ครึ่งหนึ่งอยู่ด้านหลัง และที่สามในสี่อยู่ทางซ้าย

## กลุ่มจุด (point cloud) \{#point-cloud\}

lidar ยังให้แต่ละจุดเป็นตำแหน่งเทียบกับตัว lidar ได้ด้วย ซึ่งมีประโยชน์ในการวาดแผนที่ของสิ่งที่หุ่นยนต์เห็น การคำนวณนี้ใช้เวลาเพิ่ม จึงควรเปิดใช้เฉพาะเมื่อคุณต้องใช้

:::caution[การติดตั้ง lidar]
ในหุ่นยนต์ของคุณเอง ให้ติดตั้ง lidar ไว้ด้านบน โดยใช้การหมุนแบบเดียวกับ[หุ่นยนต์เริ่มต้น](/docs/robot/build/) เพื่อให้อยู่ในแนวราบ หากอยู่ภายในตัวหุ่นยนต์หรือเอียง lidar จะวัดโดนตัวหุ่นยนต์เอง
:::
