โปรแกรมแรกของคุณจะขับหุ่นยนต์ไปข้างหน้า และหยุดเมื่ออยู่หน้าผนัง โปรแกรมนี้สั้น แต่มีทุกสิ่งที่ทุกโปรแกรมต้องมี

<CodeTabs file="hello" />

## การทำงาน \{#how-it-works\}

1. **สร้างหุ่นยนต์** `Robot()` เชื่อมต่อโปรแกรมของคุณกับหุ่นยนต์ในซิมูเลเตอร์
2. **รับไทม์สเต็ป** การจำลองเดินหน้าเป็นสเต็ป สเต็ปละไม่กี่มิลลิวินาที `getBasicTimeStep()` ให้ค่าสเต็ปของโลก
3. **รับอุปกรณ์** มอเตอร์และเซนเซอร์แต่ละตัวเรียกใช้ได้ด้วยชื่อ ซึ่งเป็นชื่อที่คุณตั้งไว้เมื่อ[ประกอบหุ่นยนต์ของคุณ](/docs/robot/build/)
4. **เปิดใช้งานเซนเซอร์** เซนเซอร์จะไม่ให้ค่าใด ๆ จนกว่าจะเปิดใช้งาน ไทม์สเต็ปบอกเซนเซอร์ว่าต้องอัปเดตบ่อยเพียงใด
5. **ลูป** `robot.step(timeStep)` ทำให้การจำลองเดินหน้าไปหนึ่งสเต็ป และคืนค่า -1 เมื่อการจำลองสิ้นสุด ทุกสิ่งที่หุ่นยนต์ของคุณทำเกิดขึ้นภายในลูปนี้

## รันโปรแกรม \{#run-it\}

1. บันทึกโปรแกรมเป็น `hello.py`
2. เปิด `game/worlds/mapping_example_1.wbt` กด **Robot setup** แล้วโหลด[หุ่นยนต์เริ่มต้น](/docs/robot/)ใต้ **Robot JSON**
3. โหลด `hello.py` ใต้ **Controller** แล้วกด **Run match**

หุ่นยนต์จะวิ่งไปข้างหน้า และคอนโซลของ Webots จะแสดงระยะห่างถึงผนังด้านหน้าจนกว่าหุ่นยนต์จะหยุด หากคุณเห็นข้อผิดพลาดแทน ให้ดูที่[การแก้ไขปัญหา](/docs/troubleshooting/#your-program)

:::tip
ใช้ `print` เพื่อทำความเข้าใจว่าหุ่นยนต์ของคุณกำลังทำอะไร นี่คือเครื่องมือที่ง่ายและมีประโยชน์ที่สุดในการหาปัญหา
:::

## ลองทำดู \{#try-it\}
- เปลี่ยนความเร็วจาก `3.0` เป็น `6.0` เกิดอะไรขึ้นเมื่อเข้าใกล้ผนัง?
- ทำให้หุ่นยนต์หยุดที่ 10 ซม. แทน 5 ซม.
- พิมพ์เวลาด้วย `robot.getTime()` ด้วย
