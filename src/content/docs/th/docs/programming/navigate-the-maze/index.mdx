ในบทเรียนนี้ คุณจะสร้างโปรแกรมที่สมบูรณ์ทีละขั้น หุ่นยนต์จะวิ่งไปรอบเขาวงกตโดยหลบผนังและหลุม และรายงานทุกสิ่งที่ดูเหมือนสัญลักษณ์บนผนัง นี่คือโปรแกรมที่คุณรันใน[การรันครั้งแรกของคุณ](/docs/getting-started/)

โปรแกรมนี้ใช้[หุ่นยนต์เริ่มต้น](/docs/robot/) และสิ่งที่คุณเรียนรู้ใน[การเคลื่อนที่](/docs/programming/movement/) และ[เซนเซอร์](/docs/programming/sensors/)

โปรแกรมฉบับสมบูรณ์: <a href={mazePy} download="maze.py">maze.py</a> · <a href={mazeC} download="maze.cpp">maze.cpp</a>

## ทำได้ดีแค่ไหน? \{#how-well-does-it-do\}
หุ่นยนต์ตัวนี้เดินไปเรื่อย ๆ: ไม่รู้ว่าเคยไปที่ใดมาแล้ว และเดาชนิดของผู้ประสบภัยทุกราย บางครั้งก็ติด และเกมจะย้ายกลับไปยังจุดตรวจหลังจาก 20 วินาที ซึ่งถือว่าดีพอสำหรับโปรแกรมแรก

## ลองทำดู \{#try-it\}
- หาความเร็วและระยะที่ดีที่สุดสำหรับหุ่นยนต์ของคุณ
- เดินตามผนังด้านหนึ่ง: รักษาระยะของเซนเซอร์ด้านข้างให้คงที่ และเลี้ยวเมื่อเซนเซอร์ด้านหน้าเห็นผนัง
- เปลี่ยนความเร็วตามระยะห่างจากผนัง

จากนั้น เรียนรู้การทำคะแนนใน[การสื่อสาร](/docs/programming/communication/)
