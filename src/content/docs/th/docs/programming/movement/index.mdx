หุ่นยนต์มีล้อสองล้อ แต่ละล้อมีมอเตอร์ของตัวเอง: `left wheel motor` และ `right wheel motor` บน[หุ่นยนต์เริ่มต้น](/docs/robot/) คุณขับหุ่นยนต์โดยตั้งความเร็วของแต่ละล้อ:

| ล้อซ้าย | ล้อขวา | หุ่นยนต์จะ... |
|---|---|---|
| ไปข้างหน้า | ไปข้างหน้า | วิ่งไปข้างหน้า |
| ถอยหลัง | ถอยหลัง | วิ่งถอยหลัง |
| ถอยหลัง | ไปข้างหน้า | หมุนตัวไปทางซ้าย |
| ไปข้างหน้า | ถอยหลัง | หมุนตัวไปทางขวา |
| เร็ว | ช้า | เลี้ยวโค้งไปทางขวา |

ความเร็วมีหน่วยเป็น**เรเดียนต่อวินาที** สูงสุด 6.28 (ล้อหมุนหนึ่งรอบต่อวินาที) ความเร็วติดลบจะทำให้ล้อหมุนถอยหลัง

## การขับเคลื่อน \{#custom-mdx-id\}

1. รับมอเตอร์แต่ละตัวด้วยชื่อของมัน
2. ตั้งตำแหน่งเป็นอนันต์ เพื่อให้หมุนได้โดยไม่จำกัด
3. ตั้งความเร็ว

มอเตอร์จะคงความเร็วล่าสุดที่คุณตั้งไว้ หุ่นยนต์จึงเคลื่อนที่ต่อไปขณะที่โปรแกรมของคุณทำอย่างอื่น โปรแกรมนี้ขับไปข้างหน้า ถอยหลัง และหมุนตัวไปทางซ้าย อย่างละหนึ่งวินาที:
