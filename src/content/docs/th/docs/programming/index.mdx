---
title: การเขียนโปรแกรมหุ่นยนต์ของคุณ
description: เส้นทางจากโปรแกรมแรกของคุณไปจนถึงหุ่นยนต์ที่เล่นได้ทั้งเกม
---

โปรแกรม หรือ**คอนโทรลเลอร์ (controller)** ทำงานเป็นลูป: อ่านเซนเซอร์ ตัดสินใจ สั่งมอเตอร์ และให้การจำลองเดินหน้าไปหนึ่งสเต็ป ทุกสิ่งที่หุ่นยนต์ของคุณทำมาจากลูปนี้

ตัวอย่างทั้งหมดในที่นี้ทำงานบน[หุ่นยนต์เริ่มต้น](/docs/robot/) ให้โหลดหุ่นยนต์นี้ก่อนรันตัวอย่าง แล้วตัวอย่างจะทำงานได้ทันที ตัวอย่างแต่ละอันมีทั้งเวอร์ชัน Python และ C/C++: เลือกภาษาของคุณในแท็บ แล้วทั้งเว็บไซต์จะใช้ตามที่คุณเลือก

## เส้นทางการเรียนรู้ \{#the-path\}

| ขั้นตอน | คุณจะได้เรียนรู้... |
|---|---|
| 1. [โปรแกรมแรกของคุณ](/docs/programming/first-program/) | เขียน โหลด และรันโปรแกรม |
| 2. [การเคลื่อนที่](/docs/programming/movement/) | ขับเคลื่อนและเลี้ยว |
| 3. [เซนเซอร์](/docs/programming/sensors/) | หาผนัง หลุม สัญลักษณ์ และตำแหน่งของคุณ |
| 4. [นำทางในเขาวงกต](/docs/programming/navigate-the-maze/) | รวมทุกอย่างเป็นโปรแกรมที่สมบูรณ์ |
| 5. [การสื่อสาร](/docs/programming/communication/) | รายงานสัญลักษณ์และทำคะแนน |
| 6. [สัญลักษณ์บนผนัง](/docs/programming/wall-tokens/) | แยกแยะผู้ประสบภัย เป้าหมาย และของปลอม |
| 7. [การสำรวจและการทำแผนที่](/docs/programming/exploring/) | สำรวจอย่างเป็นระบบและจดจำเขาวงกต |
| 8. [กติกาการทำแผนที่](/docs/rules/mapping/) และ[การส่งแผนที่](/docs/programming/map-bonus/) | รับโบนัสแผนที่ |

แต่ละขั้นต่อยอดจากขั้นก่อนหน้า หากคุณยังไม่ได้อ่าน ให้อ่าน[สรุปกติกา](/docs/rules/) ก่อน: หน้านั้นอธิบายว่าหุ่นยนต์ของคุณต้องทำอะไร และอะไรที่ได้คะแนน

หากคุณเขียนด้วย C หรือ C++ ให้อ่าน[คอนโทรลเลอร์ C++](/docs/programming/cpp/) ก่อน เพื่อคอมไพล์และรันโปรแกรมของคุณ
