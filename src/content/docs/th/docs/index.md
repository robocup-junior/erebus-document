---

Erebus เป็นสภาพแวดล้อมสำหรับการแข่งขันหุ่นยนต์จำลอง คุณออกแบบหุ่นยนต์ และเขียนโปรแกรมให้หุ่นยนต์สำรวจเขาวงกตได้เอง ค้นหาและระบุสัญลักษณ์บนผนัง หลบสิ่งกีดขวางและกับดัก ดูแลไม่ให้แบตเตอรี่หมด และสร้างแผนที่ของสภาพแวดล้อม

เอกสารนี้ครอบคลุม **Erebus v27** สำหรับกติกา **RoboCupJunior Rescue Simulation 2027** ดูเวอร์ชันอื่นที่รองรับได้ที่[เวอร์ชัน](/docs/reference/versions/)

## เส้นทางการเรียนรู้ {#the-learning-path}
ทำตามขั้นตอนตามลำดับ แต่ละขั้นต่อยอดจากขั้นก่อนหน้า

| ขั้นตอน | หน้า | คุณจะ... |
|---|---|---|
| **เริ่มต้น** | [Erebus คืออะไร?](/docs/introduction/), [การติดตั้ง](/docs/installation/) | รู้ว่ากำลังทำอะไร และติดตั้งทุกอย่างเรียบร้อย |
| **1. เกม** | [สรุปกติกา](/docs/rules/) | รู้ภารกิจ สนาม และวิธีทำคะแนน |
| **2. หุ่นยนต์ของคุณ** | [รับหุ่นยนต์ของคุณ](/docs/robot/), [ประกอบหุ่นยนต์ของคุณ](/docs/robot/build/) | โหลดหุ่นยนต์เริ่มต้นใน Erebus ได้ |
| **3. การรันครั้งแรก** | [การรันครั้งแรกของคุณ](/docs/getting-started/) | ดูหุ่นยนต์ของคุณสำรวจ และรู้จักหน้าต่างควบคุม |
| **4. พื้นฐานการเขียนโปรแกรม** | [โปรแกรมแรกของคุณ](/docs/programming/first-program/), [การเคลื่อนที่](/docs/programming/movement/), [เซนเซอร์](/docs/programming/sensors/) | ทำให้หุ่นยนต์เคลื่อนที่และรับรู้ได้ |
| **5. เล่นเกม** | [นำทางในเขาวงกต](/docs/programming/navigate-the-maze/), [การสื่อสาร](/docs/programming/communication/), [สัญลักษณ์บนผนัง](/docs/programming/wall-tokens/), [แบตเตอรี่](/docs/programming/battery/), [การสำรวจและการทำแผนที่](/docs/programming/exploring/), [กติกาการทำแผนที่](/docs/rules/mapping/), [การส่งแผนที่](/docs/programming/map-bonus/) | ทำคะแนนได้ทุกรูปแบบ |
| **6. แข่งขัน** | [การเตรียมตัวสำหรับการแข่งขัน](/docs/competition/), [Remote Controller](/docs/competition/remote-controller/) | พร้อมสำหรับการแข่งขัน |

ตัวอย่างทุกอันใช้[หุ่นยนต์เริ่มต้น](/docs/robot/) ดังนั้นให้โหลดหุ่นยนต์นี้ก่อนรันตัวอย่าง
