หน้านี้เป็นคู่มือสำหรับการแข่งขันระดับนานาชาติภายใต้กติกาปี 2027 การแข่งขันระดับท้องถิ่นและระดับภูมิภาคอาจแตกต่างออกไป ดังนั้นให้สอบถามผู้จัดของคุณ [กติกา](/docs/rules/) ทางการมีผลบังคับใช้เสมอ

## กำหนดการ {#timeline}

| เมื่อใด | สิ่งที่ต้องทำ |
|---|---|
| ตลอดทั้งปี | ติดตาม[หน้ากิจกรรม](/docs/events/upcoming-events/) และ[ฟอรัม](https://junior.forum.robocup.org/) ซึ่งมีการโพสต์คำชี้แจง |
| อย่างน้อย 4 สัปดาห์ก่อน | ผู้จัดให้คำแนะนำเกี่ยวกับแบบฟอร์มบนเว็บเพื่อเตรียมการสัมภาษณ์ |
| 3 สัปดาห์ก่อนวันแรก | กำหนดส่งเอกสาร |
| วันเตรียมการ (setup day) | มาถึงสถานที่แต่เนิ่น ๆ เพื่อลงทะเบียน สัมภาษณ์ และประชุมทีม |
| แต่ละรอบ | โลกจะถูกเปิดเผยก่อนการแข่งขันไม่นาน หลังกำหนดเวลาของแต่ละรอบแล้วจะเปลี่ยนโปรแกรมไม่ได้ |
| หลังรอบที่นับคะแนน | Technical Challenge |

## เอกสารที่ต้องส่ง {#documents-to-submit}
แม่แบบและเกณฑ์การให้คะแนนอยู่บน[เว็บไซต์ชุมชน RCJ Rescue](https://rescue.rcj.cloud/)

- [ ] **Technical Description Paper (TDP)** ทำตามแม่แบบอย่างเคร่งครัด มิฉะนั้นคะแนนของเอกสารจะเป็น 0
- [ ] **โปสเตอร์** ทั้งในรูปแบบไฟล์และโปสเตอร์จริงที่สถานที่แข่งขัน ขนาดไม่เกิน A1
- [ ] **วิดีโอ** นำเสนอโครงการของคุณ
- [ ] **วิดีโอแบบเซิร์ฟเวอร์-ไคลเอนต์:** วิดีโอสั้นที่แสดงวิธีรันคอนโทรลเลอร์บนแผนที่ตัวอย่างในการตั้งค่าแบบเซิร์ฟเวอร์-ไคลเอนต์
- [ ] **ซอร์สโค้ด** และ**แบบฟอร์มบนเว็บ**สำหรับการสัมภาษณ์

## การตั้งค่าในการแข่งขัน {#competition-setup}
เกมรันด้วยการตั้งค่าแบบเซิร์ฟเวอร์-ไคลเอนต์: ผู้จัดรันเซิร์ฟเวอร์เกมและเตรียมช่องเสียบ RJ-45 ให้หนึ่งช่อง และโปรแกรมของคุณรันบนคอมพิวเตอร์ของคุณ ดู [Remote Controller](/docs/competition/remote-controller/)

สิ่งที่ต้องนำมา:

- [ ] คอมพิวเตอร์ที่มีโปรแกรมของคุณ ติดตั้งไลบรารีทั้งหมดที่ต้องใช้ และ Webots R2025a แล้ว
- [ ] สาย Ethernet และอะแดปเตอร์หากคอมพิวเตอร์ของคุณต้องใช้
- [ ] ไฟล์ `.json` ของหุ่นยนต์ หากคุณมีหุ่นยนต์แบบกำหนดเอง
- [ ] โปสเตอร์จริง

## การตั้งค่า OpenGL {#opengl-settings}
หากผู้จัดไม่ได้ประกาศเป็นอย่างอื่น จะใช้การตั้งค่าต่อไปนี้ การตั้งค่าเหล่านี้มีผลต่อสิ่งที่กล้องเห็น ดังนั้นให้ทดสอบด้วยการตั้งค่านี้ คุณหาได้ในแท็บ OpenGL ของ Preferences ใน Webots

| การตั้งค่า | ค่า |
|---|---|
| Ambient Occlusion | Low |
| Texture Quality | Low |
| Max Texture Filtering | 4 |
| Shadows | Disabled |
| Anti-aliasing | Disabled |

## การทดสอบหุ่นยนต์ของคุณ {#testing-your-robot}
- [ ] รันบนทุกโลกที่มีมาให้ โดยเฉพาะโลก `2027_` ทั้งสี่ ซึ่งมีช่องสัมผัสและของปลอม
- [ ] สร้างแผนที่ของคุณเองด้วย [World Editor](/docs/tools/world-editor/) ให้มีครบทั้งสี่พื้นที่
- [ ] ตรวจสอบทั้งเกม: รันได้จนจบไหม เปลี่ยนแบตเตอรี่ทันเวลาไหม ส่งแผนที่และกลับไปจุดเริ่มต้นได้ไหม
- [ ] ทดสอบว่าเกิดอะไรขึ้นหลังการไม่มีความคืบหน้า (lack of progress)
- [ ] ทดสอบบนคอมพิวเตอร์ที่คุณจะนำมา และด้วยการตั้งค่า OpenGL ข้างต้น

## ระหว่างการแข่งขัน {#during-the-competition}
- เฉพาะกัปตันและรองกัปตันเท่านั้นที่เข้าพื้นที่การแข่งขันได้ เว้นแต่กรรมการจะกำหนดเป็นอย่างอื่น
- กรรมการเป็นผู้ควบคุมการจำลอง คุณแตะต้องอุปกรณ์ของเกมไม่ได้หลังจากเกมเริ่มแล้ว
- ผู้ฝึกสอน (mentor) ช่วยเหลือระหว่างการแข่งขันไม่ได้
- เตรียมพร้อมอธิบายงานของคุณ: สมาชิกทุกคนในทีมควรมีบทบาททางเทคนิคและรู้ว่างานนั้นทำงานอย่างไร

## คะแนนสุดท้าย {#final-score}
คะแนนสุดท้ายในการแข่งขันระดับนานาชาติประกอบด้วย:

| ส่วน | น้ำหนัก | เนื้อหา |
|---|---|---|
| คะแนนสนาม | 0.6 | ค่าเฉลี่ยของคะแนนสนามที่ปรับมาตรฐานแล้ว ไม่นับรอบที่แย่ที่สุดหนึ่งรอบหรือมากกว่า |
| เกณฑ์การให้คะแนน (Rubrics) | 0.2 | TDP (0.6), วิดีโอ (0.2), โปสเตอร์ (0.2) |
| Technical Challenge | 0.2 | ภารกิจย่อยที่ประกาศในการแข่งขัน แก้โจทย์โดยเขียนโปรแกรมหุ่นยนต์ใหม่ภายในเวลาจำกัด |

กรณีคะแนนเท่ากัน จะตัดสินด้วยค่าเฉลี่ยของคะแนนสนามที่ปรับมาตรฐานแล้ว SuperTeam Challenge เป็นรายการแยกต่างหากที่มีรางวัลของตัวเอง
