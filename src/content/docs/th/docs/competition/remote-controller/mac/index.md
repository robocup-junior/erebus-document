# การรันเซิร์ฟเวอร์เกมและโปรแกรมคอนโทรลเลอร์บนคอมพิวเตอร์เครื่องเดียวกัน
ก่อนอื่น ลองรันเซิร์ฟเวอร์เกมและโปรแกรมคอนโทรลเลอร์บนคอมพิวเตอร์เครื่องเดียวกัน วิธีนี้ไม่เหมือนกับการตั้งค่าในการแข่งขันจริง แต่จะช่วยคุณเมื่อดีบักบนเครื่องของตัวเอง

## เปิดโหมด Remote {#toggle-remote-mode}
เปิดโลกแล้วกด "TOGGLE REMOTE" ในหน้าต่างควบคุม ปุ่มจะเปลี่ยนเป็นสีส้มเพื่อแสดงว่าเปิดใช้งานแล้ว

![ปุ่ม TOGGLE REMOTE ที่เปิดใช้งานแล้ว](../../../../../docs/competition/remote-controller/mac/toggle_remote.png)

หากหน้าต่างควบคุมไม่แสดง ให้คลิกขวาที่ "DEF MAINSUPERVISOR Robot" ใน Scene Tree แล้วกด "Show Robot Window"

## รันโปรแกรมของคุณ {#execute-your-program}
เปิดเทอร์มินัลแล้วรันคำสั่งต่อไปนี้ โดยแทนที่ `<Your controller path>` ด้วยพาธของโปรแกรมคอนโทรลเลอร์ของคุณ

```bash
export WEBOTS_HOME=/Applications/Webots.app
"$WEBOTS_HOME/Contents/MacOS/webots-controller" "<Your controller path>"
```

หากติดตั้ง Webots ไว้ที่อื่นหรือใช้ชื่ออื่น ให้เปลี่ยน `WEBOTS_HOME` ให้ตรงกัน เช่น `"/Applications/Webots R2023b.app"`

คอนโทรลเลอร์จะเชื่อมต่อกับ Webots และรอจนกว่าเกมจะเริ่ม

## เริ่มเกม {#start-the-game}
กดปุ่มเริ่มในหน้าต่างควบคุม หุ่นยนต์จะปรากฏขึ้น และโปรแกรมของคุณจะเริ่มทำงาน

## หยุดเกม {#terminate-the-game}
หากต้องการขัดจังหวะเกม ให้กด Ctrl+C ในเทอร์มินัล

เมื่อการจำลองสิ้นสุดลง ระบบจัดการเกมของ Erebus จะสิ้นสุดลงพร้อมกัน หากต้องการรันเกมอีกครั้ง ให้โหลดโลกใหม่

# การรันเซิร์ฟเวอร์เกมบนคอมพิวเตอร์อีกเครื่องหนึ่ง
นี่คือการตั้งค่าที่ใช้ในการแข่งขันอย่างเป็นทางการ คอมพิวเตอร์ที่รันคอนโทรลเลอร์ของคุณ (ไคลเอนต์) และเซิร์ฟเวอร์เกม (เซิร์ฟเวอร์) ต้องเชื่อมต่อกับเครือข่ายเดียวกัน

1. (เซิร์ฟเวอร์) เริ่ม Webots บนเซิร์ฟเวอร์ เปิดโลก แล้วเปิดโหมด remote ในหน้าต่างควบคุม
1. (เซิร์ฟเวอร์) หาที่อยู่ IP ของเซิร์ฟเวอร์ ดูได้ใน System Settings --> Network
1. (ไคลเอนต์) รันคำสั่งต่อไปนี้ โดยแทนที่ `<Your controller path>` ด้วยพาธของโปรแกรมคอนโทรลเลอร์ของคุณ และ `<Server IP address>` ด้วยที่อยู่ IP ที่หาได้ในขั้นตอนก่อนหน้า

    ```bash
    export WEBOTS_HOME=/Applications/Webots.app
    "$WEBOTS_HOME/Contents/MacOS/webots-controller" --protocol=tcp --ip-address=<Server IP address> "<Your controller path>"
    ```
1. (เซิร์ฟเวอร์) เริ่มเกมโดยกดปุ่มเริ่ม

## การแก้ไขปัญหา {#troubleshooting}
- **คอนโทรลเลอร์เชื่อมต่อไม่ได้:** ตรวจสอบว่าคอมพิวเตอร์ทั้งสองเครื่องติดต่อกันได้ เช่น ด้วย `ping` ตรวจสอบว่าไฟร์วอลล์ของเซิร์ฟเวอร์อนุญาตพอร์ต TCP 1234 และรายการ IP ที่อนุญาตในแท็บ Network ของ Preferences ใน Webots ว่างอยู่หรือมีไคลเอนต์อยู่ด้วย
- **แสดง `No robot name provided`:** ข้อความนี้เป็นเรื่องปกติขณะรอ หากยังแสดงต่อไปเรื่อย ๆ แสดงว่าโหมด remote ไม่ได้เปิดอยู่ ให้ตรวจสอบปุ่ม TOGGLE REMOTE
- **คอนโทรลเลอร์หาไลบรารี Python ไม่พบ:** โปรแกรมรันด้วย Python ของไคลเอนต์ ดังนั้นให้ติดตั้งไลบรารีที่นั่น
