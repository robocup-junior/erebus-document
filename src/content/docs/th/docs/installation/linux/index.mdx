import { Steps } from '@astrojs/starlight/components';
import DownloadErebus from '@/components/DownloadErebus.astro';

<Steps>

1. เปิดเทอร์มินัล แล้วติดตั้ง pip และไลบรารีที่จำเป็น:

   ```bash
   sudo apt install python3-pip
   python3 -m pip install numpy termcolor requests overrides pillow opencv-python
   ```

   บน Ubuntu 24.04 pip จะไม่ยอมติดตั้งไลบรารีลงใน Python ของระบบ และแสดงข้อผิดพลาด `externally-managed-environment` ให้เพิ่ม `--break-system-packages` ในคำสั่งที่สอง หรือติดตั้งไลบรารีใน[สภาพแวดล้อมเสมือน](https://docs.python.org/3/library/venv.html) แล้วตั้งค่า Python ของมันในค่ากำหนดของ Webots

2. ดาวน์โหลดและติดตั้ง **Webots R2025a**:

   ```bash
   wget https://github.com/cyberbotics/webots/releases/download/R2025a/webots_2025a_amd64.deb
   sudo apt install ./webots_2025a_amd64.deb
   ```

3. ดาวน์โหลด <DownloadErebus /> แล้วแตกไฟล์

</Steps>

## รันสภาพแวดล้อม \{#run-the-environment\}

เปิดโลก (world) จากเทอร์มินัล โดยเปลี่ยนพาธเป็นโฟลเดอร์ Erebus ของคุณ:

```bash
webots ~/EREBUS_FOLDER/game/worlds/world1.wbt
```

Webots จะเปิดหน้าต่างควบคุมของ Erebus ในเว็บเบราว์เซอร์ของคุณ ในครั้งแรก Erebus จะติดตั้งไลบรารี Python บางตัวและเตรียมโมเดลหุ่นยนต์ ซึ่งอาจใช้เวลาสักพัก เมื่อหน้าต่างแสดง **Ready** และตัวจับเวลาเกม 08:00 ก็แสดงว่าพร้อมแล้ว:

![หน้าต่างควบคุมของ Erebus ที่พร้อมเริ่มต้น](../../../../docs/installation/linux/../control-window-ready.png)

ในครั้งแรก คอนโซลของ Webots อาจแสดง `ERROR: Skipped PROTO 'custom_robot'` ด้วย ซึ่งไม่ต้องสนใจ Erebus จะเตรียมโมเดลหุ่นยนต์และโหลดโลกใหม่เอง

ขั้นต่อไป อ่าน[สรุปกติกา](/docs/rules/) เพื่อทำความเข้าใจเกม หากเกิดปัญหา ดูที่[การแก้ไขปัญหา](/docs/troubleshooting/)
