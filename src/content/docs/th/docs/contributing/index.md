## การมีส่วนร่วมกับแพลตฟอร์ม Erebus {#contributions-to-the-erebus-platform}

คุณมีส่วนร่วมกับแพลตฟอร์ม Erebus ได้หลายวิธี:
- เปิด [issue ในรีโพสิทอรี](https://github.com/robocup-junior/erebus/issues): แจ้งให้เราทราบหากพบบั๊กในแพลตฟอร์ม หรือมีฟีเจอร์ที่คุณคิดว่าควรมี
- สร้าง pull request: หากคุณแก้บั๊กได้เอง ก็ส่งการแก้ไขนั้นเป็น pull request เพื่อให้เราตรวจสอบและรวม (merge) เข้าไปได้
- พูดคุยกับเราใน[เซิร์ฟเวอร์ Discord](https://discord.com/invite/6FJxZxk): คุณติดต่อนักพัฒนาและคณะกรรมการ RCJ Rescue ได้ที่นั่น มาแบ่งปันไอเดียของคุณกับเรา!

### การมีส่วนร่วมที่ลึกขึ้น {#deeper-involvement}
ขณะนี้เรายังไม่ได้เปิดรับนักพัฒนาใหม่สำหรับแพลตฟอร์มการจำลองอย่างจริงจัง อย่างไรก็ตาม เรามองหาผู้มีความสามารถอยู่เสมอ เพื่อดูแลแพลตฟอร์มนี้ต่อไปให้คนรุ่นหลัง หากคุณมีทักษะและต้องการเข้าร่วมทีมพัฒนา โปรดติดต่อทีมพัฒนาแพลตฟอร์มหรือคณะกรรมการ RoboCupJunior Rescue ในเซิร์ฟเวอร์ Discord

## การมีส่วนร่วมกับเอกสาร {#contributions-to-the-documentation}

- เปิด issue ใน[รีโพสิทอรีของเอกสาร](https://github.com/robocup-junior/erebus-document/issues)
- พูดคุยกับเราใน[เซิร์ฟเวอร์ Discord](https://discord.com/invite/6FJxZxk): คุณติดต่อนักพัฒนาและคณะกรรมการ RCJ Rescue ได้ที่นั่น มาแบ่งปันไอเดียของคุณกับเรา!
- มาเป็นผู้แก้ไขเอกสาร! หากคุณอยากช่วยเขียนเอกสาร โปรดติดต่อทีมพัฒนาแพลตฟอร์มในเซิร์ฟเวอร์ Discord

เอกสารนี้เป็นเว็บไซต์ [Astro](https://astro.build/) ที่ใช้ธีม [Starlight](https://starlight.astro.build/) หน้าต่าง ๆ เป็นไฟล์ Markdown ใน `src/content/docs` และทุกหน้ามีลิงก์ **Edit page** อยู่ด้านล่าง วิธีรันเว็บไซต์บนเครื่องของคุณดูได้ใน [README](https://github.com/robocup-junior/erebus-document#readme) ของรีโพสิทอรีเอกสาร
