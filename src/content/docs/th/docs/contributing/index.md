## การมีส่วนร่วมกับแพลตฟอร์ม Erebus  {#contributions-to-the-erebus-platform}

หากคุณต้องการมีส่วนร่วมกับแพลตฟอร์ม Erebus ขณะนี้มีอยู่สองสามวิธี
- เปิด [issue ในคลัง (repository)](https://github.com/robocup-junior/erebus/issues): แจ้งให้เราทราบหากคุณพบบั๊กของแพลตฟอร์ม หรือฟีเจอร์ที่คุณคิดว่าควรมี
- Pull request: หากคุณแก้บั๊กได้ด้วยตัวเอง คุณสามารถสร้าง pull request สำหรับการเปลี่ยนแปลงนั้น เพื่อให้อาจถูกนำไปใช้
- พูดคุยกับเราผ่าน[เซิร์ฟเวอร์ Discord](https://discord.com/invite/6FJxZxk): คุณติดต่อเรา (นักพัฒนา และคณะกรรมการ RCJ Rescue) ได้ผ่านเซิร์ฟเวอร์ Discord มาแบ่งปันไอเดียของคุณกับเรา!

### การมีส่วนร่วมที่ลึกขึ้น {#deeper-involvement}
ขณะนี้เราไม่ได้กำลังมองหานักพัฒนาใหม่สำหรับแพลตฟอร์มการจำลองอย่างจริงจัง อย่างไรก็ตาม เรามองหาผู้มีความสามารถใหม่ ๆ อยู่เสมอ เพื่อดูแลแพลตฟอร์มนี้ต่อไปสำหรับคนรุ่นต่อไป หากคุณมั่นใจว่ามีทักษะและต้องการเป็นส่วนหนึ่งของทีมพัฒนาแพลตฟอร์มนี้ โปรดติดต่อทีมพัฒนาแพลตฟอร์มหรือคณะกรรมการ RoboCupJunior Rescue ผ่านเซิร์ฟเวอร์ Discord

## การมีส่วนร่วมกับเอกสาร {#contributions-to-the-documentation}

- เปิด issue โดยคลิกที่ [Documentation issue](https://github.com/robocup-junior/erebus-document/issues) แล้วสร้าง issue ในคลังของโครงการ
- พูดคุยกับเราผ่าน[เซิร์ฟเวอร์ Discord](https://discord.com/invite/6FJxZxk): คุณติดต่อเรา (นักพัฒนา และคณะกรรมการ RCJ Rescue) ได้ผ่านเซิร์ฟเวอร์ Discord มาแบ่งปันไอเดียของคุณกับเรา!
- มาเป็นผู้แก้ไขเอกสารอย่างต่อเนื่อง! หากคุณต้องการมีส่วนร่วมในการเขียนเอกสารอย่างจริงจัง โปรดติดต่อทีมพัฒนาแพลตฟอร์มบนเซิร์ฟเวอร์ Discord

เอกสารนี้เป็นเว็บไซต์ [Astro](https://astro.build/) ที่ใช้ธีม [Starlight](https://starlight.astro.build/) หน้าต่าง ๆ เป็นไฟล์ Markdown ใน `src/content/docs` และทุกหน้ามีลิงก์ **Edit page** อยู่ด้านล่าง ดู [README](https://github.com/robocup-junior/erebus-document#readme) ของคลังเอกสาร เพื่อดูวิธีรันบนเครื่องของคุณ
