---
title: อภิธานศัพท์
description: คำศัพท์ที่ใช้ใน Erebus และในกติกา
---

| คำศัพท์ | ความหมาย |
|---|---|
| **พื้นที่ (Area)** | หนึ่งในสี่ส่วนของสนาม แต่ละส่วนมีผนังแบบของตัวเอง World Editor เรียกว่าห้อง (room) |
| **ตัวคูณพื้นที่ (Area multiplier, AM)** | 1, 1.25, 1.5 หรือ 2 ใช้กับคะแนนของแต่ละพื้นที่ |
| **จุดตรวจ (Checkpoint)** | ช่องสีเงิน หุ่นยนต์จะกลับไปยังจุดตรวจล่าสุดที่ผ่านมาหลังจากการไม่มีความคืบหน้า |
| **เป้าหมายเชิงรับรู้ (Cognitive target)** | สัญลักษณ์บนผนังที่เป็นวงกลมซ้อนกันห้าสี ซึ่งผลรวมของค่าบอกชนิดของวัตถุอันตราย (hazmat) ใช้แทนป้ายวัตถุอันตรายตั้งแต่ปี 2026 |
| **หน้าต่างควบคุม (Control window)** | หน้าเว็บที่คุณใช้โหลดโปรแกรมและรันเกม เรียกอีกชื่อว่า robot window |
| **คอนโทรลเลอร์ (Controller)** | โปรแกรมของคุณ |
| **หุ่นยนต์แบบกำหนดเอง (Custom robot)** | หุ่นยนต์ที่ออกแบบด้วย Robot Customizer และโหลดจากไฟล์ `.json` |
| **โบนัสออกจากสนาม (Exit bonus, EB)** | +10% สำหรับการกลับมายังช่องเริ่มต้นและส่ง `E` |
| **ของปลอม (Fake)** | สัญลักษณ์ที่ห้ามรายงาน: ผู้ประสบภัยแบบตัวอักษรที่เป็นสามมิติ และเป้าหมายเชิงรับรู้ที่มีผลรวมไม่ถูกต้อง |
| **ช่องลอย (Floating tile)** | ช่องที่ไปไม่ถึงด้วยการเดินตามผนังที่เชื่อมต่อกับจุดเริ่มต้น สัญลักษณ์ในช่องเหล่านี้มีคะแนนสูงกว่า |
| **การไม่มีความคืบหน้า (Lack of progress, LoP)** | เมื่อหุ่นยนต์ติดอยู่หรือตกลงไปในหลุม หุ่นยนต์จะกลับไปยังจุดตรวจล่าสุดและเสีย 5 คะแนน |
| **ผู้ประสบภัยแบบตัวอักษร (Letter victim)** | สัญลักษณ์บนผนังที่มีเครื่องหมาย Φ, Ψ หรือ Ω |
| **ช่องเชิงเส้น (Linear tile)** | ช่องที่ไปถึงได้ด้วยการเดินตามผนังที่เชื่อมต่อกับจุดเริ่มต้น |
| **Main Supervisor** | ส่วนของ Erebus ที่จัดการเกม เรียกอีกชื่อว่าตัวจัดการเกม (game manager) |
| **โบนัสแผนที่ (Mapping bonus, MB)** | ตัวคูณคะแนนเท่ากับ ความถูกต้อง × 1.2 + 1 |
| **เมทริกซ์แผนที่ (Map matrix)** | อาร์เรย์ที่แทนแผนที่ |
| **ทางผ่าน (Passage)** | ช่องสีที่เชื่อมระหว่างสองพื้นที่ |
| **ช่องย่อยหนึ่งในสี่ (Quarter tile)** | หนึ่งในสี่ของช่อง กว้าง 6 ซม. ใช้ในพื้นที่ 2 และ 3 |
| **การตั้งค่าแบบเซิร์ฟเวอร์-ไคลเอนต์ (Server-client setup)** | เกมรันบนคอมพิวเตอร์เครื่องหนึ่ง และโปรแกรมของคุณรันบนอีกเครื่องหนึ่ง ดู Remote Controller |
| **หนองน้ำ (Swamp)** | ช่องสีน้ำตาลที่ทำให้เวลาของเกมเดินเร็วขึ้น |
| **TDP** | Technical Description Paper (เอกสารอธิบายทางเทคนิค) |
| **ช่อง (Tile)** | หน่วยของสนาม กว้าง 12 ซม. |
| **TI, TT, CN, TMI** | ในการให้คะแนน: การระบุสัญลักษณ์ (token identification), ชนิดของสัญลักษณ์ (token type), การผ่านจุดตรวจ (checkpoint negotiation) และการระบุสัญลักษณ์ผิด (token misidentification) |
| **สัญลักษณ์บนผนัง (Wall token)** | ทุกสิ่งบนผนังที่ต้องระบุ: ผู้ประสบภัยแบบตัวอักษรและเป้าหมายเชิงรับรู้ |
| **โลก (World)** | แผนที่ ในรูปแบบไฟล์ `.wbt` |
