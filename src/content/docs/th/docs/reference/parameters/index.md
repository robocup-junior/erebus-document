## สนาม {#field}

| พารามิเตอร์ | ค่า |
|---|---|
| ช่อง (tile) | 12 ซม. × 12 ซม. |
| ช่องย่อยหนึ่งในสี่ (พื้นที่ 2 และ 3) | 6 ซม. × 6 ซม. |
| ผนัง | หนา 1 ซม. สูง 6 ซม. |
| ผู้ประสบภัยแบบตัวอักษร | 2 ซม. × 2 ซม. |
| เป้าหมายเชิงรับรู้ | เส้นผ่านศูนย์กลาง 5 ซม. |

## เกม {#game}

| พารามิเตอร์ | ค่า |
|---|---|
| เวลาของเกม | เวลาในการจำลอง 8 นาที |
| เวลาจริง | 10 นาที |
| การไม่มีความคืบหน้า (LoP) อัตโนมัติ | หลังจากอยู่ในตำแหน่งเดิม 20 วินาที |
| เวลาหยุดเพื่อรายงานสัญลักษณ์บนผนัง | อย่างน้อย 1 วินาที |
| ตัวคูณเวลาในหนองน้ำ | x5 เมื่อเข้าครั้งแรก, +1 ทุกครั้งที่เข้าหนองน้ำเดิมอีก สูงสุด x10 |
| ตัวคูณพื้นที่ | 1, 1.25, 1.5 และ 2 สำหรับพื้นที่ 1, 2, 3 และ 4 |
| โบนัสออกจากสนาม | +10% |
| ตัวคูณโบนัสแผนที่ | ความถูกต้อง × 1.2 + 1 |

## หุ่นยนต์ {#robot}

| พารามิเตอร์ | ค่า |
|---|---|
| งบประมาณ | 3000 |
| จำนวนกล้องสูงสุด | 3 |
| จำนวนเซนเซอร์วัดระยะสูงสุด | 8 |
| ระยะของเซนเซอร์วัดระยะ | 0 ถึง 0.8 m |
| ความแม่นยำของ GPS | 0.0025 m |
| ความเร็วล้อสูงสุด | 6.28 rad/s |
| Lidar | 512 จุดต่อชั้น, 4 ชั้น, 0.01 ถึง 1 m |

`timeStep` กำหนดจำนวนมิลลิวินาทีระหว่างการอัปเดตเซนเซอร์แต่ละครั้ง `int(robot.getBasicTimeStep())` ให้ค่าไทม์สเต็ปพื้นฐานของโลก ซึ่งเท่ากับ 16 ms ในโลกของ Erebus v26.1

## ชื่ออุปกรณ์ของหุ่นยนต์เริ่มต้น {#device-names-of-the-starter-robot}

นี่คือชื่อที่ต้องส่งให้ `robot.getDevice()` เมื่อใช้[หุ่นยนต์เริ่มต้น](/docs/robot/) ในหุ่นยนต์ของคุณเอง คุณเลือกชื่อได้ใน [Robot Customizer](/docs/robot/customizer/#components) ตัวส่ง (emitter) และตัวรับ (receiver) มีให้ใช้เสมอ

| อุปกรณ์ | ชื่อ |
|---|---|
| มอเตอร์ล้อ | `left wheel motor`, `right wheel motor` |
| เอนโค้ดเดอร์ล้อ | `left wheel sensor`, `right wheel sensor` |
| เซนเซอร์วัดระยะ | `leftDist`, `frontDist`, `rightDist` |
| กล้อง | `camera` |
| เซนเซอร์สี | `color` |
| GPS | `gps` |
| ไจโรสโคป | `gyro` |
| มาตรความเร่ง | `accelerometer` |
| Lidar | `lidar` |
| ตัวส่ง (emitter) | `emitter` |
| ตัวรับ (receiver) | `receiver` |
