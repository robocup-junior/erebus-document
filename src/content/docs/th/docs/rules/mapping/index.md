## แนวคิดทั่วไป {#general-idea}
การทำแผนที่ให้คะแนนในรูปของตัวคูณที่คูณกับคะแนนของการรัน หุ่นยนต์ต้องส่งเมทริกซ์ให้ Main Supervisor ของเกมจึงจะได้ตัวคูณนี้ เมทริกซ์ที่ส่งจะถูกเปรียบเทียบกับ "เฉลย" เพื่อหาค่าความถูกต้อง และตัวคูณคือ:

**ตัวคูณโบนัสแผนที่ (mapping bonus) = ความถูกต้อง × 1.2 + 1**

ดังนั้นแผนที่ที่สมบูรณ์แบบจะคูณคะแนนของคุณด้วย 2.2 วิธีส่งเมทริกซ์ดูได้ที่[บทเรียนการส่งแผนที่](/docs/programming/map-bonus/)

## กติกาการทำแผนที่ {#rules-for-mapping}
* ช่องย่อยหนึ่งในสี่ (quarter tile) แต่ละช่อง ขอบแต่ละเส้น และจุดยอดแต่ละจุด แทนด้วยเซลล์ (ค่า) หนึ่งเซลล์ ดังนั้นแผนที่ขนาด W × H ช่องจึงเป็นเมทริกซ์ที่มี (4 × H + 1) แถว และ (4 × W + 1) คอลัมน์
* องค์ประกอบแต่ละอย่างในโลกแทนด้วยค่าต่อไปนี้:

| องค์ประกอบ | ค่า |
|---|---|
| ผนัง | `1` |
| หลุม | `2` |
| หนองน้ำ | `3` |
| จุดตรวจ | `4` |
| ช่องเริ่มต้น | `5` |
| ช่องที่มีสิ่งกีดขวาง | `x` |
| ทางผ่านระหว่างพื้นที่ 1 และ 2 (สีน้ำเงิน) | `b` |
| ทางผ่านระหว่างพื้นที่ 1 และ 3 (สีเหลือง) | `y` |
| ทางผ่านระหว่างพื้นที่ 1 และ 4 (สีเขียว) | `g` |
| ทางผ่านระหว่างพื้นที่ 2 และ 3 (สีม่วง) | `p` |
| ทางผ่านระหว่างพื้นที่ 2 และ 4 (สีส้ม) | `o` |
| ทางผ่านระหว่างพื้นที่ 3 และ 4 (สีแดง) | `r` |
| สัญลักษณ์บนผนัง | รหัสที่ตรงกัน (`H`, `S`, `U`, `F`, `P`, `C`, `O`) |
| ช่อง ขอบ และจุดยอดทั้งหมดของพื้นที่ 4 รวมถึงขอบเขตของพื้นที่ | `*` |
| ช่อง ขอบ และจุดยอดอื่น ๆ ทั้งหมด | `0` |

* องค์ประกอบของพื้น (`2`, `3`, `4`, `5`, `x` และทางผ่าน) เขียนไว้ที่เซลล์ตรงกลางของช่องย่อยหนึ่งในสี่ทั้งสี่ช่องของช่องนั้น ดังที่เห็นในตัวอย่างด้านล่าง
* ไม่มีช่องใดเป็นมากกว่าหนึ่งอย่างต่อไปนี้ในเวลาเดียวกัน: หนองน้ำ หลุม จุดตรวจ ช่องเริ่มต้น ช่องที่มีสิ่งกีดขวาง หรือทางผ่านระหว่างพื้นที่
* สำหรับผนังโค้งในพื้นที่ 3 จุดยอดแทนด้วย `0`
* สัญลักษณ์บนผนังเขียนไว้ในเซลล์ของผนังที่สัญลักษณ์นั้นติดอยู่ หากมีสัญลักษณ์หลายอันบนผนังเดียวกัน เช่น อยู่ทั้งสองด้านของผนัง ให้ต่อรหัสเข้าด้วยกันในเซลล์เดียว ตามลำดับตำแหน่งสัมบูรณ์บนแผนที่: เรียงจากบนลงล่างก่อน แล้วจากซ้ายไปขวา
* ห้ามใส่สัญลักษณ์ปลอมลงในแผนที่ ทั้งผู้ประสบภัยปลอม (fake victims) และเป้าหมายเชิงรับรู้ (cognitive targets) ที่มีผลรวมไม่ถูกต้อง
* สัญลักษณ์บนผนังในช่องเต็ม (ที่ไม่ใช่ช่องย่อยหนึ่งในสี่) อาจอยู่ที่ใดก็ได้ตามแนวผนัง โดยเขียนไว้ในเซลล์ของช่องย่อยหนึ่งในสี่ที่อยู่ใกล้กว่า หรือในเซลล์ตรงกลางหากอยู่ใกล้กึ่งกลางของด้านของช่อง
* แผนที่ที่ส่งจะหมุนไปทิศทางใดก็ได้ ตราบใดที่มุมเป็นพหุคูณของ 90° Erebus จะจัดแนวเมทริกซ์ของคุณให้ตรงกับเฉลยโดยใช้ช่องเริ่มต้น ลองทุกทิศทาง และเก็บผลลัพธ์ที่ดีที่สุด

## วิธีคำนวณความถูกต้อง {#how-correctness-is-calculated}
1. เมทริกซ์จะถูกจัดแนวด้วยช่องเริ่มต้น นั่นหมายความว่า**แผนที่ของคุณต้องมีช่องเริ่มต้น**
1. ทุกตำแหน่งที่เมทริกซ์ที่ส่งหรือเฉลยมีค่าที่ไม่ใช่ศูนย์จะถูกเปรียบเทียบ หากค่าตรงกัน จำนวนที่ถูกจะเพิ่มขึ้น มิฉะนั้นจำนวนที่ผิดจะเพิ่มขึ้น ตำแหน่งที่เป็น `0` ทั้งสองฝั่งจะไม่นับ
1. ความถูกต้อง = จำนวนที่ถูก / (จำนวนที่ถูก + จำนวนที่ผิด)

เนื่องจากนับเฉพาะตำแหน่งที่มีบางสิ่งอยู่ การทำเครื่องหมายสิ่งที่ไม่มีอยู่จริงจะลดความถูกต้องลงเท่ากับการพลาดสิ่งที่มีอยู่จริง

## กรณีกำกวม {#ambiguous-edge-cases}
สำหรับกรณีกำกวมที่ไม่ได้อธิบายไว้ด้านล่าง โปรดติดต่อคณะกรรมการ RoboCupJunior Rescue ระดับนานาชาติ และ/หรือทีมพัฒนาแพลตฟอร์ม
### ผนังหนึ่งที่มีผนังมุมฉากปกติด้านหนึ่งและผนังโค้งอีกด้านหนึ่ง {#one-wall-with-a-normal-right-angled-wall-and-a-curved-wall-on-each-side}
กติการะบุว่าจุดยอดของผนังโค้งแทนด้วยศูนย์
ข้อยกเว้นคือกรณีต่อไปนี้ ซึ่งด้านหนึ่งของผนังเป็นมุมฉากปกติและอีกด้านหนึ่งเป็นโค้ง กรณีนี้ให้แทนเหมือนกับว่าทั้งสองด้านเป็นผนังปกติ
