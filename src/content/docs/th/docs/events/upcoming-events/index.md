## การแข่งขันระดับนานาชาติ RoboCupJunior 2027 {#robocupjunior-2027-international-competition}

RoboCup 2027 จะจัดขึ้นที่เมืองนูเรมเบิร์ก ประเทศเยอรมนี ระหว่างวันที่ 17 ถึง 21 มิถุนายน 2027 ทีมที่แข่งขันในรายการ RoboCupJunior Rescue Simulation จะใช้ซิมูเลเตอร์ Erebus

กติกาและรีลีสของ Erebus สำหรับการแข่งขันนี้ยังไม่ใช่ฉบับสุดท้าย เอกสารนี้อธิบาย Erebus v26 และกติกาปี 2026 ดังนั้นโปรดตรวจสอบ[หน้าของกิจกรรม](https://rescue.rcj.cloud/events/2027/RoboCup2027/simulation/index.html) เพื่อดูร่างกติกา เวอร์ชันของ Erebus ที่ใช้ในการแข่งขัน และข่าวล่าสุด
